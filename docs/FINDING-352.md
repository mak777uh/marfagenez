# FINDING-352: Двухосевая запись (L/L*)+(v/v*)²≤1 штрафует снижение нагрузки: квадрат по скорости не различает знак

**Дата:** 25.11.2026. **Агент:** `fast`.

## Что установлено

Совместное условие из `docs/FORMULA-TWO-AXES.md`:

    (L/L*) + (v/v*)² ≤ 1,   где v = dL/dt

штрафует **отрицательную** скорость так же, как положительную, потому что `v`
входит только в квадрате. Система, **снижающая** нагрузку с большой скоростью
(`v < 0`, `|v| > v*·sqrt(1 − L/L*)`), формально нарушает условие и предсказывается
как коллапсирующая — хотя снижение нагрузки по смыслу документа должно быть
безопасным направлением («медленное осушение безопасно, быстрое — нет»
относятся к росту, не к спаду).

Численный пример (команда ниже): `L/L* = 0.5`, `v/v* = −0.8` даёт
`0.5 + 0.64 = 1.14 > 1` — формула говорит «нет сохранения состояния» при снятии
нагрузки.

Минимальная правка: `v⁺ = max(v, 0)` в квадратичном члене, т.е.
`(L/L*) + (v⁺/v*)² ≤ 1`, либо явно ограничить область `v ≥ 0` и записать
«условие сформулировано только для нарастания нагрузки; для спада — отдельное
условие возврата (гистерезис, DIP33-0006)». Вторая запись честнее, потому что
документ сам декларирует гистерезис — а он и есть механизм, делающий спад
отличным от роста.

## На каком основании

```
python3 - <<'PY'
0.5 + 0.8**2   # = 1.14 > 1
PY
```

Критические точки формы (та же проверка, сетка `L/L* ∈ {0.1…0.99}`):
`v_crit/v* = sqrt(1 − L/L*)` — при `L/L*=0.9` это 0.316, при `0.99` — 0.10,
т.е. вблизи `L*` допустимая скорость падает круто (квадрат даёт особенность
квадратного корня на границе).

Различимость (п.3 правил): сумма квадратов против альтернатив различима
измерением — при `L/L*=0.5` sum-форма даёт `v_crit=0.707 v*`, тогда как
линейная `1−L/L*` даёт `0.5 v*` и произведение комплементов — иное значение;
разница ~30–40 % в критической скорости, измеримо в системах с известными
`L*`, `v*` (например, бистабильная модель DIP34-0008, где порог basin
instability уже вычислен: r*≈1.07672 при Δr≈0.327).

Числа-якоря из карты: DIP34-0008 (порог + условие по скорости — прямая
литературная опора двух осей), DIP33-0006 (задержка обратного перехода ∝ ε,
не ε^(2/3) — ограничение на форму восстановления), B16-01-0003 (шум опускает
критическую скорость — документ сам называет условие без шума
«оптимистичной границей», это согласуется).

## Что это НЕ доказывает

- Не доказывает, что `v⁺`-правка правильна: возможны системы, где быстрый спад
  тоже опасен (инерция восстановления, гистерезис) — тогда нужен не `max(v,0)`,
  а отдельная ветвь.
- Не проверяет эмпирически, что реальный коллапс следует именно этой границе:
  критерий опровержения `(v/v*)²`-члена («переход при одной скорости
  независимо от уровня») в этом раунде не закрыт — прямого измерения
  «одна система, разные скорости» не найдено.
- Не аудирует `L*` и `v*` как функции состояния: если критическая нагрузка сама
  деградирует с историей, константные пороги — приближение.

## Следующая проверка

1. В `docs/FORMULA-TWO-AXES.md` дописать область применимости: условие —
   только для `v ≥ 0`; для `v < 0` ввести отдельное условие возврата или
   сослаться на гистерезис (DIP33-0006, DIP34-0008).
2. Численный эксперимент в `core/` (если появится задача): система с известными
   `L*`, `v*`, разными скоростями подхода — проверить, что предсказанная
   `v_crit = v*·sqrt(1 − L/L*)` совпадает с измеренной границей коллапса.
3. Найти в карте/литературе систему, где спад нагрузки с разной скоростью даёт
   разные исходы — это сразу проверит и знак-дефект, и гистерезис.

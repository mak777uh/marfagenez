# Правило остановки литературного круга

Фаза 4 плана `docs/PLAN-2026-11-24.md`. Правило было только для экспериментальной линии; здесь оно
записано и для литературной.

## Правило

1. **Два круга подряд без новой проверенной ячейки** — менять **канал**, а не формулировку запроса.
   Порядок замены: Europe PMC REST → NCBI `efetch` → PMC ID converter + `efetch` → издательские OA
   (Frontiers, PLOS, eLife, MDPI, bioRxiv, arXiv) → CORE/Unpaywall.
2. **Канал меняли, а ячеек всё равно нет** — остановить литературный круг и заняться сшивкой уже
   найденного: воронка показывает, что предельный выход нового поиска близок к нулю.
3. **Не считать «нет доступа» за «нет в литературе».** Закрытый текст — это `[только указатель]`, и в
   ячейку он не идёт.

## Почему правило нужно

Воронка литературной работы: **192 кандидата → 108 принято → 8 тронуты связью → 1 проверен** (по
внешнему разбору и по нашей карте). При таком выходе следующий проход по связности даёт почти ноль, а
сшивка уже найденного — десятки новых пар. Это и есть причина правила.

## Что считается «кругом»

Один цикл работы = один поисковый проход: партия дипа либо собственный поиск с проверенными DOI и
дословными цитатами. Круг **без новой ячейки** — это круг, где ни одна ячейка не прошла проверку цитаты.

## Как правило проверяется

- В журнале (`docs/agent/AGENT_LOG.md`) каждый круг пишет, сколько ячеек принято.
- Если два соседних круга дали 0 — в записи следующего круга обязано быть указано, **какой канал заменён**.
- Если и после замены 0 — запись обязана сказать, что круг остановлен и работа переведена в сшивку.

## Что это правило не запрещает

- Оно **не запрещает** искать под конкретную дыру (`gap`), когда есть точный вопрос.
- Оно **не требует** останавливать дипы совсем: дип — это канал, и его замена тоже канал.

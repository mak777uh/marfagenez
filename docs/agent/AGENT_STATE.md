# AGENT_STATE.md — где проект сейчас

**Этот файл читает следующий агент первым.** Он отвечает на четыре вопроса:
где мы, что делаем сейчас, что дальше, чего не трогать. Он не дневник —
дневник это `AGENT_LOG.md`.

**Гейт:** `run.sh agents` требует, чтобы этот файл был тронут **в том же
коммите**, что HEAD. Проверяет по истории Git, а не по времени файла: после
clone/checkout mtime врёт.

**Как это выполняется.** Гейт сравнивает `git rev-parse HEAD` с хэшем
последнего коммита, тронувшего этот файл, — то есть требует, чтобы файл был
в **каждом** коммите, включая чисто механические. Поэтому правка состояния —
не дневник, а часть коммита: перед `git commit` допиши в §3 строку о том, что
изменил этот коммит. Если менять нечего — коммит не нужен.

**Обновлять в конце каждого цикла**, перед `git commit`.

## §3 Текущий вопрос

**Открытые вопросы сейчас.** Полная история — [`AGENT-HISTORY.md`](AGENT-HISTORY.md).

**Второй потолок снят: при смертельной засухе оптимум внутри (0.75), а не на краю (цикл 279).** `FINDING-311`,
`core/examples/organ_saving.rs`, `POSITIVE.md` §4.13. При `p = 0.02`, `k = 400` средняя жизнь: **146.8 / 158.3 /
162.7 / 164.5 / 161.7** для `alpha` 0 / 0.25 / 0.5 / **0.75** / 1.0 — оптимум **внутри**, «тратить всё» хуже.
Без засух, наоборот, `alpha = 1` даёт **856**, то есть выбор **возникает из режима**. **Впервые два назначения одного
вещества и середина лучше крайностей.** **Оговорка:** разброс при засухе всего **147–165** (12 %) — выбор
**формальный**; шаг свипа 0.25. **Предсказание:** сузить до 0.60…0.85 — максимум около 0.7, кривая плоская.

**Оптимум — плато 3 %, а не пик; «тратить всё» отстаёт на 2 % (цикл 280).** `FINDING-312`,
`core/examples/organ_saving.rs`, `POSITIVE.md` §4.13 исправлен. Свип 0.05 под смертельной засухой: **161.0 / 161.1 /
160.2 / 162.8 / 164.5 / 164.4 / 165.1 / 163.9** для `alpha` 0.55…0.90. **Разброс 3.0 %**, максимум при 0.85, а
`alpha = 1` (161.7) отстаёт на **2 %**. **Акцент 311-й исправлен:** выбор **мягкий**, а не острый. **Сила выбора
зависит от режима:** без засух разброс **7.2 раза** (жёсткий выбор), при смертельной засухе — **12 %** (мягкий).
**Предсказание:** при 1600 сидах плато расширится, если часть различий была шумом.

**У оптимума нет положения: вершина переезжает, плато сужается (цикл 281).** `FINDING-313`,
`core/examples/organ_saving.rs` (1600 сидов), `POSITIVE.md` §4.13 исправлен. При 400 сидах максимум при `alpha = 0.85`
(разброс 3.0 %), при **1600** — при **0.70** (разброс **1.7 %**). **Вершина — шум, а не точка.** **Утверждать можно:**
крайности хуже (146.8 и 161.7 против ~165), внутри полосы различий нет. **Утверждать нельзя:** что форма «выбирает
0.7» — это разные выборки, а не разные стратегии. **Выбор в модели — допуск, а не точка.** **Предсказание:** причина
полосы — выживание в худший момент; при редкой засухе (`p = 0.001`) выбор снова станет острым.

**Полосу создаёт катастрофа, а не метрика; линия «выбор» закрыта (цикл 282).** `FINDING-314`,
`docs/CHOICE-LINE-CLOSED.md`, `POSITIVE.md` §4.13 и `WHERE-WE-ARE.md` обновлены. Разбросы по режимам: **86 %** без
засух, **10 %** при смертельной (`p = 0.02`, `k = 400`), **82 %** при редкой (`p = 0.001`, `k = 50`) — полоса
существует **только** при катастрофе. **Механизм:** при смертельной засухе любая доля выше порога даёт **одинаковую
защиту** — защищает запас, достаточный для пережидания, а не средняя доля. **Линия закрыта:** четыре результата,
четыре ошибки — все про то, что я мерил **точки** там, где есть **полосы**. **Следующий потолок — третий: две
независимые величины** (без них возможен только бюджет, не обмен).

**Две независимые опасности: смесь сдвигается, но оптимум не всегда внутри (цикл 283).** `FINDING-315`,
`docs/DESIGN-two-quantities.md`, `core/examples/organ_mixture.rs`, `POSITIVE.md` §4.14. Целость защищает от распада,
запас от голода. Средняя жизнь при `beta` = 0.4 / 0.8 / 1.0: **242 / 655 / 661** при засухе 0.1 %; **236 / 402 /
214** при 0.5 %; **245 / 114 / 77** при 2 %. **Оптимум сдвигается 1.0 → 0.8 → 0.6** — доля, верная при одной
опасности, неверна при другой. **Но (a) опровергнуто:** при редкой засухе оптимум на **краю**; (c) провалилось по
моему же допуску (сдвиг 0.2 при шаге свипа 0.2). **Предсказание:** повторить при 1600 сидах — оптимумы останутся
1.0 / 0.8 / 0.6, если это гладкий оптимум, а не плато.

  Новую запись гейт создаёт только тогда, когда тело результата
  отличается; повторный замер возвращает существующий файл (`save()` в
  `checks/result.py`). Если после `run.sh all` в `results/` появился
  `??`-файл — значит, замер действительно новый.

  перепроверки дописывается в `reproduced_at` существующего результата, когда
  коммит отличается от того, где замер получен впервые. Их надо закоммитить
  вместе со следующим коммитом, а не искать причину в своих изменениях.

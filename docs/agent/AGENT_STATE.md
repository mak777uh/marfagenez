# AGENT_STATE.md — где проект сейчас

**Этот файл читает следующий агент первым.** Он отвечает на четыре вопроса:
где мы, что делаем сейчас, что дальше, чего не трогать. Он не дневник —
дневник это `AGENT_LOG.md`.

**Гейт:** этот файл обязан быть закоммичен **в том же коммите**, что
последнее изменение репозитория. Проверяет `run.sh agents` по истории Git,
а не по времени файла: после clone/checkout mtime врёт.

**Обновлять в конце каждого цикла**, перед `git commit`.

## §2 Статус задачи

Одна задача, не список. Формат: `не начата` / `в работе` / `заблокирована` /
`сделана`.

- **Задача:** `World` принимал параметры, при которых арифметика теряет смысл,
  и молчал об этом.
- **Статус:** `сделана` (2026-11-14).
- **Готово:**
  - **Дефект.** У `World` нет конструктора, поля `pub`, поэтому
    `maintenance_cost = NaN` писалось напрямую. Дальше арифметика не падала:
    `energy -= NaN` делал энергию `NaN`, `NaN.min(capacity)` возвращал
    `capacity` (потому что `f64::min` отбрасывает `NaN`-сторону), а проверка
    смерти `energy <= 0.0` становилась ложной. Организм **выживал вечно на
    полном баке**, ничего не платя, и нигде не было ошибки. Та же форма дыры
    у `income = NaN` (`resource.min(NaN)` возвращает `resource`, клетка
    вычерпывается целиком вместо темпа `income`) и у отрицательных стоимостей
    (выживание по построению).
  - **Исправление.** `World::validate() -> Result<(), String>` называет первое
    плохое поле. Вызывается в `Life::new` — единственной воронке всех
    конструкторов (`spawn_at`, `spawn_even`, `spawn`), поэтому обойти его
    нельзя. Поля остались `pub`: 26 мест `World { .. }` в `core/src` и
    `core/tests` — приватность сломала бы их ради того же эффекта.
  - **`validate` не смешан с `is_viable`.** Нежизнеспособный мир — это
    находка, а не битый вход: эксперимент может хотеть показать, что в нём
    никто не выживает. `is_viable` отвечает на вопрос модели, `validate` — на
    вопрос «это вообще числа».
  - Тест `core/tests/world_validation.rs`, 5 исходов: `default_world_is_valid`
    (silent), `nan_maintenance_is_rejected` (**fires**, и попутно доказывает
    бессмертие — без этого тест проверял бы только, что `validate` вернул
    ошибку, а не что ошибка была нужна), `life_refuses_invalid_world`,
    `each_bad_field_is_named` (6 мутаций: `income` NaN и −1, `maintenance`
    −0.5, `damage_rate` INF, `repair_cost` −1, `capacity` 0),
    `unviable_world_is_still_valid` (**specific** — ловит попытку слить
    `validate` с `is_viable`).
  - **Отказ виден снаружи.** Оба бинарника обрабатывают `None` от `spawn*`
    явно: `core/src/bin/trace.rs` печатает `cannot build the cycle` и
    `exit(1)`, `core/src/bin/occupancy.rs` падает на `.expect("population")`.
    Молчаливого «пустого популяции» нет — иначе `validate` вернул бы ровно тот
    класс дефекта, который закрывает.
- **Проверено:** `./run.sh test` — Rust 202 passed, 0 failed (197 + 5 новых).
- **Не сделано:** `checks/log_check.py` не написан; `docs/UNREPRODUCIBLE.md`
  не создан (A1, A5 блока A).

## §3 Текущий вопрос

**Что делает следующий раунд:** прочитать `docs/PLAN-NEXT.md` и начать блок A
(день 1 по §6: A1, A3, A5, D-1, D-2). Блок B ждёт решений владельца D1/D3/D4.
Блок C закрыт частично: C1 (`structure`) решён удалением, а не «сделать
независимой» — независимой организации в модели нет, и производное число,
изображавшее её, было хуже честного отсутствия.

**Почему именно это:** три аудита 2026-11-14 сошлись на одном: модель
отвечает на более узкий вопрос, чем заявлено, и самый дешёвый способ поднять
ценность — закрыть разрыв между заявлением и тем, что меряется, а не
расширять модель.

## §5 Чего не трогать

- **`results/`** — записи прогонов версионируются. Удалять только файлы,
  созданные текущей инъекцией, **по имени**, не глобом: `rm -f results/*/run-*.json`
  уже однажды снёс 19 закоммиченных записей.
- **Трассы** (`trace-*.json`, 66–177 MB) — артефакты, в `.gitignore`. Семь
  трасс сломали push 2026-11-13 (GH001, >100 MB).
- **`docs/FINDING-*.md`** — не переписывать задним числом. Новая находка —
  новый файл; старая остаётся как была, даже если неверна.
- **Windows-клон** — не править (см. §1).

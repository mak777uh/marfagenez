## 2. «Векторный» износ фактически скалярный

- exp_wear_vec.rs хранит один скалярный wear; Form::Vector => keff(profile) * wear. Профиль компонентов сводится к одному коэффициенту.
- Равенства mB==mC, mD==mE, c2==uniform==scalar — алгебраические вырождения конструкции (одинаковый keff), а не проявления компонентной динамики износа.
- Поэтому P2 «структурная память подтверждена» следует читать как: чувствительность смертности к структуре профиля через keff подтверждена; компонентная динамика износа этим экспериментом не тестировалась.

## 3. Оценки контрастов

- Прямые per-seed средние разности: 21.9167 и 5.8333.
- Bootstrap ресамплирует пары внутри фиксированных seeds, но не seeds как кластеры; CI описывает прежде всего within-seed variability. Это не арифметическая ошибка и не меняет зарегистрированный failed; estimator должен быть явно описан при цитировании.

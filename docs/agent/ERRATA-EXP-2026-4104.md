# Errata: EXP-2026-4104 (A-P5, нулевая модель D-Q9)

## 1. Статус исхода: passed условный

- Зарегистрированный outcome=passed верен по amended analyzer 1.0.1, но НЕ является чистым подтверждением исходной предрегистрации.
- Предрегистрированная метрика dfdt_mean10 требовала строгого убывания по frac. Фактические значения: frac=1.0 → 0.077579; frac=0.5 → 0.082797; frac=1/3 → 0.066667. Первая пара (1.0 против 0.5) нарушает убывание.
- Анализатор 1.0.1 ПОСЛЕ прогона исключил dfdt_mean10 из monotonicity-блока и заменил её на v_first = frac·R0. Замена объяснена артефактом раннего завершения ремонта (window-mean искажается финишем), но она меняет смысл исходного критерия.
- v_first в этой модели почти прямо задан определением capacity и не является независимой проверкой формы всей кривой восстановления.

# AGENT_LOG.md — журнал циклов

**Одна запись на цикл.** Цикл — это «нашёл вопрос → арифметика → прогон →
числа → запись → коммит». Запись пишется **в конце цикла**, перед коммитом.

Правило: если запись не изменила следующее действие — это не запись, а
пересказ. Пересказ не нужен, он уже есть в `git log`.

Формат записи — ровно шесть полей. Все обязательны.

---

## Шаблон

```
### Цикл N — <дата> — <коммит>
- **Вопрос:**
- **Арифметика:** (число до прогона)
- **Что сделано:**
- **Числа:** (что вернул прогон, дословно)
- **Состояние на конец цикла:** (где именно оборвалось — файл:строка,
  что запущено, что не запущено)
- **Что не сработало:** (обязательно; «ничего» — подозрительный ответ)
```

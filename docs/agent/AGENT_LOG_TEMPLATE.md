# AGENT_LOG_TEMPLATE.md — формат записи цикла

Вынесено из `docs/agent/AGENT_LOG.md` 2026-11-21. Причина: шаблон в шапке журнала содержал код-блок, и
однажды незакрытая тройная обратная кавычка отключила разбор всего журнала — `log_check` разобрал **ноль** циклов, а пустой
список прошёл правило «1..n» (`FINDING-331`). Шаблон рядом с записями — это мина под ними.

## Формат

**Одна запись на цикл.** Цикл — это «нашёл вопрос → арифметика → прогон → числа → запись → коммит». Запись
пишется **в конце цикла**, перед коммитом.

Правило: если запись не изменила следующее действие — это не запись, а пересказ. Пересказ не нужен, он уже
есть в `git log`.

Ровно шесть полей, все обязательны:

- **Вопрос:** что проверяли и почему именно это.
- **Арифметика:** что должно получиться при верной и при неверной гипотезе.
- **Что сделано:** правки, команды, инъекции.
- **Числа:** до и после, с командой.
- **Состояние на конец цикла:** что закоммичено, что осталось, что не сработало.
- **Что не сработало:** обязательно, если было.

## Пример

### Цикл 1 — 2026-11-14 — `84fd66a`

- **Вопрос:** `run.sh all` возвращает 0 потому, что проверки прошли, или потому, что код возврата теряется?
- **Арифметика:** если код теряется, подложенный дефект не меняет вывода, кроме собственной печати.
- **Что сделано:** четыре инъекции в гейт; `run.sh` переписан по правилу «вывод фильтруется, код берётся от
  проверки».
- **Числа:** до правки И1 → `sorry: 1`, `ВСЁ ЗЕЛЁНОЕ`, rc=0; после → `FAIL: 1 незакрытых sorry`.
- **Состояние:** патчи незакоммичены, `all` красный из-за отсутствия `AGENT_STATE.md`.
- **Что не сработало:** И3 не воспроизвелась, пока PATH не перезаписан целиком.

Полная запись цикла 1 — в журнале.

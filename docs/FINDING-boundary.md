# Находка: принцип, который нельзя нарушить незаметно

**Дата:** 2026-11-11
**Проект:** МАРФАГЕНЕЗ++
**Где:** `core/src/boundary.rs`, `core/src/boundary_probes.rs`

---

## Что проверяли

Манифест говорит: **среда не измеряет, не направляет**. Проверил, соблюдается ли это в коде.

## Что нашёл

Принцип соблюдён — но **слабо**:

```
нет score/evaluate/compare/suggest/hint/goal/rank
```

Это **отсутствие**, а не гарантия. Кто угодно может добавить `score()`, и ничто не возразит.

## Три слоя защиты

Сделал третий слой:

| слой | как | что останавливает |
|---|---|---|
| **отсутствие** | нет `score()`, нет `suggest()` | очевидное нарушение |
| **приватность** | поля `Child` приватные | чтение ребёнка снаружи среды |
| **именование** | `OutsideExperiment` — отдельный тип | запись обратно без признания |

Третий слой — новый. Он **не запрещает** эксперимент. Он заставляет эксперимент **назвать себя**.

```rust
let experiment = OutsideExperiment::declare();
experiment.step_and_act(&mut medium, &mut child, |p| vec![p[0] + 0.5]);
```

Тест, который это использует, **не может притворяться**, что тестирует среду.

## Полный список того, что среда может

```rust
pub enum MediumAction {
    DriftAndNoise,   // двигает ребёнка его собственным дрейфом и шумом
    Fold,            // возвращает ребёнка в комнату
}
```

**Ровно два действия.** Оба **слепые**: не смотрят, где ребёнок, чтобы решить, что с ним делать.

Если кто-то добавит третье — тест `probe_the_absence_is_real` упадёт.

## Пробы: гейт, который может провалиться

| проба | что подложено | что показывает |
|---|---|---|
| `probe_a_measuring_medium_is_visible` | среда, отвечающая популяции | она **видна** в результате |
| `probe_the_absence_is_real` | предположение, что есть `score()` | его нет — список из двух действий |
| `probe_outside_experiment_is_named` | действие на ребёнка | тип говорит «снаружи» |

Все три проходят. Но главное — **первая может провалиться**: если измеряющая среда даст тот же разброс, что молчащая, тест упадёт.

Проверено: молчащая даёт закон `B/√3`, измеряющая — нет. **Нарушение видно.**

## Формула

$$\text{среда} = \{\text{DriftAndNoise}, \text{Fold}\}$$

Два действия. Оба слепые. Всё остальное — снаружи, с именем.

## Для ребёнка

> **Среда, которая может только двигать и держать границу, не может оценить. Не потому что ей запрещено — потому что у неё нет органа для этого.**

Это сильнее, чем «среда не должна измерять». Это «среда **не может** измерять» — в буквальном смысле, как нет руки у камня.

## Честная оговорка

`OutsideExperiment` — это **маркер**, не защита. Он не мешает писать эксперименты, нарушающие принцип. Он делает их **видимыми при чтении кода**.

Настоящая защита — то, что `Medium` не имеет доступа к `Child` кроме `step()`. Но `set_position` публичный, и через него можно писать обратно. Это лазейка, названная честно.

# Аудит единиц в формулах карты знаний (F-001, F-003, F-029)

**Дата:** 25.11.2026. **Основание:** записи формул в `docs/ELEPHANT-LITERATURE.md` (строки F-001/F-003/F-029),
таблица `UNITS` в `kg/migrate.py`, и независимая числовая проверка (`check_units.py` в корне репозитория,
результаты ниже приведены дословно).

Правило проекта: у каждой величины в формуле есть единица, и если `units` в узле говорит `1`, а из
уравнения следует `1/с` — это дефект, а не мелочь.

## 1. F-001 — кумулятивная опасность

Запись:

```
H(T) = ∫₀ᵀ μ(t) dt,     μ(t) = μ₀ + λδt,     μ₀T + (λδ/2)T² = 1
```

**Требование размерности.** `μ(t)` и `μ₀` — `1/с`; член `λδt` должен давать `1/с`, значит
`[λδ] = 1/с²`.

**Было в `UNITS`:** `lambda: "1"`, `delta: "1"` → `λδt` безразмерно, складывается с `1/с`. **Неверно.**

**Верно:** `lambda: "1/с"`, `delta: "1/с"` (тогда `λδ = 1/с²`); либо ввести `α = λδ` с единицей `1/с²`
и записывать `μ(t) = μ₀ + αt`.

**Числовая проверка** (μ₀ = 0,01; λ = δ = 0,001):

```
T = 99.50 с; H(T) = 1.000000
μ₀·T = 0.01·99.5      -> безразмерно (1)
λδ·T² = 0.001·0.001·9901.2 -> безразмерно (1)
```

**Отдельный вывод (не дефект, а свойство):** `λ` и `δ` входят **только произведением**. Значит по данным
о смертности их нельзя разделить — идентифицируемо лишь `α = λδ`. Это стоит записать явно: иначе
появится соблазн «измерить λ и δ по отдельности» из одной и той же кривой.

## 2. F-003 — корневой закон и граница режимов

Запись:

```
λD² + μ₀D = δ/(1 − h),     D* = (−μ₀ + √(μ₀² + 4λδ/(1−h))) / (2λ)
```

**Единицы.** `D` и `h` безразмерны. Правая часть должна быть `1/с`, значит `δ: "1/с"`.
Тогда `λD²` тоже `1/с` ⇒ `lambda: "1/с"`.

**Было:** `lambda: "1"` — **неверно** (при таком значении `λD²` безразмерно).
**Верно:** `lambda: "1/с"`, `delta: "1/с"`, `mu0: "1/с"`.

**Граница режимов.** Прежнее условие `h < 1 − δ/(μ₀D)` содержало **неизвестное** равновесие `D`, то есть
не было условием. Правильное условие — через безразмерное число:

```
η = λδ / (μ₀²(1 − h))        (безразмерно: (1/с²) / ((1/с²)·1))
линейный режим:  η ≪ 1   →  D* ≈ δ/(μ₀(1−h))
корневой режим:  η ≫ 1   →  D* ≈ √(δ/(λ(1−h)))   (показатель −1/2)
```

Порог по `h` (если нужен именно он) получается из `η = 1`:

```
h* = 1 − λδ/(2μ₀²)   — точка, где члены λD² и μ₀D равны на равновесии (D = μ₀/λ)
```

**Числовая проверка границы** (равенство членов в `h*`, разница левой и правой частей):

```
μ₀=1, λ=1, δ=1: h*=0.5000; λD²+μ₀D=2.000000; δ/(1−h*)=2.000000; разница 0.00e+00
μ₀=0.5, λ=1, δ=1: h*=-1.0000; 0.500000 = 0.500000; разница 0.00e+00
μ₀=1, λ=2, δ=1: h*=0.0000;  1.000000 = 1.000000; разница 0.00e+00
```

**Важное следствие для наших чисел.** При μ₀ = λ = δ = 1 наши точки `h = 0.90 / 0.95 / 0.98 / 0.99`
дают `η = 10 / 20 / 50 / 100`, то есть **все четыре уже в корневом режиме**, а не «только с h ≥ 0.97».
Значит запись «корневой режим — только при h ≥ 0,97» верна лишь для конкретных μ₀, λ, δ и должна быть
переписана через `η`. Отношение `D*/D_lin` при этих точках: 0,270 / 0,200 / 0,132 / 0,095 — то есть
линейная аппроксимация завышает равновесие в 4–10 раз.

## 3. F-029 — нормальные формы и размытие перехода

Запись:

```
ẋ = r + x²,   ẋ = rx − x²,   ẋ = rx − x³,   Δ ~ ε^(2/3)
```

**Единицы.** `ẋ` имеет `1/с`; `r` имеет `1/с`; `x` безразмерен. Тогда коэффициенты при `x²`/`x³` тоже
должны нести `1/с`:

```
ẋ = r + a·x²,   ẋ = r·x − b·x²,   ẋ = r·x − c·x³,     a, b, c — 1/с
```

Без этих коэффициентов равенства размерно бессмысленны (складывается `1/с` и `1`). В `UNITS` у F-029
не было ни `a`, ни `b`, ни `c`; `Delta` был объявлен как «ширина перехода, в единицах x» — это и есть
главная ошибка (см. ниже).

**Где живёт показатель 2/3.** Числовая проверка для несовершенной вилки `ẋ = r·x − x³ + ε`:

```
eps=0.1     r_fold=0.407163     r_fold/eps^(2/3)=1.8899
eps=0.01    r_fold=0.087721     r_fold/eps^(2/3)=1.8899
eps=0.001   r_fold=0.018899     r_fold/eps^(2/3)=1.8899
eps=1e-06   r_fold=0.000189     r_fold/eps^(2/3)=1.8899
ожидание 3/2^(2/3) = 1.88988157484231
```

То есть `Δ_r = 3·2^(−2/3)·ε^(2/3)` — **ширина по параметру `r`**, а `r` имеет единицы `1/время`.
Сдвиг по состоянию при этом масштабируется как `ε^(1/3)`: `x_fold = (ε/2)^(1/3)`.

Для статического несовершенства `r + x² + ε = 0` сдвиг по `r` **линеен** по `ε`, а по `x` — `√ε`:

```
eps=0.1: сдвиг x = sqrt(eps) = 0.316228
eps=0.01: 0.100000
eps=0.001: 0.031623
```

**Вывод.** Запись «Δ ~ ε^(2/3) в единицах x» неверна дважды: и по оси (это ось параметра, `1/время`),
и по общности (для статического сдвига показатели другие: 1 по `r`, 1/2 по `x`). Показатель 2/3
принадлежит **динамике прохождения складки** (ширина по параметру), а не «размытию состояния».

## 4. F-002 — порог доли удержания (25.11.2026)

Запись:

```
D_{n+1} = h·D_n + δ·T          рекуррентность повреждения по поколениям
D*      = δ·T / (1 − h)        конечное плато при h < 1
```

**Единицы.** `D` и `h` безразмерны; `T` — время поколения в секундах; произведение `δ·T` обязано быть
безразмерным, значит `δ: 1/с`. Было: единицы не объявлены вовсе. Стало:
`{D: 1, h: 1, delta: 1/с, T: с, D_star: 1}`.

**Свойство, как у `F-001`:** `δ` и `T` входят **только произведением**. По данным о накоплении их нельзя
разделить — наблюдаемо лишь `δ·T` (повреждение за поколение).

**Проверка записанных «плато».** В записи стоят числа 2,02 / 3,28 / 5,80 / 8,68 для `h = 0,90 / 0,95 /
0,98 / 0,99`. Если это неподвижные точки `δ·T/(1−h)`, то `δ·T` должно быть одним и тем же:

| h | записано | `δ·T`, требуемое формулой | предел при `δ·T = 0,2` |
|---|---|---|---|
| 0,90 | 2,02 | 0,202 | 2,00 |
| 0,95 | 3,28 | 0,164 | 4,00 |
| 0,98 | 5,80 | 0,116 | 10,00 |
| 0,99 | 8,68 | 0,0868 | 20,00 |

Требуемое `δ·T` падает в 2,3 раза — значит числа **не являются неподвижными точками**. Они совпадают
с конечным горизонтом `D_n = δ·T·(1 − h^n)/(1 − h)` при `δ·T = 0,2` и

```
h = 0,95: n ≈ 33   (D_n = 3,264)
h = 0,98: n ≈ 43   (D_n = 5,805)
h = 0,99: n ≈ 57   (D_n = 8,722)
```

То есть записанные значения — **снимки на разных горизонтах**, а не плато; пределы при том же `δ·T`
равны 2 / 4 / 10 / 20. Горизонт в записи не указан, поэтому числа не воспроизводимы: без `n` их нельзя
получить ни из формулы, ни из прогонов.

**Исправление записи:** либо писать пределы (2 / 4 / 10 / 20 при `δ·T = 0,2`), либо указывать горизонт
рядом с каждым числом. Первое предпочтительнее: предел не зависит от того, сколько поколений считали.

## 5. F-004 и F-005 — обмен и доля поддержания (25.11.2026)

### F-005 — тривиально

```
энергия = κ·E (поддержание сомы) + (1−κ)·E (рост и размножение)
```

Единицы: `E` — Дж, `κ` — безразмерная доля, «энергия» — Дж. Было: не объявлены.
Стало: `{энергия: Дж, E: Дж, kappa: 1}`. Проверять нечего: обе ветви складываются в `E`.

### F-004 — размерно **недоопределена**, пока не объявлено, что такое `n` и `p`

```
приход = c_y·σ·p·f̄
расход = f₀ + μ·n + κ·n²/p
жива ⟺ приход ≥ расход
```

Первое требование: все три члена расхода имеют одну размерность, и она равна размерности прихода.
Второе: `n` и `p` должны быть объявлены, иначе `μ·n` и `κ·n²/p` не типизируются однозначно.
Два непротиворечивых варианта:

| что такое `n` | `p` | `f₀` | `μ` | `κ` | `c_y` |
|---|---|---|---|---|---|
| масса, г | доля, 1 | Дж/с | Дж/(с·г) | Дж·с/г² | Дж/г |
| число особей, шт | число, шт | Дж/с | Дж/(с·шт) | Дж·с/шт² | Дж/шт |

Оба варианта согласованы, то есть **уравнение само по себе не выбирает интерпретацию**. Это дефект
записи, а не формулы: нужно объявить, что `n` — масса (как в DEB, `L-012`), а `p` — безразмерная доля.

**Принятая запись** (каноническая, по DEB): `n` — г, `p` — 1; тогда `μ: Дж/(с·г)` и `κ: Дж·с/г²`.
Записано в `kg/migrate.py`.

**Что остаётся сделать:** переписать саму запись `F-004` в корпусе, добавив строку «n — масса, p —
безразмерная доля». Сейчас это видно только в таблице единиц.

## 6. F-007 и F-017 — порог ошибок Эйгена (25.11.2026)

Две записи об одном явлении:

```
F-007   σ · q^ν = 1        граница удержания информации;  L_max ≈ ln(σ)/(1 − q)
F-017   σ · q^ν > 1        порог;                        μ_c = ln σ / ν
```

**Единицы — все безразмерные:** `σ` — превосходство (отношение приспособленностей), `q` — вероятность
правильного копирования на основание, `ν` — длина генома в основаниях (счётная), `L_max` — та же длина.
Было: не объявлены. Стало: `{sigma: 1, q: 1, nu: 1, L_max: 1}` и `{sigma: 1, q: 1, nu: 1, mu_c: 1}`.

**Согласованность двух форм** (`tools/eigen_threshold.py`): из `σ·q^ν = 1` следует `ν = ln σ / (−ln q)`,
а при малом `1 − q` это `≈ ln σ/(1 − q)`. Значит `L_max` — **не отдельная величина, а сам `ν`**, и обе
записи дают одно число:

| σ | q | `ν = lnσ/(−ln q)` | `lnσ/(1 − q)` | разница |
|---|---|---|---|---|
| 2 | 0,999 | 692,8 | 693,1 | 0,1 % |
| 2 | 0,99 | 69,0 | 69,3 | 0,5 % |
| 10 | 0,9999 | 23 024,7 | 23 025,9 | 0,0 % |

**Пределы.** `q → 1` ⇒ `L_max → ∞` (идеальная репликация удерживает любой геном); `σ → 1` ⇒ `L_max → 0`
(нет превосходства — нечего удерживать); `σ·q^ν < 1` ⇒ порог нарушен, ошибка катастрофы.

**Числа при σ = 2:** `q = 0,9999` → 6931 основание; `0,999` → 693; `0,99` → 69; `0,97` → 23. То есть
«точность 99 % на основание» удерживает геном короче ~70 оснований.

**Опровергающее условие:** система, удерживающая информацию при `σ·q^ν < 1` (пространственная структура,
рекомбинация, репарация), требует поправки — это и есть известное ограничение модели.

**Что это НЕ доказывает:** что реальные геномы живут на этом пороге (у них есть репарация, которой в
формуле нет) и что `σ` измеримо в природе как отношение приспособленностей.

### Дополнение 25.11.2026: `μ_c` — на основание, а не на поколение

`F-017` записывает `μ_c = ln σ / ν`. Проверка размерности и смысла (`tools/eigen_threshold.py`):
в пороге `q^ν·σ = 1` величина `q` — точность **на основание**, значит

```
(1 − q)·ν < ln σ     ⇒     μ_c = ln σ / ν  — доля ошибок НА ОСНОВАНИЕ (безразмерна)
ν·μ_c = ln σ         — доля ошибок НА ГЕНОМ за репликацию (тоже безразмерна, но другая)
```

Числа: при `σ = 2`, `ν = 1000` → `μ_c = 6,93·10⁻⁴` на основание; на геном `= 0,693 = ln 2`. При `ν = 100`
→ `μ_c = 6,93·10⁻³`, на геном по-прежнему `0,693`. То есть **поколенческая величина от длины генома не
зависит**, а `μ_c` зависит.

**Почему это важно.** Смешать «на основание» и «на поколение» — ровно тот дефект, что в `F-002`, где
«за поколение» оказалось единственной общей единицей у несопоставимых величин. Здесь формулы корректны,
но запись `μ_c` не говорит, к чему она нормирована; теперь говорит.

**Что это НЕ доказывает:** что `μ_c` применима к организмам с репарацией (модель без неё) и что
`σ` измеримо в природе.

## 7. F-006 и F-019 — критерий Chao `Πλ ≤ 1/6` (25.11.2026)

Две записи об одном критерии: `F-006` (складка и универсальный масштаб) и `F-019` (равновесие при
симметричном делении). Записано: `Π` — время повреждения (с), `λ` — темп повреждения (1/с),
`a` — асимметрия (1), `Πλ` — безразмерно.

**Что проверено (`tools/chao_threshold.py`).**

| что | результат |
|---|---|
| размерность | `Π·λ` безразмерно, порог `1/6` тоже — согласовано |
| предел `λ → 0` | `Πλ → 0 < 1/6` — равновесие есть при любом `Π` |
| предел `Π → ∞` | `Πλ → ∞ > 1/6` — равновесия нет |
| граница | это **линия** `λ_crit = (1/6)/Π`, а не число |
| пример из карты | `Πλ = 0,10 ≤ 0,167` — равновесие есть, сходится |

**Что НЕ проверено:** зависимость порога от асимметрии `a`. В записи сказано, что `a` сдвигает порог,
но формула сдвига не выписана, и константа `1/6` здесь не выводится — она взята из модели Chao.
Выводить её из наших данных было бы подгонкой.

**Почему «линия, а не число» важно:** при `Π = 0,6 с` критический темп `0,278 1/с`, при `Π = 6 с` —
`0,028 1/с`, то есть в десять раз меньше. Запоминать «1/6» как число и переносить его между системами
нельзя: это произведение, а не порог по одной оси.

**Опровергающее условие:** равновесие при `Πλ > 1/6` в системе без асимметричного деления и без
выброса повреждения при делении.

## 8. F-014 — порог полосы `δ_c ≈ σ_g·√(2 ln N)` (25.11.2026)

Запись: `δ_c ≈ σ_g·√(2 ln N)`, при `σ_g ≈ 0,1` и `N ≈ 10³` даёт `0,37` — «середина окна 0,2…0,5».
Проверка: `tools/noise_threshold.py`.

**Единицы.** `σ_g` — стандартное отклонение шума в долях (безразмерно), `N` — число независимых шумов
(счёт), `δ_c` — та же размерность, что `σ_g`. Записано: `{delta_c: 1, sigma_g: 1, N: 1}`.

**Арифметика сходится:** `0,1·√(2 ln 1000) = 0,3717`.

**Но «порог» здесь — не то слово.** `σ_g·√(2 ln N)` — это **типичный максимум** `N` гауссовых шумов.
Вероятность, что максимум его превысит, по построению ≈ `1 − e⁻¹ ≈ 0,63`; медиана приходится примерно
на это же значение. То есть `0,37` — не редкое событие, а «обычный самый большой выброс».

Порог заданной редкости считается иначе — `δ_p = σ_g·√(2 ln(N/p))`:

| p (вероятность превышения) | `δ_p` | во сколько раз выше 0,37 |
|---|---|---|
| 0,5 | 0,3899 | 1,05 |
| 0,1 | 0,4292 | 1,15 |
| 0,05 | 0,4451 | 1,20 |
| 0,01 | 0,4799 | 1,29 |
| 0,001 | **0,5257** | 1,41 |

**Следствие для окна 0,2…0,5.** При `N = 10³` и `σ_g = 0,1`:
- «обычный максимум» `0,37` — внутри окна;
- порог 5 % `0,445` — тоже внутри;
- порог 0,1 % `0,526` — **уже вне окна**.

То есть окно и порог не независимы: если требовать редкое событие, окно должно быть шире.

**Пределы.** `N → 1` ⇒ `δ_c → 0`; `N → ∞` ⇒ `δ_c → ∞`, но как `√(2 ln N)`: при `σ_g = 0,1` миллион шумов
дают всего `0,526`.

**Опровергающее условие:** если наблюдаемая граница полосы соответствует превышению реже 0,1 % при
`N ≈ 10³`, формула с `σ_g = 0,1` её не описывает — нужен либо больший `σ_g`, либо другая статистика шума.

## 9. F-020 — Гомпертц, Макегам и плато (25.11.2026)

```
Гомпертц:   μ(x) = R · e^(αx)        удвоение примерно каждые 8 лет взрослой жизни
Макегам:    μ(x) = μ₀ + R · e^(αx)
Плато:      при исчерпании избыточности μ выходит на уровень архитектуры
```

**Единицы.** `μ`, `R`, `μ₀` — интенсивность смертности, 1/год; `α` — 1/год; `α·x` безразмерно при `x` в
годах; `t_d = ln 2/α` — годы. Записано: `{mu: 1/год, R: 1/год, mu0: 1/год, alpha: 1/год, x: год,
t_d: год}`.

**Арифметика удвоения.** `t_d = 8 лет` ⇒ `α = ln 2/8 = 0,0866 1/год`; при 7 годах `0,0990`, при 9 —
`0,0770`. Значит «примерно 8 лет» — это `α ≈ 0,087`, а не свободный параметр.

**Согласованность без подгонки каждой точки** (`tools/gompertz_check.py`). Пусть `μ(40) = 0,002 1/год`
(типичное человеческое значение); тогда `R = 6,25·10⁻⁵ 1/год` и

| возраст | `μ` | вероятность умереть за год |
|---|---|---|
| 60 | 0,011 | 0,011 |
| 80 | 0,064 | 0,062 |
| 100 | 0,362 | 0,304 |
| 110 | 0,861 | 0,577 |

Ориентиры `μ(80) ≈ 0,06` и `μ(100) ≈ 0,3–0,5` попадают в эти значения **без отдельной подгонки**.

**Где модель ломается — и это проверяемо.** Гомпертц монотонно растёт: **плато он не даёт по форме**.
Запись объясняет плато сменой механизма (исчерпание избыточности), а не свойством формулы. Опровергающее
условие: Гомпертц предсказывает рост `μ(110)/μ(100) = e^(α·10) = 2,38`; данные о долгожителях дают рост,
близкий к 1.

**Что это НЕ доказывает.** Что реальная смертность человека следует Гомпертцу (это подгонка двух
параметров на одном числе); что плато объясняется избыточностью (это гипотеза записи); и что `α`
одинаков для разных видов — у животных он различается в разы.

### Дополнение 25.11.2026: `μ₀` и `α` не различимы по двум точкам

Вопрос: нужен ли Макегаму параметр `μ₀`, или он лишний? Ответ зависит от того, различимы ли параметры.

Фиксируем две точки — `μ(40) = 0,002` и `μ(80) = 0,064` — и решаем, какие `(μ₀, α, R)` их описывают:

| `μ₀`, 1/год | `α`, 1/год | `R` | `μ(100)` | `μ(110)` |
|---|---|---|---|---|
| 0 | 0,0866 | 6,25·10⁻⁵ | 0,362 | 0,861 |
| 0,0005 | 0,0936 | 3,54·10⁻⁵ | 0,414 | 1,054 |
| 0,001 | 0,1036 | 1,59·10⁻⁵ | 0,501 | **1,410** |
| ≥ 0,002 | — | — | — | модель невозможна: `μ₀` не меньше `μ(40)` |

**Вывод:** все три строки описывают две точки **одинаково точно** — `μ₀` и `α` компенсируют друг друга.
Различить их можно только по третьей точке, и то слабо: `μ(100)` для крайних вариантов отличается в
1,4 раза, а «ориентир» `0,3–0,5` покрывает весь диапазон.

**Следствие для записи:** утверждение «Макегам = начальная смертность + возрастная компонента» верно как
форма записи, но **не как различимая гипотеза** о данных из двух точек. Чтобы `μ₀` был оправдан, нужна
либо точка в молодом возрасте (где `μ₀` доминирует), либо больше данных, либо явное указание, что `μ₀`
фиксирован извне.

**Что это НЕ доказывает:** что `μ₀ = 0` в реальности; и что по трём точкам параметры различимы
устойчиво — это зависит от точности данных, которой мы не имеем.

## 10. Различимость параметров — общее правило (25.11.2026)

Пять раз в этой линии обнаруживалось одно и то же: параметры входят в формулу **только произведением**,
и данные различают комбинацию, а не множители.

| формула | комбинация | следствие |
|---|---|---|
| `F-001` | `alpha = lambda·delta` | наблюдаемо только `alpha` (`FINDING-297`) |
| `F-002` | `delta·T` | различимо только повреждение за поколение (`FINDING-343`) |
| `F-017` | `q^nu` | различима точность в степени длины генома |
| `F-006`, `F-019` | `Pi·lambda` | порог задан произведением |
| `F-020` | `μ₀` и `α` | по двум точкам не различимы (компенсируют друг друга) |

**Правило.** Если в записи параметры входят только произведением, то:
- в тексте надо называть наблюдаемую комбинацию, а не «параметр»: «повреждение за поколение», а не
  «темп δ и время T»;
- проверка не может быть точечной: нельзя «измерить δ», можно только δ·T;
- два разных набора множителей с одинаковым произведением — **одна и та же формула**, и выбирать между
  ними по данным нельзя.

**Инструмент.** `tools/identifiability.py` механически ищет произведения в латексе всех формул и печатает
кандидатов; результат — `docs/IDENTIFIABILITY.md`. Список для чтения глазами: регексп по латексу даёт
ложные срабатывания (обрывки слов), поэтому кандидат — не приговор.

**Что это НЕ доказывает:** что параметр, вошедший в произведение, не имеет физического смысла; что
комбинацию нельзя расщепить другим экспериментом (часто можно — меняя `T` независимо); что найденные
автоматически кандидаты действительно произведения.

## 12. Ещё три формулы: `F-012`, `F-016`, `F-011` (25.11.2026)

| формула | единицы | почему так |
|---|---|---|
| `F-012` (Прайс) | `z` и `Delta_z` в единицах признака, `w` и `w_bar` безразмерны, `Cov` в единицах признака | `Δz̄ = Cov(w,z)/w̄ + E[w·Δz]/w̄`: приспособленность безразмерна, поэтому обе дроби наследуют единицы признака |
| `F-016` (цена страховки) | `lambda` 1/с, `sigma2` 1/с² | `log λ_s ≈ log λ̄ − σ²/(2λ̄²)`: `σ²/λ̄²` безразмерно, значит логарифмы сравнимы — иначе запись не имеет смысла |
| `F-011` (эко-подпись) | все три величины безразмерны | `ΔR = R_original − R_modified` — разность откликов, долей/индексов |

**Долг по единицам: 10 → 7 из 31.**

**Что осталось без единиц (7):** `F-008` (ядро выживания — множества, а не величины), `F-009` (структурное
замыкание — логическое условие), `F-010` (RAF — множества), `F-013` (цепь рождения–смерти — вероятности,
запись через `π(i)`), `F-026` (зерно среды — качественное различие стратегий), `F-030` (метрики — несколько
разных величин в одной записи), `F-031` (ограничение из графа — множество конфигураций).

**Честно:** у шести из семи единиц нет не потому, что забыли, а потому, что **величины не числовые** —
множества, логические условия, качественные стратегии. Записывать им «1» было бы формальностью. Исключение
— `F-013`: там вероятности и `rho`, единицы могли бы быть, но запись задана для цепей с шагом ±1, где
величины безразмерны по построению; это надо оформить отдельно, а не выдумывать.

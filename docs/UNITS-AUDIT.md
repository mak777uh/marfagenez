# Аудит единиц в формулах карты знаний (F-001, F-003, F-029)

**Дата:** 25.11.2026. **Основание:** записи формул в `docs/ELEPHANT-LITERATURE.md` (строки F-001/F-003/F-029),
таблица `UNITS` в `kg/migrate.py`, и независимая числовая проверка (`check_units.py` в корне репозитория,
результаты ниже приведены дословно).

Правило проекта: у каждой величины в формуле есть единица, и если `units` в узле говорит `1`, а из
уравнения следует `1/с` — это дефект, а не мелочь.

---

## 1. F-001 — кумулятивная опасность

Запись:

```
H(T) = ∫₀ᵀ μ(t) dt,     μ(t) = μ₀ + λδt,     μ₀T + (λδ/2)T² = 1
```

**Требование размерности.** `μ(t)` и `μ₀` — `1/с`; член `λδt` должен давать `1/с`, значит
`[λδ] = 1/с²`.

**Было в `UNITS`:** `lambda: "1"`, `delta: "1"` → `λδt` безразмерно, складывается с `1/с`. **Неверно.**

**Верно:** `lambda: "1/с"`, `delta: "1/с"` (тогда `λδ = 1/с²`); либо ввести `α = λδ` с единицей `1/с²`
и записывать `μ(t) = μ₀ + αt`.

**Числовая проверка** (μ₀ = 0,01; λ = δ = 0,001):

```
T = 99.50 с; H(T) = 1.000000
μ₀·T = 0.01·99.5      -> безразмерно (1)
λδ·T² = 0.001·0.001·9901.2 -> безразмерно (1)
```

**Отдельный вывод (не дефект, а свойство):** `λ` и `δ` входят **только произведением**. Значит по данным
о смертности их нельзя разделить — идентифицируемо лишь `α = λδ`. Это стоит записать явно: иначе
появится соблазн «измерить λ и δ по отдельности» из одной и той же кривой.

## 2. F-003 — корневой закон и граница режимов

Запись:

```
λD² + μ₀D = δ/(1 − h),     D* = (−μ₀ + √(μ₀² + 4λδ/(1−h))) / (2λ)
```

**Единицы.** `D` и `h` безразмерны. Правая часть должна быть `1/с`, значит `δ: "1/с"`.
Тогда `λD²` тоже `1/с` ⇒ `lambda: "1/с"`.

**Было:** `lambda: "1"` — **неверно** (при таком значении `λD²` безразмерно).
**Верно:** `lambda: "1/с"`, `delta: "1/с"`, `mu0: "1/с"`.

**Граница режимов.** Прежнее условие `h < 1 − δ/(μ₀D)` содержало **неизвестное** равновесие `D`, то есть
не было условием. Правильное условие — через безразмерное число:

```
η = λδ / (μ₀²(1 − h))        (безразмерно: (1/с²) / ((1/с²)·1))
линейный режим:  η ≪ 1   →  D* ≈ δ/(μ₀(1−h))
корневой режим:  η ≫ 1   →  D* ≈ √(δ/(λ(1−h)))   (показатель −1/2)
```

Порог по `h` (если нужен именно он) получается из `η = 1`:

```
h* = 1 − λδ/(2μ₀²)   — точка, где члены λD² и μ₀D равны на равновесии (D = μ₀/λ)
```

**Числовая проверка границы** (равенство членов в `h*`, разница левой и правой частей):

```
μ₀=1, λ=1, δ=1: h*=0.5000; λD²+μ₀D=2.000000; δ/(1−h*)=2.000000; разница 0.00e+00
μ₀=0.5, λ=1, δ=1: h*=-1.0000; 0.500000 = 0.500000; разница 0.00e+00
μ₀=1, λ=2, δ=1: h*=0.0000;  1.000000 = 1.000000; разница 0.00e+00
```

**Важное следствие для наших чисел.** При μ₀ = λ = δ = 1 наши точки `h = 0.90 / 0.95 / 0.98 / 0.99`
дают `η = 10 / 20 / 50 / 100`, то есть **все четыре уже в корневом режиме**, а не «только с h ≥ 0.97».
Значит запись «корневой режим — только при h ≥ 0,97» верна лишь для конкретных μ₀, λ, δ и должна быть
переписана через `η`. Отношение `D*/D_lin` при этих точках: 0,270 / 0,200 / 0,132 / 0,095 — то есть
линейная аппроксимация завышает равновесие в 4–10 раз.

## 3. F-029 — нормальные формы и размытие перехода

Запись:

```
ẋ = r + x²,   ẋ = rx − x²,   ẋ = rx − x³,   Δ ~ ε^(2/3)
```

**Единицы.** `ẋ` имеет `1/с`; `r` имеет `1/с`; `x` безразмерен. Тогда коэффициенты при `x²`/`x³` тоже
должны нести `1/с`:

```
ẋ = r + a·x²,   ẋ = r·x − b·x²,   ẋ = r·x − c·x³,     a, b, c — 1/с
```

Без этих коэффициентов равенства размерно бессмысленны (складывается `1/с` и `1`). В `UNITS` у F-029
не было ни `a`, ни `b`, ни `c`; `Delta` был объявлен как «ширина перехода, в единицах x» — это и есть
главная ошибка (см. ниже).

**Где живёт показатель 2/3.** Числовая проверка для несовершенной вилки `ẋ = r·x − x³ + ε`:

```
eps=0.1     r_fold=0.407163     r_fold/eps^(2/3)=1.8899
eps=0.01    r_fold=0.087721     r_fold/eps^(2/3)=1.8899
eps=0.001   r_fold=0.018899     r_fold/eps^(2/3)=1.8899
eps=1e-06   r_fold=0.000189     r_fold/eps^(2/3)=1.8899
ожидание 3/2^(2/3) = 1.88988157484231
```

То есть `Δ_r = 3·2^(−2/3)·ε^(2/3)` — **ширина по параметру `r`**, а `r` имеет единицы `1/время`.
Сдвиг по состоянию при этом масштабируется как `ε^(1/3)`: `x_fold = (ε/2)^(1/3)`.

Для статического несовершенства `r + x² + ε = 0` сдвиг по `r` **линеен** по `ε`, а по `x` — `√ε`:

```
eps=0.1: сдвиг x = sqrt(eps) = 0.316228
eps=0.01: 0.100000
eps=0.001: 0.031623
```

**Вывод.** Запись «Δ ~ ε^(2/3) в единицах x» неверна дважды: и по оси (это ось параметра, `1/время`),
и по общности (для статического сдвига показатели другие: 1 по `r`, 1/2 по `x`). Показатель 2/3
принадлежит **динамике прохождения складки** (ширина по параметру), а не «размытию состояния».

## 4. Что исправлено в данных

| узел | было | стало |
|---|---|---|
| `F-001` | `lambda: "1"`, `delta: "1"` | `lambda: "1/с"`, `delta: "1/с"` (λδ = 1/с²) |
| `F-003` | `lambda: "1"` | `lambda: "1/с"` |
| `F-029` | `Delta: ширина в единицах x` | `Delta_r: "1/с"` (ширина по параметру), добавлено `Delta_x: "1"` |

Правка внесена в `kg/migrate.py` (единственное место, где объявлены единицы), затем `kg/` пересобран.

## 5. Что это не доказывает

- Что наши формулы верны физически: проверена только размерность и границы режимов.
- Что литература знает эти формы: поиск форм F-003 в литературе не закрыт (`L-005`, `L-009` — кандидаты).
- Что `η` можно измерить: для этого нужны отдельные измерения `λ`, `δ`, `μ₀` в одной системе.

## 6. Следующая проверка

Подставить в `η` измеренные (а не выбранные) значения `λ`, `δ`, `μ₀` из литературы и проверить, в каком
режиме реально живут системы, для которых мы заявляем корневой закон. Если `η < 1` — корневой режим
нашим данным не нужен.

## 4. F-002 — порог доли удержания (25.11.2026)

Запись:

```
D_{n+1} = h·D_n + δ·T          рекуррентность повреждения по поколениям
D*      = δ·T / (1 − h)        конечное плато при h < 1
```

**Единицы.** `D` и `h` безразмерны; `T` — время поколения в секундах; произведение `δ·T` обязано быть
безразмерным, значит `δ: 1/с`. Было: единицы не объявлены вовсе. Стало:
`{D: 1, h: 1, delta: 1/с, T: с, D_star: 1}`.

**Свойство, как у `F-001`:** `δ` и `T` входят **только произведением**. По данным о накоплении их нельзя
разделить — наблюдаемо лишь `δ·T` (повреждение за поколение).

**Проверка записанных «плато».** В записи стоят числа 2,02 / 3,28 / 5,80 / 8,68 для `h = 0,90 / 0,95 /
0,98 / 0,99`. Если это неподвижные точки `δ·T/(1−h)`, то `δ·T` должно быть одним и тем же:

| h | записано | `δ·T`, требуемое формулой | предел при `δ·T = 0,2` |
|---|---|---|---|
| 0,90 | 2,02 | 0,202 | 2,00 |
| 0,95 | 3,28 | 0,164 | 4,00 |
| 0,98 | 5,80 | 0,116 | 10,00 |
| 0,99 | 8,68 | 0,0868 | 20,00 |

Требуемое `δ·T` падает в 2,3 раза — значит числа **не являются неподвижными точками**. Они совпадают
с конечным горизонтом `D_n = δ·T·(1 − h^n)/(1 − h)` при `δ·T = 0,2` и

```
h = 0,95: n ≈ 33   (D_n = 3,264)
h = 0,98: n ≈ 43   (D_n = 5,805)
h = 0,99: n ≈ 57   (D_n = 8,722)
```

То есть записанные значения — **снимки на разных горизонтах**, а не плато; пределы при том же `δ·T`
равны 2 / 4 / 10 / 20. Горизонт в записи не указан, поэтому числа не воспроизводимы: без `n` их нельзя
получить ни из формулы, ни из прогонов.

**Исправление записи:** либо писать пределы (2 / 4 / 10 / 20 при `δ·T = 0,2`), либо указывать горизонт
рядом с каждым числом. Первое предпочтительнее: предел не зависит от того, сколько поколений считали.

# `F-023`: двойственная задача — инвариант относится к состоянию, а не к потокам

**Дата:** 25.11.2026. **Агент:** `main`. **Воспроизведение:** `python3 tools/duality_invariants.py`.

## Запись в узле

```
прямая:   max cᵀv   при  S·v = 0,  l ≤ v ≤ u        (S — стехиометрия, v — потоки)
двойственная:  min uᵀy⁺ + lᵀy⁻   при  Sᵀ·y ≥ c
инварианты: левое ядро S: {w : wᵀS = 0} → wᵀv постоянно            (L-064)
```

## Что показали числа

Цикл `A → B → C → A`, три вещества, три реакции; левое ядро `S` одномерно, `w ∝ (1,1,1)`.

**(1) Так, как записано — `wᵀv` — не постоянно:**

| поток `v = t·(1,1,1)` | `wᵀv` |
|---|---|
| `t = 0,5` | 0,866025 |
| `t = 1,7` | 2,944486 |
| `t = 4,2` | 7,274613 |

Разброс **в 8,4 раза**. Все три потока допустимы (`Sv = 0`).

**(2) Постоянна другая величина — `wᵀx`,** где `x` — состояние: вдоль траектории `ẋ = S·v` при `v = (1,1,1)`
`wᵀx = 1,154700538` на всём интервале `t = 0…5`.

Это и есть стандартное сохранение фрагментов (moiety conservation): `d(wᵀx)/dt = wᵀSv = 0`.

**(3) Сильная двойственность подтверждена:** оптимум прямой `16,000000000`, двойственной `16,000000000`,
разница `0,00e+00`; `y = (−3; 0,1; 0)`, `Sᵀy ≤ c`.

**(4) Теневые цены определены с точностью до сдвига вдоль `w`:** `Sᵀ(y + 2,5·w) = Sᵀy` (проверено —
не изменилось). Именно эта неоднозначность и стоит за словами «физический смысл — химические потенциалы».

## Дефект записи

`wᵀv постоянно` — **неверно в буквальном смысле**: `wᵀS = 0` влечёт `(wᵀS)v = 0` тождественно, то есть
**никакого ограничения на `wᵀv` не даёт**. Ограничение возникает только если `v = ẋ`, то есть для состояния.

**Как надо:** `wᵀS = 0 ⇒ wᵀx` сохраняется вдоль траектории. Для потоков верное утверждение другое:
`Sᵀ(y + αw) = Sᵀy` — теневые цены не определены вдоль `w`.

Это тот же класс, что `F-029` (`ε^(2/3)` вместо `α^(2/3)`) и `F-021` (ступенька вместо излома): **запись
верна по духу и неточна по букве**, и неточность ровно в том, к чему относится величина.

## Опровергающее условие

Если `wᵀv` окажется постоянным на разных допустимых потоках — запись верна в буквальном смысле.
`tools/duality_invariants.py` проверяет это прямо и возвращает 1, если ожидание не подтвердилось.

## Что это НЕ доказывает

- Что исходная работа (L-064) ошибается: возможно, там `v` означает состояние, а не поток — это надо
  прочитать в источнике, а не вывести из обозначения.
- Что двойственность «объясняет» химические потенциалы: проверено только равенство оптимумов и сдвиг.

# FINDING-307. Закон `h < 1` проверен прямо: **плато 2.05** против **линейного роста до 181.9**

**Слону:** превращает объяснение 306-й из соображения в **измерение**. При `h = 0.9` среднее повреждение выходит на
**плато 2.02–2.05** за 200 000 шагов, при `h = 1.0` растёт **линейно** до **181.9** — в **88.7 раза** выше. Это и есть
разница между «поколения забывают» и «не забывают».

**Дата:** 2026-11-19. **Статус:** (a)(b)(c) `passed`. **Цикл:** 275.

## Постановка

Один штамм без конкуренции: форма живёт, пока не умрёт от угасания; место занимает новорождённый с повреждением
`h · (среднее повреждение)`. N = 2000.

## Предсказание, записанное до прогона

При `h = 0.9` — **плато**; при `h = 1.0` — **рост**; отношение к концу **больше двух**.

## Результат (`core/examples/organ_damage_drift.rs`, 200 000 шагов)

| шаг | `h = 0.9` | `h = 1.0` |
|---|---|---|
| 20 000 | 2.026 | 19.750 |
| 40 000 | 2.003 | 39.116 |
| 60 000 | 2.031 | 58.115 |
| 80 000 | 2.019 | 76.761 |
| 100 000 | 2.036 | 95.065 |
| 120 000 | 2.038 | 113.039 |
| 140 000 | 2.037 | 130.697 |
| 160 000 | 2.022 | 148.048 |
| 180 000 | 2.041 | 165.104 |
| **200 000** | **2.050** | **181.876** |

## Вердикт

**(a) подтверждено:** при `h = 0.9` — **плато**: последний прирост **0.0091** при уровне 2.05, то есть **0.4 %**.

**(b) подтверждено:** при `h = 1.0` повреждение **растёт** — последний прирост 16.77, и оно **в 88.7 раза** выше.

**(c) подтверждено:** отношение **88.71** при предсказанных «больше двух».

## Что это доказывает

- **Закон `Dₙ = hⁿ·D₀` верен как утверждение о дрейфе**, а не только о поколениях: он описывает **среднее по
  популяции** во времени.
- **`h = 1` — граница между стационарным и нестационарным режимом**, и она **измерена**, а не выведена на глаз.
- **Плато при `h < 1`** объясняет, почему в 305-й при `inherit = 0.5` доля не зависела от размера популяции: штамм
  достигал **стационарного повреждения**, и дальше ничего не менялось.

## Что это не доказывает

- Не доказывает, что плато при `h = 0.9` **не поедет** на горизонте в десять раз длиннее: 200 000 шагов — не
  бесконечность.
- Не проверено `h` между 0.9 и 1.0: граница там, где схождение медленнее.
- Один штамм без конкуренции; с конкуренцией картина та же по существу, но числа иные.

## Что дальше — предсказание до кода

**Сузить границу:** `h` = 0.95, 0.98, 0.99 при 400 000 шагов.

**Предсказание:** плато будет **расти** по мере приближения к 1 — как `1/(1 − h)` для геометрической суммы, то есть
0.95 → ≈20, 0.99 → ≈100. Если плато не следует `1/(1−h)` — значит повреждение не складывается геометрически, и
закон нужно переписать.

# Проверка формулы на измеренных числах: осмолярность

Сгенерировано `tools/check_osmotic.py`. Только арифметика формулы `(L/L*) + (v/v*)^2 <= 1`.

## Данные

- превышение уровня: **1000 мосмоль/кг** (1640 против 640), одинаковое в обоих опытах;
- медленный подход: **50 мосмоль/кг/ч** (за 20 ч) — выжило **89%**;
- мгновенный скачок: скорость неограниченна — выжило **30%**.

## Что следует из формулы

Для медленного подхода, раз он дал выживание:

    (L/L*) + (v/v*)^2 <= 1   =>   v* >= v / sqrt(1 - L/L*)

| доля уровня L/L* | какой должна быть v*, мосмоль/кг/ч |
|---|---|
| 0.50 | не меньше 71 |
| 0.70 | не меньше 91 |
| 0.90 | не меньше 158 |
| 0.95 | не меньше 224 |
| 0.99 | не меньше 500 |

## Что это предсказывает и как проверить

Если формула верна, то при промежуточных скоростях исход должен лежать между 30% и 89%:

| скорость, мосмоль/кг/ч | предсказание при L/L* = 0,5 (v* ≈ 71) | при L/L* = 0,9 (v* ≈ 158) |
|---|---|---|
| 50 | выживает (запас 0.50) | выживает (запас 0.90) |
| 70 | выживает (запас 0.02) | выживает (запас 0.80) |
| 100 | срыв | выживает (запас 0.60) |
| 160 | срыв | срыв |
| 250 | срыв | срыв |
| 400 | срыв | срыв |

## Что это даёт

1. Числа **совместимы** с формулой при `v*` от 71 до бесконечности: двух точек недостаточно, чтобы
   получить `v*` однозначно.
2. Но они **исключают** одну вещь: если бы порог по скорости отсутствовал (то есть `v*` бесконечно),
   исход при мгновенном скачке был бы таким же, как при медленном подходе. Он не такой.
3. Значит вторая ось нужна, а не только первая. Это первое **эмпирическое** основание для члена
   `(v/v*)^2`, а не только аналогия с инженерным законом безопасности.


## Второй набор: глиома C6, три скорости (DIP41-0001)

Сдвиг 300 → 440 мосмоль/кг при 37 °C, три скорости подхода:

| скорость, мосмоль/(кг·мин) | в час | исход |
|---|---|---|
| 3 | 180 | объём держится |
| 6 | 360 | объём падает |
| 9 | 540 | объём падает |

Отсюда критическая скорость для этой системы лежит **между 180 и 360 мосмоль/кг/ч**.
Это первый измеренный интервал для `v*`, а не оценка из формулы.
## Решающий опыт

Нужны **промежуточные скорости**: 70, 100, 160, 250 мосмоль/кг/ч. Если выживание падает между 50 и
160 — `v*` попадает в этот интервал, и формула проверена. Если остаётся 89% до 400 и выше —
второй член надо переписать (например, в первой степени).

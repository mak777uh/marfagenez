# Формы зависимости «темп → исход»: что реально измерено

Сгенерировано `tools/shapes.py` по числам принятых ячеек карты. Ни одна модель не подгоняется:
показано, как выглядит ряд и к какому типу формы он относится.

| ряд | скорости | исходы | форма |
|---|---|---|---|
| отогрев ооцитов (Seki, Table 3) | 139 / 476 / 1220 / 2170 / 2950 | 11.1 / 54.3 / 68.8 / 69.4 / 82.5 (%) | **монотонно растёт** |
| охлаждение при отогреве 2170 (Seki) | 37 / 187 / 522 / 1827 | 15.8 / 69.4 / 62.9 / 30 (%) | **внутренний максимум** |
| охлаждение при отогреве 2950 (Seki) | 187 / 522 / 1827 | 82.5 / 88.9 / 89.6 (%) | **монотонно растёт** |
| K562, охлаждение (Dumont) | 5 / 180 / 250 / 5000 / 30000 | 20 / 2 / 2 / 2 / 18 (%) | **внутренний минимум** |
| E. coli, нагрев 65 °C (Huertas, Table 1) | 14.7 / 15.4 / 15.8 / 17.1 / 17.8 | 4.07 / 3.12 / 1.34 / 0.31 / 0.27 (log) | **монотонно падает** |
| SCC61, мощность дозы (Wozny) | 0.5 / 2 / 10 | 0.39 / 0.24 / 0.2 (SF2) | **монотонно падает** |

## Сколько разных форм

Различных типов формы в шести рядах: **4**.

- **монотонно растёт**: 2 (отогрев ооцитов (Seki, Table 3); охлаждение при отогреве 2950 (Seki))
- **внутренний максимум**: 1 (охлаждение при отогреве 2170 (Seki))
- **внутренний минимум**: 1 (K562, охлаждение (Dumont))
- **монотонно падает**: 2 (E. coli, нагрев 65 °C (Huertas, Table 1); SCC61, мощность дозы (Wozny))

## Что это значит

1. **Единой кривой нет.** В шести рядах четыре разных типа формы: монотонный рост, монотонное
   падение, внутренний максимум и внутренний минимум.
2. **Внутренний экстремум встречается дважды** и оба раза в криобиологии, где конкурируют два
   механизма повреждения (эффекты растворов и внутриклеточный лёд).
3. **Нулевой случай** (охлаждение при быстром отогреве) показывает, что форма зависит от того,
   какой этап лимитирует: при смене лимитирующего этапа штраф за темп исчезает.

## Чего не хватает для безразмерной оси

Чтобы свести ряды к одной кривой `исход = f(v/v*)`, нужна критическая скорость `v*` для каждого
ряда. Она известна только там, где есть внутренний экстремум (Seki: оптимум охлаждения около
187 °C/мин) или явная граница (глиома: между 180 и 360 мОсм/(кг·ч)).

Для монотонных рядов `v*` **не определена**: у отогрева ооцитов выживаемость растёт до самого
края диапазона, у E. coli инактивация падает до самого края. Без `v*` безразмерная ось не
строится, и сравнивать такие ряды между системами пока нельзя.

## Практический вывод

Формула должна содержать переключатель лимитирующего этапа, а не одну универсальную кривую:
наблюдаемые формы различаются не шумом, а тем, какой механизм первым перестаёт успевать.

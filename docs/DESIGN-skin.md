# DESIGN-skin.md — кожа как состояние: величина, которую держат **против распада**

**Слону:** **это и есть шаг к слону.** `GOAL.md` §1a называет кожей «границу как состояние» и говорит:
живое **активно поддерживает себя против распада**, камень — просто не меняется. До сих пор в модели не было
величины, которую организм мог бы держать **лучше или хуже**: урон капал сам, починка была задана снаружи
(`RepairPolicy`), и решения организм не принимал. Здесь появляется такая величина.

**Дата:** 2026-11-19. **Статус:** расчёт и предсказания, **кода ещё нет**. **Цикл:** 218.

---

## 1. Откуда задача

`docs/REVISION-heredity.md` §4: линия наследственности научилась делать **постоянство**, а не
**поддержание**. Регулятор размера держит число клеток — но камень тоже «держит» число, если его не трогать.

Разница в том, что живое **тратит поток**, чтобы не распасться. В модели этого потока нет: `damage` растёт с
`damage_rate`, починка стоит `dr·rc` и **выбирается снаружи**, а не организмом.

## 2. Минимальный механизм

Форма получает **целостность** `q ∈ (0, 1]`:

```
каждый шаг     q ← q · (1 − d)                 распад, экспоненциальный
починка        q ← min(1, q + u)   за счёт      c · u   энергии
смерть         q ≤ q_min                        рассыпалась
решение        u выбирается из собственного состояния (политика)
```

**Три свойства, которых раньше не было:**

1. **`q` — состояние**, а не счётчик: его можно потерять и вернуть.
2. **Удержание стоит потока** `c·u` каждый шаг, и он конкурирует с `maintenance` и ремонтом.
3. **Политика наследуется** — механизм `Heredity` из линии 253–257 уже есть; `u` становится наследуемым
   параметром, и отбор может его двигать.

## 3. Расчёт — до кода

### 3.1. Без починки

`q_n = q_0 (1 − d)^n`. Смерть при `q ≤ q_min`:

```
L = ln(q_min / q_0) / ln(1 − d)
```

При `q_0 = 1`, `q_min = 0.2`, `d = 0.05`: `L = ln 0.2 / ln 0.95 = (−1.6094)/(−0.0513) ≈ 31.4` шага.

### 3.2. С постоянной починкой `u`

Установившееся значение: `q* = u/d` (потому что `q(1−d) + u = q` ⇒ `q·d = u`).

Держать целостность можно, если `q* ≥ q_min`, то есть

```
u ≥ d · q_min
```

Стоимость удержания в шаг — `c · d · q_min`. При `d = 0.05`, `q_min = 0.2`, `c = 10`:

```
u_min = 0.01 за шаг,   цена = 0.1 за шаг
```

### 3.3. Новая граница поддержания

Третий член цены встаёт рядом с двумя уже известными:

```
income ≥ maintenance + damage_rate · repair_cost + c · d · q_min
```

**При `maintenance = 0.6`, `income = 1.0`, `dr·rc = 0.03`** свободно `0.37 ≥ 0.1` — кожа оплачивается.
**При `maintenance = 0.95`** свободно `0.02 < 0.1` — **мир гибнет от потери кожи, хотя поддержание
оплачивает**. Это и есть новая граница, и она проверяема.

### 3.4. Почему это не то же, что `damage`

`damage` — счётчик, который **только убивает**: при `damage ≥ 1` смерть, и всё. `q` — величина, которую
можно **держать около цели**, и цена удержания пропорциональна распаду. Поэтому в `q` впервые выразимо
«поддерживает себя лучше или хуже», а в `damage` — нет.

## 4. Предсказания, записанные до кода

- **P1.** Без починки время жизни равно `ln(q_min)/ln(1−d)` **с точностью до шага**: при
  `d = 0.05, q_min = 0.2` — 31 или 32 шага, во всех сидах.
- **P2.** С починкой `u ≥ d·q_min` время жизни **не ограничено** (100 000 шагов и жив), и `q` колеблется
  около `u/d` в пределах ±0.02.
- **P3.** При `u < d·q_min` время жизни **конечно** и растёт как `1/(d·q_min − u)`: при `u = 0.008`
  (`d·q_min − u = 0.002`) — около 500 шагов, при `u = 0.0095` — около 2500.
- **P4.** Граница по `maintenance` сдвигается ровно на `c·d·q_min = 0.1`: мир, платящий `0.95`, гибнет от
  кожи, мир, платящий `0.85`, живёт.
- **P5.** При наследуемой политике `u` и цене `c` в опасной зоне (свободно `0.05…0.15` за шаг) доля
  «поддерживающих» растёт от 0 к большинству; при свободном `< 0.05` — **не растёт** ни у кого, и мир
  вымирает. Это и есть вопрос о слоне, выраженный числом.

## 6. Что этот механизм **не** даст

- **Не даст обмена через границу** (`GOAL.md` §1a: «убери обмен — рассыпается»): вещество по-прежнему
  только берётся, не возвращается. Q-011 остаётся открытым.
- **Не даст производства**: организация задана извне.
- **Не докажет, что жизнь «появилась»**: он даст **величину, которую держат против распада**, и границу
  цены. Это первый честный шаг к слону, а не слон.

## 7. Если P5 подтвердится

Тогда в проекте впервые будет **эндогенная** причина разницы между организмами: не заданная политика, а
**отобранная** интенсивность поддержания. Это и есть то, чего линии 1–257 не могли дать: там поведение было
написано, здесь оно становится **следствием цены**.

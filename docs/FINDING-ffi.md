# Находка: Rust вызывает Lean

**Дата:** 2026-11-11
**Проект:** МАРФАГЕНЕЗ++
**Где:** `laws/FFI.lean`, `core/src/bridge.rs`, `core/build.rs`

---

## Что было

Lean и Rust были **двумя слоями**, которые случайно описывали одни законы. Связь была **смысловая**, не техническая.

Теперь — **техническая**.

## Что сделано

```
laws/FFI.lean  --[lean -c]-->  FFI.c  --[gcc]-->  FFI.o  -->  Rust
```

Rust вызывает Lean-функции напрямую:

```rust
pub fn lean_saturation(free_walk: u64, wall_law: u64) -> u64 {
    unsafe { marfa_saturation(free_walk, wall_law) }
}
```

## Что экспортируется

| функция | что считает |
|---|---|
| `marfa_saturation` | `min(freeWalk, wallLaw)` |
| `marfa_fraction_pct` | `100·spread/law` |
| `marfa_fill_time` | `(b/σ)²` |
| `marfa_race_lost` | проиграна ли гонка |
| `marfa_fold_shifted` | складка точки в комнату |

## Проверка: 6 из 6

| тест | что проверяет |
|---|---|
| `the_bridge_is_available` | мост собран |
| `saturation_agrees` | 25 пар входов |
| `fill_time_agrees` | 20 пар |
| `fold_agrees` | все `x` в `[0, 8b]` для трёх `b` |
| `race_lost_agrees` | 12 пар |
| `fraction_pct_agrees` | 9 пар |

**Rust и Lean дают одинаковые ответы.**

## Четыре препятствия по дороге

### 1. `UInt64`, а не `Nat`

`Nat` в Lean — это `lean_object*` (указатель на кучу). `UInt64` — настоящий `uint64_t`.

Первая попытка объявила `lean_object*` и получила `marfa_add(40,2) = 21` вместо 42.

### 2. Рантайм нужно инициализировать

Без `lean_initialize()` первый вызов падал с `failed to initiate panic`.

### 3. Инициализация должна быть в главном потоке

Rust-тесты запускаются в отдельных потоках. `Once` внутри теста — слишком поздно.

Решение: **конструктор C** (`__attribute__((constructor))`), который срабатывает до `main` в главном потоке.

### 4. `ar` теряет `.init_array`

Конструктор был в объекте, но `ar` выбрасывал секцию `.init_array`. Без неё конструктор не вызывался.

Решение: **линковать объект напрямую**, не через архив.

## Формула

$$\text{Rust} \xrightarrow{\text{FFI}} \text{Lean}$$

Обе реализации считают одну формулу. Расхождение — ошибка в одной из них.

## Что это даёт

| было | стало |
|---|---|
| Lean и Rust отдельно | **Rust спрашивает Lean** |
| «закон доказан» | **программа использует доказанный закон** |
| смысловая связь | **техническая связь** |

## Чего это не даёт

**Не доказывает, что Rust-код верен.** Доказывает, что формулы совпадают на проверенных входах.

**Не переносит доказательство.** Переносится **формула**, не доказательство. Доказательство осталось в Lean.

## Честная оговорка

Мост работает, если есть Lean и gcc. Если нет — собирается заглушка, `bridge::available()` возвращает `false`, тесты **пропускаются**, не падают.

Это сделано намеренно: отсутствие инструмента — это **пропуск**, не провал.

# FINDING-350: `κ = 1/PAL` в диапазоне 0,29–0,58 — одно число в модели описывает только покой

**Дата:** 25.11.2026. **Агент:** `main`. **Тип:** данные (внесены в карту) + следствие для `F-005`.
**Связано:** `FINDING-348`, `FINDING-349`, `F-005`, `F-021`, `MAIN-P49-01`.

## Что внесено в карту

Атом `MAIN-P49-01` по обзору Park 2019 (`10.20463/jenb.2019.0024`, открытый доступ, раздел «PAL data for
female athletes» и Figure 1). Карта: **1008 → 1009 ячеек**.

| группа | PAL | `1/PAL` |
|---|---|---|
| коллегиальные пловчихи | 1,71 | 0,58 |
| теннисистки | 1,97 | 0,51 |
| бегуньи сборной США | 1,99 | 0,50 |
| синхронное плавание | 2,18 | 0,46 |
| кросс-кантри | 2,24 | 0,45 |
| яхтсменки (сборы) | 2,41 | 0,41 |
| баскетбол | 2,60 | 0,38 |
| бегуньи на выносливость | 2,68 | 0,37 |
| элитные пловчихи (сборы) | 3,00 | 0,33 |
| лыжницы-гонщики | 3,40 | **0,29** |

## Что это значит

1. **Диапазон `κ` — 0,29–0,58, то есть вдвое.** Запись `F-005` с одним `κ = 0,57` описывает **только
   режим покоя/лёгкой активности**. При соревновательных нагрузках доля поддержания падает до 0,3.
2. **Разброс есть и внутри одного вида спорта:** пловчихи 1,71 (умеренные тренировки) против 3,00
   (элитный сбор) — то есть `κ` зависит не от вида, а от объёма тренировок в текущем режиме.
3. **Для модели это не мелочь:** если `κ` — параметр, то он должен быть переменной, а не константой; если
   константа — модель описывает средний нетренированный режим, и это надо писать явно.

## Чего это НЕ доказывает

- Что наша `κ` (доля потока на поддержание сомы) **измерена** у спортсменов: измерен `PAL`, а `κ`
  получена тождеством `1/PAL`. Тождество не подтверждает гипотезу, а задаёт её форму.
- Что атом первичен: обзор вторичен, каждое значение взято из отдельной работы; для точного
  использования нужен первичный источник по каждому виду спорта.
- Что `κ` у животных ведёт себя так же: у мелких млекопитающих доля поддержания выше.

## Следующая проверка

Взять первичные DLW-работы для двух крайних точек (пловчихи 1,71 и лыжницы 3,40), выписать их локаторы и
проверить, что диапазон не артефакт обзора.

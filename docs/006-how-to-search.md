# 006 · Как искать в публикациях

**Читайте по порядку.** Седьмой документ. Предполагается, что вы прочли 000–005.
Следующий: [`007-where-we-are.md`](007-where-we-are.md).

---

## Лестница доказательности

**полный текст** → «в статье сказано…» · **аннотация** → «авторы заявляют…» · **вторые руки** → только указатель ·
**локатор не найден** → не использовать.

Правило: ссылка без локатора **не встаёт в основание ни одного пункта**.

## Инструменты

`crossref` — проверить ссылку и получить DOI; `europepmc` / `arxiv` / `s2` / `pubmed` — найти; `web_fetch` — поднять
уровень до полного текста; `web_search` / `research` — обзор и **синонимы**.

## Шаблоны, которые работают

1. проверка ссылки: `"<автор> <год> <фрагмент названия>"`;
2. формула: `"<явление> derivation"`, `"exact solution <модель>"`;
3. обзор: `"<тема> review 2024"`;
4. **другая запись** (главный приз): описывать **явление**, а не наш термин;
5. проверка «критичности»: `"critical exponent saddle-node divergence"`;
6. против себя: `"critique of <наша идея>"`;
7. смежные области: та же задача в **надёжности, управлении, химии, экономике** — там другие слова.

# Покрытие сшивки: считать по величине, а не по факту пары

Сгенерировано `tools/stitch_audit.py` по вердиктам Red Team (`docs/REDTEAM-STITCH-VERDICTS.json`).

## Почему прежняя метрика завышена

`docs/STITCH-COVERAGE.md` считал утверждение «опёртым», если у него есть хоть одна пара
«ячейка ↔ узел». Red Team показал, что **20 из 111 пар** держатся на совпадении слова, числа или
размерности, а не измеряемой величины. Значит пара — не то же самое, что опора.

## Покрытие в двух счётах (25.11.2026)

Раньше печаталось одно число — по узлам с `lit_ref`. Оно **занижало** результат: узел может иметь
`S`-пару в таблице сшивки и не иметь `lit_ref` в самом узле (`F-007`, `L-009`).

| счёт | значение | что значит |
|---|---|---|
| по всем узлам с утверждением | **37 / 152** | есть `S`-пара, величина совпала |
| по узлам с `lit_ref` | `20 / 152` | то же, но узел ещё и ссылается на литературу сам |

Знаменатель — `claims + formulas + gaps + correspondences`; `definitions`, `experiments`, `evidence`
в него не входят.

| прежняя | `33 / 152` | есть хоть одна пара |
| строгая | `20 / 152` | есть пара, где измеряемая величина совпадает |
| промежуточная | `28 / 152` | считая частичные |

Для работы следует пользоваться **строгой** метрикой: только она означает, что литература
действительно измеряет ту же величину.

## Чем опёрты `established`-записи

Литературная сшивка — не единственный вид опоры: у прогонов опора — сам прогон. Поэтому здесь
отдельно: как `established`-записи соотносятся со строгой литературной опорой (`S`).

| вид | `established` | из них с парой `S` | без пары `S` |
|---|---|---|---|
| `claim` | 5 | 2 | 3 |
| `formula` | 4 | 0 | 4 |
| `experiment` | 312 | 0 | 312 |

У прогонов опора — прогон, а не литература, поэтому «без пары `S`» для них нормально. Для `claim`
и `formula` отсутствие `S` означает, что строгой литературной опоры нет: либо она держится на
прогоне (`math.checked`), либо её нет вовсе.

### `claim`/`formula` со статусом `established` без строгой литературной опоры

Важно: отсутствие пары `S` **не** значит «нет опоры». Опору надо смотреть в `evidence`:
прогон (`experiment`), находка (`result`), литературный узел (`literature`) или формула.

| запись | лучший вердикт литературы | виды `evidence` |
|---|---|---|
| `C-001` | `Ch` | experiment, formula, result |
| `C-002` | `Ch` | experiment, result |
| `C-003` | `Ch` | experiment, formula, result |
| `F-001` | `N` | run |
| `F-003` | `Ch` | run |
| `F-022` | `нет пары` | run |
| `F-023` | `нет пары` | run |

**Без `evidence` вообще нет ни одной** — у всех пяти есть хотя бы один вид опоры.

## Ограничение

Вердикты — суждение Red Team по тексту и переменным, а не измерение. Спорную пару можно
переклассифицировать, но только с объяснением, какая величина на самом деле общая.

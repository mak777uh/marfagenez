# LITERATURE-GAPS.md — чего в литературе не нашлось (и чего не удалось прочесть)

**Зачем.** Отрицательный результат поиска — тоже результат: он воспроизводим и защищает от повторного переоткрытия.
Формат записи: **что искали**, **где**, **дата**, **чем это ограничено**.

---

## G-001 · Пересечение «повреждённая мембрана + её цена» — не закрыто

**Искали.** Модель, где (1) мембрана **повреждается**, (2) повреждение **наследуется**, (3) **ремонт оценён** и входит
в бюджет. Запросы: `protocell damage inheritance asymmetric division membrane maintenance cost`,
`protocell damaged membrane inherited repair cost division asymmetry`.
**Где.** `crossref`, `exa` (через веб-поиск), 2026-11-20.
**Что нашли вместо.** Протоклетки с **асимметричным делением** (`L-052`, 2024); стохастические модели повреждения с
починкой и асимметрией (`L-053`, 2019); наследование повреждения без мембраны (`L-054`, 2007).
**Ограничение.** Смотрели **аннотации**: полные тексты не открылись (см. G-002).

## G-002 · Полные тексты недоступны: домены резолвятся в приватные адреса

**Что происходит.** `web_fetch` отвечает `SSRF blocked: <домен> resolves to private address` для
`pmc.ncbi.nlm.nih.gov`, `en.wikipedia.org`, `arxiv.org`. То есть в этой среде **полный текст по этим доменам не
поднимается**.
**Следствие для реестра.** Часть записей имеет уровень **аннотация / фрагмент**, а не «полный текст». Это записано в
каждой записи честно.
**Что делать вместо.** (1) Работать по **фрагментам поисковой выдачи** (в них часто есть нужная цитата, как вышло с
`Πλ = 1/6`); (2) проверять ссылку через `crossref` (DOI находится); (3) если владелец может открыть PDF — просить
файл и читать локально; (4) не выдавать фрагмент за прочитанное.
**Дата.** 2026-11-20.

## G-003 · Универсальной «доли реакций» для RAF-замыкания нет

**Искали.** Число «какая доля реакций нужна для замыкания».
**Нашли.** Такой универсальной доли **нет**; есть классы задач (максимальная RAF — полиномиально, минимальная по
мощности — NP-полна), см. `L-043`, `L-027`.
**Ограничение.** Аннотации.

## G-004 · Названия для нашей «честной вероятности» нет

**Искали.** Устоявшийся термин для вероятности шага, при которой **медиана** стационарного распределения не смещается.
**Нашли.** Стандарт определён через **среднее** (критическая вероятность, мартингальность), а медианная версия имени не
имеет; наша величина — **медиана стационарного распределения** (`F-013`).
**Вывод.** Термин оставляем свой, но с явным определением.

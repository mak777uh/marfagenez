# HISTORY-LINE-CLOSED.md — линия «прошлое»: что измерено и почему она закрыта

**Дата:** 2026-11-19. **Линия:** находки 294–309, четырнадцать циклов. **База:** `master` @ `96e74f3`.

---

## 1. Зачем линия была открыта

`MODEL-CEILINGS.md` назвал **первый потолок** формулировки: у формы нет **прошлого** — состояние было одним числом
`q`, и одинаковые `q` делали формы неразличимыми. Потолок решено было снять **первым**, потому что это дешевле всего
и даёт сразу три вещи.

---

## 2. Что измерено и остаётся верным

| результат | число | где |
|---|---|---|
| **жизнь как скорость, а не как бит** | `mu(q) = rate·(1−q)^p`, средняя жизнь `1/mu(q)`; ошибка 0.3–2.2 % | 294 |
| **поглощающее состояние** | `mu(1) = 0`: целая форма **бессмертна**, нужен **пол старения** | 296 |
| **ступеньки на старом пороге нет** | 147 → 165 через `u/need = 1`, отношение 1.12 | 295 |
| **избыток покупает жизнь до целости** | 172 → 5000 при `yield` 1.25 → 2.0, дальше насыщение | 296 |
| **прошлое делает равные формы неравными** | 339 / 258 / 128 при одном `q = 0.5` | 297 |
| **закон жизни с повреждением** | `mu0*T + (lambda*delta/2)*T^2 = 1` | 297 |
| **порог вытеснения — `h = 1`** | `h < 1` — плато, `h >= 1` — рост | 306, 307 |
| **точная формула плато** | `lambda*D^2 + mu0*D = delta/(1-h)`, семь точек, расхождение <= 3 % | 308, 309 |

## 3. Что оказалось моими ошибками

| цикл | ошибка | чем поймана |
|---|---|---|
| 294 | угасание без пола | `mu(1) = 0` → бессмертие |
| 297 | «разница втрое» | 1.32 раза |
| 298 | «1.38 примерно равно предсказанным 1.31» | грубая модель даёт 1.11; совпадение случайно |
| 298 | конструкция, где слоты закреплены за штаммами | доля оставалась ровно 0.500 |
| 300 | `mean_damage = 1e9` при пустом штамме | вымирание становилось поглощающим |
| 303–304 | «вытеснения нет» при N = 200 | при N = 5000 доля 0.997 |
| 305 | «малое преимущество вытеснит при большом N» | 0.536 при любом N |
| 308 | `1/(1−h)` | измерено 0.42 от предсказанного |

**Восемь ошибок за четырнадцать циклов**, и каждая поймана числом.

---

## 4. Что можно утверждать после линии

1. **Жизнь можно задать без порога:** смертность от состояния, средняя жизнь `1/mu(q)` — закон, а не подгонка.
2. **У формы есть прошлое:** две формы с одинаковой целостью **не равны**, жизнь считается **квадратным уравнением**.
3. **Прошлое наследуется, и порог вытеснения — `h = 1`:** ниже штраф затухает по поколениям, на нём и выше — нет.
4. **Повреждение ограничивает само себя:** плато расходится как **корень**, а не как `1/(1−h)`.

## 5. Чего утверждать нельзя

1. **Что пол старения (`floor`) имеет смысл** — он **взят извне** и не измерен.
2. **Что `mu` линейна по повреждению** — допущение модели.
3. **Что при `h` → 1 поведение остаётся корневым бесконечно** — проверено до 0.999.
4. **Что это слон.** Форма по-прежнему одна целостность плюс счётчик повреждений; **двух независимых величин нет**.

---

## 6. Почему линия закрыта

**6.1. Потолок снят.** Прошлое есть, оно влияет, и влияние описано **точной формулой** с тремя параметрами, заданными
заранее.

**6.2. Дальнейшее дробление не даёт понимания.** `h = 0.9999` даст число, но не новый механизм.

**6.3. Следующий потолок даёт новое качество, а не уточнение.** Излишек: у формы нет **выбора**, потому что лишнее
вещество некуда девать (`MODEL-CEILINGS.md`, шаг 2).

---

## 7. Что дальше

**Излишек.** Дать веществу применение: запас, который позволяет пережить `k` шагов нулевого притока. Тогда впервые
появится **выбор** — потратить сейчас или сберечь, — и вопрос, который в модели ещё не ставился: **что форма
предпочитает**.

**Предсказание:** если у запаса есть польза, оптимальный `yield` перестанет быть «любым выше 2» и станет **конечным
числом** — то есть исчезнет насыщение, наблюдённое в 293-й и 296-й.

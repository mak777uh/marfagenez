# Точка невозврата: v2 — ремонт ограничен доступным грузом

**Это моя конструкция**, помечено. Собрана из принятых ячеек карты (см. раздел «Опоры»);
числа ниже — иллюстрация структуры, а не измерение. Сгенерировано `tools/dcritical2.py`.

## Что было не так в v1

Версия 1 записывала `dD/dt = P − C0·exp(−D/D_cap)`. У неё два дефекта, оба найдены численно:

1. **При `D = 0` модель даёт отрицательную скорость**, если `C0 > P0`: ремонт «удаляет»
   повреждение, которого ещё нет. Физически это невозможно.
2. **Равновесие v1 неустойчиво:** производная правой части в точке `D*` равна `P0/D_cap > 0`.
   Значит `D*` — не «порог, после которого плохо», а **сепаратриса**: слева система сползает
   к нулю, справа уходит вверх. Как «точка невозврата» это верно, как «плато» — нет.

## Запись v2

```
R(D) = min( C0·exp(−D/D_cap),  k·D )        ремонт не больше мощности и не больше груза
dD/dt = P0 − R(D)
```

`D` — повреждение в «событиях ремонта»; `P0` — поток повреждения (события/ч); `C0` — предельная
мощность ремонта (события/ч); `D_cap` — повреждение, при котором мощность падает в `e` раз;
`k` — константа скорости первого порядка (1/ч).

## Равновесия v2 и их устойчивость

Проверено численно при `C0 = 3`, `D_cap = 4`, `k = 1`:

| `P0` | число равновесий | что это |
|---|---|---|
| 0.5 | 2 | D* = 0.500 (устойчиво); D* = 7.167 (неустойчиво) |
| 1 | 2 | D* = 1.000 (устойчиво); D* = 4.394 (неустойчиво) |
| 1.5 | 2 | D* = 1.500 (устойчиво); D* = 2.773 (неустойчиво) |
| 2 | 0 | равновесий нет: повреждение растёт неограниченно |
| 2.5 | 0 | равновесий нет: повреждение растёт неограниченно |
| 3 | 0 | равновесий нет: повреждение растёт неограниченно |
| 3.5 | 0 | равновесий нет: повреждение растёт неограниченно |

**Что видно:** при малом потоке есть **два** равновесия — нижнее устойчивое (рабочая точка) и
верхнее неустойчивое (сепаратриса). С ростом потока они сближаются, сливаются и исчезают.
Именно эта пара и есть «два порога»: до нижнего система возвращается, между ними — уходит вверх,
после исчезновения равновесий не возвращается вообще.

| `DIP49-0001`, `DIP49-0002` | быстрая (18–36 мин) и медленная (1,5–5,1 ч) компоненты репарации |
| `DIP59-0001` | полувремя разрешения фокусов 1,4 → 5,7 ч при росте дозы |
| `DIP59-0005` | контрпример: полувремя DSB не зависит от дозы (168 ± 10 мин при 3–90 Гр) |
| `B26-01-0009` | авторы теневых цен сами пишут, что скачки не проверены |

## Область применимости

| условие | следствие |
|---|---|
| `P0 = 0` | `R = min(C0, kD) = kD` при малом `D`: восстановление экспоненциально, не «вечно» |
| `P0 > C0` | равновесий нет: мощность ремонта меньше потока при любом `D` |
| `C(D) ≥ k·D` всюду | второй механизм (деградация мощности) не включён, модель первого порядка |
| `D_cap → ∞` | мощность не падает, остаётся только `k·D` |

## Что различает v1 и v2

**Импульс с последующим снятием нагрузки (pulse-chase):**

- **v2 при `P0 = 0`:** восстановление **экспоненциально** с константой `k`, то есть после снятия
  нагрузки ремонт идёт тем быстрее, чем больше груза (до предела `C0`).
- **v1 при `P0 = 0`:** восстановление с **постоянной** скоростью `C0` (мощность не зависит от груза),
  пока груз не станет мал — там v1 ломается (уходит в отрицательные значения).
- **Пороговая модель v2:** между нижним и верхним равновесием есть полоса, где система уходит
  вверх даже при неизменном потоке; в v1 такой полосы нет — там всё определяется знаком одного
  выражения.

**Значит эксперимент должен давать пары `(D, R(D))`, а не только «выжил/погиб».**

## Чем это опровергается

- Если после снятия нагрузки восстановление идёт с **постоянной** скоростью независимо от груза —
  член `k·D` неверен.
- Если равновесий всегда **одно** и оно устойчиво — двухпороговой структуры нет.
- Если при `P0 > C0` система всё равно возвращается — мощность ремонта не ограничена сверху.

## Чего не хватает

- **`D_cap` не измерена** ни в одной системе (см. `FINDING-341`: падение ремонта видно в фокусных
  измерениях и не видно в прямых).
- **`k` и `C0` не разделены** в публикациях: числа вида `1,14–2,31 ч⁻¹` — константы первого порядка,
  а не предельная мощность.
- Нет работы, где `D_crit` и `D_death` измерены **в одной системе**.

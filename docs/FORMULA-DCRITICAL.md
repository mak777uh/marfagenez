# Формула точки невозврата: два порога вместо одного

**Это моя конструкция**, а не формула из источника. Собрана из принятых ячеек карты; числа ниже — иллюстрация структуры, а не измерение. Сгенерировано `tools/dcritical.py`.

## Запись

```
dD/dt = P − C(D),   C(D) = C0·exp(−D/D_cap)

точка невозврата:  D_crit = D_cap·ln(C0/P0)
смерть:            D_death > D_crit   (отдельное событие, а не тот же порог)
```

`D` — повреждение в единицах «событий, эквивалентных одному ремонту»; `P` — поток повреждения (событий в час); `C0` — пропускная способность ремонта (событий в час); `D_cap` — повреждение, при котором способность ремонта падает в `e` раз (событий).

## Почему два порога, а не один

Если повреждение только копится, порог один — «сколько вытерпит». Но повреждение, по ячейкам карты, **снижает саму способность ремонта**: после выхода цитохрома c биоэнергетика не выключается (`B21-01-0003`), клетки восстанавливаются после снятия индуктора (`B21-01-0004`), а предсказать исход по одному числу нельзя (`B22-01-0006`). Отсюда два разных порога:

- **`D_crit`** — выше него система ещё жива, но восстановиться уже не может (ремонт слабее потока);
- **`D_death`** — выше него наступает гибель; **`D_death > D_crit`**.

## Как двигается точка невозврата

Всё задаёт **отношение** `C0/P0`, а не абсолютные величины:

| `C0/P0` | `D_crit / D_cap` | что это значит |
|---|---|---|
| 1.2 | 0.18 | поток почти равен ремонту: порог очень низкий |
| 2 | 0.69 | запас есть, но небольшой |
| 5 | 1.61 | ремонт с большим запасом |
| 10 | 2.30 | ремонт с большим запасом |
| 100 | 4.61 | ремонт с большим запасом |

**Ключевое следствие:** порог растёт как **логарифм** отношения, то есть каждое удвоение запаса ремонта добавляет `ln 2 = 0.69·D_cap` — одну и ту же величину, а не пропорциональную.

## Масштаб пропускной способности по ячейкам

| этап | `C0`, 1/ч | сколько это |
|---|---|---|
| быстрая репарация ДНК (DIP49-0001) | 1.14–2.31 | |
| медленная репарация ДНК (DIP49-0002) | 0.14–0.46 | |
| вырезание 8-oxoG (DIP49-0006) | 3.78 | |
| обновление белков, культура (DIP49-0007) | 0.035–0.05 | |

Разброс между этапами — **два порядка** (0,035 у белков против 3,78 у 8-oxoG), и это согласуется с `I-060`: внутри одного класса повреждений репарация различается в 40–60 раз. Значит `D_crit` в одной и той же клетке **разный для разных видов повреждения** — единого порога нет.

## Что это предсказывает (и как проверить)

1. **Порог зависит от запаса ремонта логарифмически.** Проверка: подать импульс повреждения разной величины, снять индуктор и найти границу восстановления; повторить при подавлении ремонта (например, OGG1 или протеасомы). Предсказание: граница сдвигается на `ln(C0/C0')·D_cap`.
2. **`D_crit < D_death`.** Проверка: в одной системе измерить обе границы — восстановление после снятия индуктора и гибель — и показать, что между ними есть полоса «жив, но не восстановится».
3. **Порог зависит от вида повреждения** внутри одной клетки: у 8-oxoG он выше, чем у белков, при одинаковом `D_cap`.

## Чем это опровергается

- Если `D_crit` **не зависит** от пропускной способности ремонта — член `C(D)` неверен, и порог описывается одним накоплением.
- Если `D_crit` **совпадает** с `D_death` во всех измерениях — двухпороговая структура лишняя.
- Если после снятия индуктора восстановление идёт **полностью при любом** накопленном повреждении — точки невозврата нет вовсе (анастасис без границы).

## Чего не хватает

- **`D_cap` не измерен ни в одной системе.** Это ключевая величина: без неё формула задаёт только форму зависимости, но не числа.
- Нет работы, где `D_crit` и `D_death` измерены **в одной системе**.
- Поток `P` в наших источниках задаётся внешне (мМ/мин, °C/мин, Гр/мин), а не в единицах ремонта.

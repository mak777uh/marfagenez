## Что проверяли

В проекте `medium` было найдено: при постоянном толчке `μ` и шуме `σ` в отражающей комнате `[-B, B]` стационарная плотность

$$\rho(x) \propto e^{\alpha x}, \qquad \alpha = \frac{2\mu}{\sigma^2}$$

## Моя ошибка по дороге

Первая версия проверки считала моменты **вручную** и давала бессмыслицу:

| α | sd (руками) | sd (SymPy) |
|---|---|---|
| 0.22 | **3.72** | 1.660 |
| 2.22 | **0.000** | 0.450 |

`sd = 3.72` при комнате шириной 6 — невозможно. `sd = 0` при большом `α` — тоже.

**Ошибка была в моей арифметике, не в физике.** SymPy даёт правильные числа, и они совпадают с симуляцией.

> **Ручная формула моментов — источник ошибки. Символьный движок — нет.**

Это ровно тот случай, для которого в проекте есть SymPy: не для красоты, а чтобы **не считать вручную**.

## Формула

$$\alpha = \frac{2\mu}{\sigma^2}$$

- `α = 0` — нет толчка, равномерное, `sd = B/√3`
- `α` растёт — плотность прижимается к стене, `sd` падает
- `α → ∞` — плотность на стене, `sd → 0`

## Согласование с прошлым раундом

Прошлый раунд: «`spread = B/√3` — предел без толчка».

Эта проверка даёт **точную формулу** для случая с толчком:

$$\text{sd}(\alpha) = \sqrt{\int_{-B}^{B} x^2 \frac{e^{\alpha x}}{Z}\,dx - \left(\int_{-B}^{B} x \frac{e^{\alpha x}}{Z}\,dx\right)^2}$$

То есть `spread = B/√3` — это **частный случай** при `α = 0`.

## Для ребёнка

> **Нет «нормального» диапазона вообще. Есть диапазон, зависящий от того, насколько ребёнка толкают и насколько ему шумно.**

`spread = f(μ/σ²)` — одна кривая, и она **всегда** ниже `B/√3`, кроме точки `μ = 0`.

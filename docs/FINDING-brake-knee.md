# Находка: тормоз имеет плато, потом обрыв

**Дата:** 2026-11-10
**Проект:** МАРФАГЕНЕЗ++
**Где:** `core/tests/threshold_brake.rs`, `core/tests/brake_knee.rs`

---

## Что проверяли

Прошлый раунд: **демпфирование** (убирает долю каждого шага) имеет порог у `d = 1`.

Здесь другое: **тормоз** — ребёнок тормозит **только большие шаги**. Маленькие проходят нетронутыми.

## Что предсказал

Что тормоз будет сужать **постепенно**, без обрыва — в отличие от демпфирования.

**Предсказание не подтвердилось.** Вышло **плато, потом обрыв** — третья форма.

## Результат

| limit | разброс / закон |
|---|---|
| 1.00 | 1.002 |
| 0.60 | 0.999 |
| 0.40 | 0.993 |
| **0.30** | **0.978** ← уровень шума |
| 0.25 | 0.973 |
| 0.20 | 0.968 |
| 0.10 | 0.945 |
| 0.05 | 0.933 |
| 0.02 | 0.879 |
| **0.01** | **0.634** |

> **Плато до уровня шума, потом обрыв.**

## Почему колено на уровне шума

Тормоз режет шаги больше `limit`. Типичный шаг — это шум `σ = 0.3`.

- пока `limit > σ` — почти ни один шаг не режется, ребёнок не тронут
- когда `limit < σ` — тормоз начинает резать **обычный шум**, движение уменьшается
- когда `limit ≪ σ` — режется почти всё, ребёнок почти стоит

$$\text{колено} \approx \sigma$$

## Три формы реакции

| реакция | форма | порог |
|---|---|---|
| **тяга к позиции** | плавное сужение | нет |
| **демпфирование** | медленно, потом обрыв | `d → 1` |
| **тормоз** | плато, потом обрыв | `limit ≈ σ` |

## Почему тормоз мягче демпфирования

| | при максимуме | разброс |
|---|---|---|
| демпфирование `d = 0.99` | убирает 99% шага | **0.349** |
| тормоз `limit = 0.01` | режет всё больше 0.01 | **0.634** |

Демпфирование убирает **движение**. Тормоз режет **шаг** — а на следующем шаге шум приходит снова.

> **Резать шаг мягче, чем гасить движение.**

## Для ребёнка

| что делает | что происходит |
|---|---|
| не тормозит | закон |
| тормозит только большие шаги | **почти ничего** (пока порог выше обычного) |
| тормозит обычные шаги | сужается |
| тормозит всё | сильно сужается, но не пришпилен |

> **Тормозить «только крайности» почти ничего не меняет. Тормозить обычное — меняет.**

## Связь с прошлым проектом

В `medium` было: обрезка (`clip`) создаёт атом на стене. Тормоз — это **не** обрезка: он не двигает ребёнка к фиксированной точке, а уменьшает шаг.

Поэтому тормоз мягче. Но он всё равно **режет хвост**, и это сужает.

## Честная оговорка

Проверен один вид тормоза: режем до `limit`, сохраняя направление. Есть другие (полный стоп при превышении, тормоз с задержкой) — не проверены.

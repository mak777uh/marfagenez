собственных проверок. **Порядок — по цене ошибки, а не по цене работы:** сначала то, что не даёт врать,

## Порядок работ

### U1. B-min: контракт литературы и независимая проверка — ✅ сделано (цикл 384)
**Что:** в каждую `### L-NNN` — JSON-блок (схема ниже); `kg/migrate.py` читает блоки, а не прозу; новый
`checks/literature_contract.py` **не импортирует** `migrate` — парсит реестр сам; обратный индекс
`papers/ ↔ L-NNN`; проза «Проверено» генерируется из блока; `kg/literature-overrides.json` поглощается
блоками и удаляется.
**Зачем:** сейчас реестр — проза, а проверка — её же парсер (слепота `regress.py` на новом этаже).
**Готово:** подлог «fulltext без файла» ⇒ FAIL; пустой файл ⇒ FAIL; sha не совпал ⇒ FAIL; файл в `papers/`
без записи `≥ fragment_read` ⇒ FAIL; проза расходится с блоком ⇒ FAIL; `override`-ключ без L-записи ⇒ FAIL.
**Схема:** `locator{doi, arxiv, arxiv_version, openalex, pmid}`, `access{level, artifact, sha256, bytes,
retrieved_at, via, via_detail}`, `inspection{scope, reviewed_ranges[{type: section|page|lines, from, to}]}`,
`bibliographic{title, year, first_author}`, `legacy`, `legacy_reason`. Таблица `level → (provenance, strength)`
— **данными в коде**: full ⇒ verified/strong, fragment ⇒ verified/moderate, abstract ⇒ extracted/weak,
metadata/secondary ⇒ extracted/weak + `secondary_of`.

### U2. Абстракты: отпечаток вместо текста — правило R7 включено; покрытие считается (`tools/lit_coverage.py`), отпечатки для 24 записей требуют прогона добычи
**Что:** `abstract_sha256` обязателен для `abstract_read`; `via` — перечисление каналов; кэш текста только
для CC0-каналов (OpenAlex, arXiv-metadata); правило нормализации записано (NFC, схлопывание пробелов,
реконструкция из inverted index).
**Зачем:** Crossref-абстракты под копирайтом издателя, репозиторий публичный — кэшировать нельзя.
**Готово:** `abstract_read` без отпечатка ⇒ FAIL; количественный claim, опирающийся только на абстракт без
артефакта ⇒ FAIL.

### U3. Двунаправленность правила PROTOCOL — 0,5 круга
**Что:** «назван ⇒ запускается ⇒ файл существует»; «вызовом» считать строку запуска, а не упоминание в
комментарии; `JUDGES` пополнить `audit.js` и `verify_all.js`; selftest на три подлога.
**Зачем:** мёртвая строка в PROTOCOL — та же ложь, что неназванная проверка.
**Готово:** удалить строку для `.sh` ⇒ FAIL; добавить строку на несуществующий файл ⇒ FAIL; упомянуть
`checks/x.py` в комментарии ⇒ не считается вызовом.

### U4. Allowlist для `results/` — 0,5 круга
**Что:** `checks/results_allowlist.py` — замкнутый список паттернов (`run-*.json`, `summary*.json`,

**Готово:** `results/litsearch/x.json` ⇒ FAIL; текущее дерево зелёное; перепись печатается.

### U5. `litsearch`: три канала, RRF, снимок — 1,5 круга
**Что:** `tools/litsearch.py`; дедуп до fusion (`doi → arxiv → pmid → title_norm+year`); RRF `k=60`, равные
веса; снимок `literature/runs/<run_id>.json` + `raw/<channel>.json.gz` со sha; **истина — ранги, RRF —
производное**; тай-брейк и `k` — константы схемы; `checks/litsearch_contract.py` пересчитывает дедуп, RRF,
`degraded`, `saturation` офлайн; `--offline --from-run`.
**Зачем:** сейчас поиск есть, истории и проверяемости нет.
**Готово:** правка `rrf` без правки рангов ⇒ FAIL; два replay побайтово равны; `status: error` при
`degraded:false` ⇒ FAIL.

### U6. Кэш и бюджет — 0,5 круга
**Что:** кэш `sha256(endpoint + канонические параметры + версия парсера)`; `--offline` (ноль сети и ноль
списаний); леджер **`literature/budget/openalex.jsonl`** (не `results/`); политика: предупреждение при

**Готово:** при остатке $0.05 прогон идёт без OpenAlex и помечен `degraded`; `--offline` не пишет в леджер;

### U7. Inbox и карантин кандидатов — 1 круг
**Что:** `literature/inbox/<run>.json` (пишет добыча) → `kg/candidates.jsonl` (мержит оркестратор);
`kg.py ingest-lit` (дедуп против графа, карантина и **tombstones**); литературный `admit` пишет L-блок,
событие в существующий `kg/admissions.jsonl` и ребро; без ребра к существующему узлу или `gap` — отказ.
**Зачем:** поля `lifecycle` в узлах нет, а `find` не фильтрует — кандидаты в `nodes.jsonl` сразу меняют
навигацию.
**Готово:** ingest 50 кандидатов не меняет `wc -l nodes.jsonl` и вывод `map`; admit без ребра отказывает;
повторный ingest отклонённого tombstone не создаёт кандидата.

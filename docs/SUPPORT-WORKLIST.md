## Как этим пользоваться

1. Берём линию, где больше всего **формул** — там есть что измерять.
2. Для каждой формулы выписываем её величины (например, `D_cap`, `C0`, `P`) и ищем работы с числами.
3. Утверждения без формулы ищутся хуже: у них нет величины, только качественное содержание.
4. Дыры (`gap`) не ищем — они уже фиксируют, что не нашли.

# Находка: нет оптимума — есть насыщение

**Дата:** 2026-11-11
**Проект:** МАРФАГЕНЕЗ++
**Где:** `core/tests/optimal_width.rs`, `checks/width.py`

---

## Что предсказал

Что есть **оптимум ширины** комнаты: слишком узко — мало диапазона, слишком широко — не успеет заполнить.

$$B^* = \sigma\sqrt{T}$$

**Оптимума нет.** Измеренный всегда на краю: `B=40`, `B=32` — самый широкий.

## Что на самом деле

| `B` | закон `B/√3` | измерено | доля закона |
|---|---|---|---|
| 1 | 0.58 | 0.577 | **99.9%** |
| 2 | 1.15 | 1.189 | 102.9% |
| 4 | 2.31 | 2.350 | 101.8% |
| 8 | 4.62 | 4.458 | 96.5% |
| 16 | 9.24 | 8.006 | 86.7% |
| **32** | 18.48 | **9.324** | 50.5% |
| **64** | 36.95 | **9.326** | 25.2% |
| **128** | 73.90 | **9.326** | 12.6% |

**Разброс растёт с `B` до 32, потом останавливается.**

## Правильная формула

$$\text{spread}(t, B) = \min\left(\sigma\sqrt{t},\ \frac{B}{\sqrt{3}}\right)$$

- **ниже насыщения** — стена давит, разброс `B/√3`
- **выше насыщения** — ребёнок не доходит до стены, разброс `σ√t`

Ширина насыщения — где они встречаются:

$$\sigma\sqrt{t} = \frac{B}{\sqrt{3}} \quad\Rightarrow\quad B_{\text{sat}} = \sqrt{3}\,\sigma\sqrt{t}$$

Для `σ = 0.3`, `t = 1000`: `B_sat = 16.4`.

## Проверка

| `B` | измерено | `σ√t` |
|---|---|---|
| 32 | 9.601 | 9.487 |
| 64 | 9.613 | 9.487 |
| 128 | 9.613 | 9.487 |

Совпадение до **1.3%**.

## Почему нет оптимума

> **Более широкая комната никогда не даёт меньше диапазона. Она даёт тот же диапазон, как только ребёнок перестаёт доходить до стены.**

Значит выбор ширины — **не компромисс**. Любая комната шириной ≥ `B_sat` так же хороша, как любая другая. Уже — ограничивает.

## Формула для практики

$$\text{spread} = \min\left(\sigma\sqrt{t},\ \frac{B}{\sqrt{3}}\right)$$

Чтобы комната не ограничивала:

$$B \ge \sqrt{3}\,\sigma\sqrt{t}$$

## Для ребёнка

| комната | что происходит |
|---|---|
| **уже `B_sat`** | стена ограничивает — диапазон = `B/√3` |
| **шире `B_sat`** | стена не мешает — диапазон = `σ√t` |
| **ещё шире** | **то же самое** |

> **Шире определённого предела комната не даёт ничего. Уже — отнимает.**

Это важнее, чем «оптимум». Оптимум означает компромисс: больше одного — меньше другого. Здесь компромисса нет: **есть порог**, выше которого всё равно.

## Связь с Саммерхиллом

N16: «Саммерхилл — остров, и он должен быть.»

Модель говорит точнее: остров должен быть **достаточно большим**, и не больше. За пределом `B_sat` размер не важен.

## Честная оговорка

Модель одной черты, один шум. `σ√t` — это свободный случайный ход; для одной черты он точен, для многих может отличаться.

Но результат точен в своей области: **в этой модели ширина насыщается, оптимума нет**.

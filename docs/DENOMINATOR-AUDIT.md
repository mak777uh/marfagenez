# Ячейки с несколькими знаменателями — список для проверки на внутренние противоречия

**Дата:** 25.11.2026. **Инструмент:** `python3 tools/cell_denominator_audit.py [--min N] [--json]`.

## Зачем

Агент `probe` нашёл ячейку `DIP39-0008`, где два знаменателя несовместимы: `4,3·10³` частиц на мг белка и
`11·10¹⁰` частиц на грамм печени дают отношение **25,6 кг белка на грамм печени** — физически невозможно.

Этот класс дефекта **дешевле** поиска между разными работами: не нужно сверять условия экспериментов,
достаточно перемножить два числа из одной ячейки.

Инструмент ничего не решает: он выдаёт **список для чтения** — 12 ячеек из 1115, где встречается больше
одного знаменателя.

## Как проверять

1. Взять число при каждом знаменателе.
2. Перемножить/поделить, чтобы перейти к одному знаменателю.
3. Если результат физически невозможен (например, килограммы на грамм) — это внутреннее противоречие.
4. Если результат разумен — записать «проверено», чтобы второй раз не смотреть.

## Ограничения инструмента

- Ловит только те формулировки, что зашиты в паттерны (русские «на мг/г/кг/клетку/м²/см²/мкм²/л/моль/с»,
  английские «per mg/g/cell»). «На 10⁶ клеток» или «на единицу белка» не поймает.
- Рядом с знаменателем берёт **первое** число в окне — иногда соседнее, а не относящееся к делу.
- Поэтому это **список для чтения**, а не приговор: в проверенных вручную 7 из 12 дефекта нет.

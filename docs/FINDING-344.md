# FINDING-344: три «неверифицированных» числа Reznik подтверждены по сырому Dataset S1

**Дата:** 25.11.2026. **Тип:** проверка данных (первоисточник), не измерение.
**Источник:** Reznik, Mehta, Segrè 2013, `10.1371/journal.pcbi.1003195`, Dataset S1,
`https://journals.plos.org/ploscompbiol/article/file?type=supplementary&id=info:doi/10.1371/journal.pcbi.1003195.s001`
— скачан 25.11.2026, 35 198 байт, настоящий XLSX (PK-архив), три листа: `Figure 2`, `Figure 3`, `Figure 5C`.

## Что установлено

Три числа, которые в карте стояли как **неверифицированные** (взяты из пересказа, а не из данных),
найдены в сыром файле **точным совпадением** и с подписями метаболитов:

| число | где | подпись строки |
|---|---|---|
| `−0,0368` (пируват) | `Figure 2`, строка 3, колонка «Shadow Price» | тип ограничения `Glucose`, метаболит `Pyruvate` |
| `−15,1745` (ATP) | `Figure 2`, строка 22 | тип ограничения `Phosphate`, метаболит `ATP` |
| `−9,0416` (UTP) | `Figure 2`, строка 43 | тип ограничения `Uracil`, метаболит `UTP` |

Колонки листа: `Type of Limitation`, `Nutrient Name`, `Normalized Shadow Price`, `Shadow Price`,
`Growth Limitation`, `Metabolite Index`. Числа взяты из колонки **`Shadow Price`**, а не из
нормированной.

## Что это меняет

1. Три числа переходят из «неверифицировано» в «проверено по первоисточнику» — с локатором вида
   «лист, строка, колонка».
2. **Опровергнуто прежнее утверждение**, что PLOS отдаёт TIFF под именем `.xlsx`. Для этого DOI
   `s001` — корректный XLSX; прежняя блокировка была либо на другом URL, либо на другом артефакте.
3. Появились выгрузки: `docs/artifacts/reznik2013-Figure-2.csv`, `-Figure-3.csv`, `-Figure-5C.csv`.

## Воспроизведение

```
python3 tools/reznik_dataset.py --write
```

Скрипт читает XLSX напрямую (zip + XML, без внешних библиотек), печатает листы, ищет записанные числа
и выгружает CSV.

- Что числа означают то, что мы им приписывали: подпись строки говорит «ATP» и «Type of Limitation =
  Phosphate», но связь с нашей моделью — отдельный вывод.
- Что все три листа разобраны полностью: извлечены строки, но не проверена их полнота против рисунков.
- Что другие «неверифицированные» числа карты тоже найдутся: проверены три.

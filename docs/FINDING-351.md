# FINDING-351: Аудит v3 recruitment-формулы — числа подтверждены, граница R(0)=C0 требует оговорки

**Дата:** 25.11.2026. **Агент:** `fast`. **Раунд:** S3-formulas-lean-20261125T055221.
**Объект:** `R(D) = C0·exp(−D/a)·(1 + D/b)` из `docs/FORMULA-DCRITICAL.md` (раздел «v3»).

## Что установлено

1. **Все числа документа воспроизводятся.** При `a=2, b=0.5, C0=1`: `D* = a−b = 1.5`;
   `R(0.01)=1.0149≈1.01`, `R(1.5)=1.8895≈1.89`, `R(5)=0.9029≈0.90` — совпадает с текстом.
   Наклон в нуле `+1.5 = C0(a−b)/(ab) > 0` при `a>b` — знак подтверждён (положительный,
   вопреки первой записи проверки, где я сам перевернул формулу).
2. **Режимы подтверждены численно:** при `a>b` кривая немонотонна (максимум при `D*=a−b`,
   `R→0` при `D→∞`); при `a≤b` — монотонное убывание от `R(0)=C0`.
3. **Граница `R(0)=C0`, а не 0.** В записи v3 стоит голая `R(D)=C0·e^{−D/a}(1+D/b)`:
   при `D=0` она даёт `C0` — ту же структуру дефекта, что была у v1 («ремонт удаляет
   повреждение, которого нет»: `dD/dt = P0 − C0 < 0` при `P0<C0`). В v2 дефект был закрыт
   членом `min(·, k·D)`. Если v3 — поправка только к экспоненциальной ветви, нужно явно
   писать `R(D) = min(C0·e^{−D/a}(1+D/b), k·D)`: иначе формула в текущей записи
   противоречит собственному критерию «`R(0)` должно быть 0».
4. **Предел `a→∞`:** `R → C0(1+D/b)` — мощность ремонта растёт линейно без насыщения;
   математически согласовано, физически означает «ремонтных центров всегда хватает».
   В таблице применимости v3 этот предел не оговорён (есть `a≫90 Гр`, но не `a→∞`).
5. **Единицы согласованы:** `D, a, b` — в «событиях ремонта»; `C0` — события/время;
   `exp(−D/a)` и `(1+D/b)` безразмерны. Дефектов размерности нет.

## На каком основании

- Команда: `python3` с `math.exp`, скрипт в истории раунда (пересчёт `R(D)` на сетке
  `D ∈ {0, 0.01, 0.5, 1.5, 3, 5, 10}`, наклон в нуле конечной разностью, случай `a<b`).
- Локатор: `docs/FORMULA-DCRITICAL.md`, раздел «v3: параметр насыщения относится к
  эндпоинту», строки с формулой `R(D) = C0 · exp(−D/a) · (1 + D/b)` и таблицей режимов.

## Что это НЕ доказывает

- Что v3 неверна: пункт 3 — неоднозначность записи, а не опровержение; с `min(·,k·D)`
  формула корректна и v2 получается при `b→∞`.
- Что параметры `a, b` измеримы: по `docs/FINDING-345.md` `D_cap` расходится >1200 раз
  между эндпоинтами; для v3 это значит, что `a` и `b` по двум точкам не разделяются
  (в документе оговорено).
- Что recruitment-член реален биологически: это формальная гипотеза, подтверждённая
  только направлением (53BP1-фокусы, маркерный эндпоинт).

## Приоритет 0: тавтологии

**Почему первым:** пока они есть, «198 теорем» ничего не значит.

### Найти все

Не только `:= rfl`. Есть три вида:

1. **`X = X := rfl`** — 10 штук, найдены
2. **Вывод в гипотезах** — `theorem f (h : P) : P := h` (как `equal_effort_maximises_growth`)
3. **Условие содержит заключение** — `(h : a < b) : a < b`

### Проверить каждый файл

```
laws/*.lean — 49 файлов
```

Для каждой теоремы ответить:
- что она **утверждает**?
- что она **доказывает**?
- совпадает ли?

### Переклассифицировать

| было | станет |
|---|---|
| `theorem` | `theorem` — если доказано содержательно |
| `theorem` | `-- CONJECTURE:` — если не доказано |
| `theorem` | `-- OBSERVATION:` — если только измерено |

## Приоритет 4: Dimension

Формула `d/(d+2)·R²` — это `E[‖X‖²]` (средний квадрат радиуса), **не** дисперсия координаты.

Дисперсия одной координаты: `R²/(d+2)`.

**Что делать:**
1. Явно назвать, что именно считается
2. Если «разброс» — определить: сумма дисперсий? средняя? корень из суммы?
3. Согласовать Lean, Rust, текст

## Приоритет 5: расширение модели

**Только после 0–4.**

Разбор предлагает:
- векторное состояние `X_i = (x_i1, ..., x_id)`
- зависимости между характеристиками
- память `M_i`
- влияние на среду `E_i`
- самостоятельная смена целей

**Моё замечание:** прежде чем расширять, надо понять, **что именно** даст расширение. Сейчас модель одной черты дала 5 законов. Модель `d` черт дала закон `d/(d+2)` — но он оказался про `E[‖X‖²]`, не про разброс.

Расширение без исправления основания умножит ошибки.

## Главный вывод

> **Не надо пытаться сделать ребёнка, который будет хорошим по нашим меркам. Надо исследовать, как может возникнуть организм, способный самостоятельно поддерживать, изменять и развивать собственную организацию.**

Это точнее исходного манифеста. «Среда не измеряет» — **запрет**, а не **описание**. Нужна **положительная** программа:

- целостность
- восприятие
- память
- действие
- изменение среды
- наследование

---

## Три принципа, которые сохраняются

**1. Не программировать конечный образ организма.**
Мы не решаем заранее, что он обязан стать сложным, разумным, кооперативным.

**2. Не путать заботу с управлением.**
Среда даёт ресурсы, безопасность, условия восстановления. Но не оценивает и не направляет каждый шаг.

**3. Не путать свободу с отсутствием причинных механизмов.**
Организм должен иметь внутренние процессы, обратную связь, память. Без них он просто случайно движется.

**Плюс четвёртый:**
**Среда должна допускать, чтобы организм изменял условия собственного дальнейшего развития.**

## Различение, которого не хватает

| понятие | что это |

| **случайное изменение** | шум |

| **обучение** | изменение поведения на основе опыта |
| **адаптация** | изменение под давлением среды |
| **возникновение организации** | появление новых внутренних структур |
| **наследование** | передача правил развития |
| **эволюция** | изменение популяции через поколения |
| **открытая эволюция** | появление новых типов организации |

**Сейчас всё это смешано в одном слове «развитие».**

# P0 — исправить основание

## P0.1. Шар: fold не сохраняет меру

**Проблема:** `Shape::Ball` использует радиальное складывание без учёта объёма оболочки `r^(d-1)`.

**Проверено:** из внешних точек `chi² = 31 429 297` при ожидании 9.

**Что делать:**
- либо реализовать корректное отражение в шаре (учитывающее геометрию),
- либо **убрать `Shape::Ball` из всех результатов** и оставить только `Box`.

**Мой выбор:** убрать. Шар не даёт ничего, чего не даёт куб, а стоит дорого.

## P0.2. `ball_trait_variance` неверна

```rust
// сейчас
self.half_width.get().powi(2) / self.dims as f64   // R²/d

// должно быть
self.half_width.get().powi(2) / (self.dims as f64 + 2.0)   // R²/(d+2)
```

## P0.3. RNG-корреляция

**Проблема:** `Cycle::born` создаёт `Rng::new(seed)` для начальных состояний, затем `Medium::new(room, seed)` создаёт **тот же** генератор. Первый шум повторяет последовательность начальных координат.

**Что делать:**
- отдельный seed для рождения
- отдельный seed для шума
- тест: проверить корреляцию между начальным состоянием и первым шумом

## P0.4. `Child::new` не проверяет контракт

- документация говорит «отрицательный drive запрещён», код принимает
- начальные координаты не проверяются на `NaN`/`inf`

## P0.5. `build.rs`: заглушка неполная

Заглушка экспортирует 5 функций, мост объявляет 14. При отсутствии Lean — ошибка линковки.

**Что делать:** заглушка на все 14, и тесты **пропускаются**, а не падают.

## P0.6. Развести два понятия

| сейчас | должно быть |
|---|---|
| `OutsideReading::of(&Child)` — разброс между координатами одного | **индивидуальная вариация** |
| `Cycle::read()` — разброс между организмами по координате | **популяционное разнообразие** |

Это разные величины, они не должны называться одинаково.

## P0.7. Насыщение — переклассифицировать

`laws/Saturation.lean` доказывает свойства `min`, не динамику.

**Что делать:** пометить как **арифметическое ядро**, а достижение пределов — как **наблюдение**.

$$\text{энергия: } E_{t+1} = E_t + I_t - C_{\text{maintenance}} - C_{\text{action}}$$

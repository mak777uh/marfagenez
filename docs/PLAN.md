## Главное открытие: Verus меняет архитектуру

Разбор предлагал три пути:

| путь | что даёт | проблема |
|---|---|---|
| **Aeneas** | Rust → Lean | не установлен, beta, ограничения |
| **Lean-first** | всё в Lean | двойная работа, `Float` ≠ `ℝ` |
| **Verus** | **доказать Rust как есть** | **уже установлен, работает** |

> **Verus позволяет доказать свойства реального Rust-кода, не переписывая его.**

Это решает главную проблему: **не нужно две реализации**.

### Как это работает

```rust
// спецификация — на математических int
spec fn saturation_spec(free_walk: u64, wall_law: u64) -> u64 {
    if free_walk < wall_law { free_walk } else { wall_law }
}

// реализация — на машинных u64, с доказанным соответствием
fn saturation(free_walk: u64, wall_law: u64) -> (r: u64)
    ensures r == saturation_spec(free_walk, wall_law),
{
    if free_walk < wall_law { free_walk } else { wall_law }
}
```

**Проверено: 7 verified, 0 errors** — все свойства насыщения из Lean, но для **реального Rust**.

### Что это даёт

| было | стало |
|---|---|
| Lean доказывает `min`, Rust делает своё | **Verus доказывает Rust-код** |
| FFI-мост сравнивает на 309 входах | **доказательство для всех входов** |
| две реализации | **одна** |

## Пересмотр принципа «среда не измеряет»

**Было:** «Среда не измеряет.»

**Проблема:** смешаны три вещи:

| что | влияет на организм? |
|---|---|
| **наблюдение** | нет |
| **оценивание** | нет |
| **обратное воздействие** | **да** |

**Стало:**

> **Наблюдение отделено от управления. Ни один измерительный канал не изменяет динамику организма, если обратное воздействие явно не включено в эксперимент.**

## Правило двух формулировок

| строгая формулировка | допустимая гипотеза |
|---|---|
| Отражённое движение имеет стационарное распределение | Геометрия может влиять на диапазон |
| Адаптивная ширина изменила разброс | Обратная связь может влиять |
| Копирование притягивает к ориентиру | Социальное обучение может уменьшать различия |

**Вторая не следует из первой.**

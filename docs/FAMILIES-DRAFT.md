# Семьи экспериментов: черновик (сгенерировано `tools/exp_families.py`)

**Что это.** Предложение, как сжать записи прогонов в семейства, **не удаляя** ни одного прогона.
Семейство = имя эксперимента + канонические параметры (JSON с сортированными ключами).

## Числа

- прогонов: **407**
- разных имён экспериментов: **110**
- семейств (имя + параметры): **117**
- семейств из одного прогона: **75**
- семейств, где РАЗНЫЕ вердикты (passed и failed) при одинаковых параметрах: **8**
- семейств без вердикта (void / not applicable) — не конфликт: **20**

## Предложение для `kg/`

1. Каждому узлу-прогону добавить поле `data.family` = `<эксперимент>-<8 hex>` (вычисляется
   детерминированно, скрипт выше). Прогоны **не удаляются**.
2. Не вводить новый вид узла: семейство читается группировкой по `data.family`.
3. Если у семейства вердикты расходятся — поле `data.family_conflict: true`, чтобы фронт
   `kg/frontier` это видел.
4. Семейство с прогонами только одного вердикта считается воспроизведённым; с одним прогоном —
   нет (записано как ограничение).

## Чего этот черновик не делает

- Не меняет `kg/` (правка узлов — отдельный шаг `main`).
- Не решает, что считать «семьёй» по смыслу: здесь только механическая группировка по параметрам.
- Не проверяет, что параметры описывают опыт полностью (часть записей — `commit unknown`).

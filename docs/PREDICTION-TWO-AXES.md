# Предсказание: какая критическая скорость следует из измеренных порогов

Сгенерировано `tools/predict_two_axes.py` из принятых ячеек. Скрипт только пересчитывает единицы.

Формула: `(L/L*) + (v/v*)^2 <= 1` (`I-039`). Для проверки нужна `v*` в тех же единицах, что `L*`.
Вывод из принятых чисел: `v* = L* / tau`, где `tau` — время полужизни пула.

## Числа

| величина | значение | источник |
|---|---|---|
| L* (Km деградации) | 6.00e-08 М | `DIP31-0005` |
| tau (полужизнь клиренса) | 48.8 мин = 2928 с | `DIP31-0001` |
| v* = L*/tau | 2.05e-11 М/с | расчёт |
| v* = L*/tau | 1.77e-06 М/сут | расчёт |
| измеренная r_crit у цианобактерий | 0.1378 1/сут | `DIP34-0005` |
| измеренная r_crit у планктона | 0.003 1/сут | `DIP34-0008` |

## Сравнение

Чтобы измеренная критическая скорость цианобактерий (0.1378 1/сут) соответствовала расчётной (1.77e-06 М/сут), критическая нагрузка должна быть:

    L* = v*_измеренная * tau = 0.1378 * 2928 с = 4.67e-03 в единицах относительной нагрузки

То есть если формула верна, система с полужизнью пула 48,8 мин и измеренной критической скоростью 0.1378 1/сут должна обрываться при относительной нагрузке около 0.5% от критической за сутки накопления.

## Что это предсказывает в проверяемой форме

| уровень нагрузки L/L* | предсказание для медленного подхода | для быстрого |
|---|---|---|
| 0.10 | выдерживает скорость до 0.95·v* | срыв задолго до порога по уровню |
| 0.25 | выдерживает скорость до 0.87·v* | срыв задолго до порога по уровню |
| 0.50 | выдерживает скорость до 0.71·v* | срыв задолго до порога по уровню |
| 0.75 | выдерживает скорость до 0.50·v* | срыв задолго до порога по уровню |

## Чем это проверяется

Нужны три числа в одной системе: `L*`, `tau` и хотя бы одна измеренная критическая скорость. Если предсказанная `v*` совпадёт с измеренной в пределах фактора два — форма верна; если разойдётся на порядок — член `v/v*` надо переписать (например, в первой степени).

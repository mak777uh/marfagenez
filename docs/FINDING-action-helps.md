## Инструмент, который надо было написать первым

`checks/viability.py`:

```
нужно на организм: 0.630 за шаг
поле даёт:         0.800 за шаг
запас:             +27%

Мир жизнеспособен.
```

**Формула:**

$$\text{supply} = \frac{\text{rich\_cells} \times \text{RICH} \times \text{REGROW}}{n_{\text{org}}}$$

$$\text{need} = \text{maintenance} + \text{damage\_rate} \times \text{repair\_cost}$$

**Нужно `supply > need`.**

## Результат

| условие | выживаемость | ходов |
|---|---|---|
| **A** не двигается | **85.0%** | 0 |
| **B** к соседу | **100.0%** | 235 |
| **C** случайно | **42.5%** | 41354 |

| сравнение | разница |
|---|---|
| **B против A** | **+15.0%** |
| **B против C** | **+57.5%** |

> **Действие помогает: 85% → 100%.**
> **Умное правило лучше случайного: 100% против 42.5%.**

---

## Почему случайное хуже

`C` сделал **41354** ходов против **235** у `B`.

Каждый ход стоит `0.1` энергии. `41354 × 0.1 = 4135` энергии потрачено зря.

`B` двигается **только когда есть смысл** — 235 раз.

> **Действие помогает не потому, что двигаться хорошо, а потому что
> двигаться в нужный момент лучше, чем двигаться всегда.**

## Закон

$$\text{выгода} = \text{доступ к ресурсу} - \text{стоимость хода}$$

| условие | ходов | стоимость | выгода |
|---|---|---|---|
| A | 0 | 0 | нет доступа |
| **B** | 235 | **23.5** | **есть доступ** |
| C | 41354 | **4135** | доступ есть, но цена огромна |

**B — оптимум:** достаточно ходов для доступа, мало для экономии.

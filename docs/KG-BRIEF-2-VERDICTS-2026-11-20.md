# KG-BRIEF-2-VERDICTS-2026-11-20.md — решения по D-01…D-14

**Дата:** 2026-11-20. **Что это:** итог двух разборов [`docs/KG-BRIEF-2.md`](KG-BRIEF-2.md). Формат — решение +
проверяемое следствие. Там, где разборы расходились, выбран более строгий вариант и сказано почему.

---

## 1. Решения

| D | решение | проверяемое следствие |
|---|---|---|
| **D-01** | 10 частей замораживаются как словарь; **«сырьё» — не 11-я линия, а стадия** (`stage` у `run`/`finding`) | линия только у `claim`; инвариант «живой узел не ссылается на deprecated-линию» |
| **D-02** | `lines: [..]` + primary + канонический порядок + дедуп; предупреждение при `len(lines) > 3` | счётчики: «узлов» и «инцидентов» печатаются раздельно, Σ по линиям == Σ `len(lines)` |
| **D-03** | парсер + **стратифицированный** спот-чек (≥1 на линию, все «угаданные» ячейки); парсер fail-closed | `unparsed` вместо пустой линии; у разметки своя provenance (`method: parsed`, commit, checked_by); откат линии при >10 % ошибок |
| **D-04** | `kind: correspondence` отдельно; направленный (`left`/`right` в `data`) | нет рёбер `supports/refutes` из моста в claim; оба полюса обязаны существовать |
| **D-05** | **лестница** `draft → complete → exam_ready` вместо привязки к E-id; два свидетельства — **по одному с каждой стороны**; пустые `lost_assumptions` требуют `justification` | экзамен требует `exam_ready`; «≤ 2 шага» признан почти вакуумным и заменён полнотой полей |
| **D-06** | `same_as` claim↔литература **снят сразу**, заменён на `analogous_to` | `check` = **ошибка**, не предупреждение: `same_as` только claim↔claim |
| **D-07** | механическое ребро — **тип** `candidate_supports`, не `supports: weak` | степень узла для глубины считается только по эпистемическим рёбрам; повышение — отдельный глагол |
| **D-08** | ключ идемпотентности — по **фрагменту**: `(source_path, locator, hash(норм. текст))` | правка → новый узел + `supersedes`; старый остаётся `superseded` |
| **D-09** | `triage_status` отдельно от `provenance`; фильтр **и промежуточных** узлов `expand` | одна функция `hidden()`; `provenance=extracted` больше ничего не прячет само |
| **D-10** | круг = объект с замороженным манифестом (`round_id`, ids, `graph_hash`, seed, версия импортёра) | экзамен каждый круг — только dev-28; holdout — по вехам |
| **D-11** | `preflight` обязателен и **проверяется артефакт** (штамп + свежесть `graph_hash`), а не намерение | строка в `AGENTS.md` §1; проверка в `checks/experiment.py` |
| **D-12** | штамп: запросы, scope, k, top-N, commit, `graph_hash`, время + **статус** `MATCHES / NO_MATCHES / PARTIAL / ERROR` | «не найдено» ≠ «ошибка поиска» |
| **D-13** | dev гоняет агент, **holdout гоняет владелец**; изоляция ролью, а не `.gitignore` | canary-строка в gold; каталог `kg/eval` исключён из `ingest`; лимит предъявлений holdout |
| **D-14** | независимая разметка (commit-reveal), **raw agreement + κ + матрица ошибок**; допуск `κ̂ ≥ 0.7` **и** нижняя граница bootstrap ≥ 0.55, либо n ≥ 80 | смена модели/промпта аннулирует κ → рекалибровка |

**Три «иначе», принятые против моего брифа:** D-06 (снять `same_as` сразу, а не предупреждать), D-07
(`candidate_supports` вместо `supports: weak`), D-09 (`triage_status` вместо фильтра по `provenance`).

## 2. Что уже сделано в коде (этот цикл)

| решение | изменение |
|---|---|
| D-06 | четыре связи `C-003↔L-060`, `C-004↔L-051`, `C-005↔L-023`, `C-006↔L-065` переведены в `analogous_to`; в `check` добавлен инвариант «`same_as` только claim↔claim» — теперь это **ошибка** |
| D-04 | словарь получил `correspondence`; инвариант: оба полюса существуют, из моста нет `supports/refutes` в claim |
| D-07 | в словарь добавлены `candidate_supports`, `tested_in`, `stated_in`; набор `EPISTEMIC_RELATIONS` считает степень для глубины `expand` |
| D-09 | функция `hidden()`: прячет только `triage_status=quarantined`; `expand` фильтрует **и промежуточные** узлы |
| D-12 | `graph_hash()` — канонический (по содержимому, не по байтам); штамп `preflight` печатается JSON-строкой со статусом и commit |

Отдельная находка по ходу: первая версия патча перезаписала множество статусов `EPISTEMIC`, и `check` сразу показал
«bad epistemic» на 88 литературных узлах — инвариант поймал ошибку за один прогон, что и есть его назначение.

## 4. Порядок, уточнённый после разборов

1. **Круг 1:** словарь 10 частей + `lines` + канонический порядок + разметка 8 своих утверждений + пропаганация
   литературы с `provenance: parsed`. Инвариант D-06 уже в силе.
2. **Круг 2:** 15–20 мостов как `correspondence` со лестницей `draft → complete → exam_ready`; полные тексты под них;
   `connectivity` должна дать **одну** компоненту (сейчас три).
3. **Круг 3:** `ingest` с ключом по фрагменту, `triage_status`, `candidate_supports`, манифест круга; полный экзамен
   с новым `graph_hash` как точкой отсчёта.

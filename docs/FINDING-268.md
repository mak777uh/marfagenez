# FINDING-268. Замкнутый круговорот **возможен**: форма живёт на собственном распаде

**Слону:** это первый случай в проекте, когда форма **живёт без внешнего притока** — только на том, что сама
возвращает в среду. Она **участвует в формировании условий собственного дальнейшего существования** не
метафорой, а арифметикой: то, что она теряет, среда перерабатывает, и она этим живёт. Третья часть цели
(`GOAL.md` §1) впервые выражена числом.

**Дата:** 2026-11-19. **Статус:** все предсказания `passed`, включая новое. **Цикл:** 231.

## Механизм

`SkinCycle` в `core/src/skin.rs`: среда с **двумя** видами вещества —

```
ready     то, что форма может взять
spent     то, что вернул её распад — в таком виде непригодно
convert   доля spent, которую среда перерабатывает в ready за шаг
```

`core/examples/skin_cycle_arithmetic.rs`, одна форма, **внешний приток 0**, начальный запас 100.

## 1. Арифметика: сколько берёт и сколько возвращает

```
берёт     c·u_min = 10 · 0.01 = 0.100 в шаг     (цена того, чтобы оставаться целым)
возвращает q·d    = 1.0 · 0.05 = 0.050 в шаг    (то, что даёт распад)
```

**Берёт вдвое больше, чем возвращает.**

## 2. Проверка: переработка не спасает

| переработка | живых | `ready` | `spent` |
|---|---|---|---|
| **0.0** (нет) | **0** | 0.0 | **11.8** |
| 0.5 | **0** | 0.0 | 0.0 |
| **1.0** (полная) | **0** | 0.0 | 0.0 |

При полной переработке форма **всё равно гибнет** — потому что берёт вдвое больше, чем возвращает. **Никакая
скорость переработки не замыкает круг.**

## 3. Условие замыкания — и оно выполнимо

Круговорот замыкается, когда **возвращается не меньше, чем берётся**:

```
c·u_min  ≤  q·d          берёт не больше, чем возвращает
c·d·q_min ≤ q·d          подставив u_min = d·q_min
c·q_min  ≤  q            d сокращается
```

При установившемся режиме на пороге `q = q_min = 0.2`, поэтому:

```
c ≤ 1
```

**Проверено:**

| цена кожи `c` | переработка 1.0, приток 0 | живых | шагов |
|---|---|---|---|
| **1.0** | **да** | **1** | **200 000** |
| 2.0 | нет | 0 | — |
| 4.0 | нет | 0 | — |
| 6.0 | нет | 0 | — |

> **Форма с ценой кожи 1 живёт 200 000 шагов без единой молекулы извне — только на собственном распаде.**

## Что это доказывает

- **Замкнутый обмен возможен** и замыкается он **не переработкой**, а **ценой**: скорость переработки не
  помогает, а отношение «берёт / возвращает» — решает.
- **Критерий точный и выводимый:** `c·q_min ≤ q`, при работе у порога `c ≤ 1`.
- **Форма может быть своим поставщиком** — впервые в проекте.

## Что это не доказывает

- **Это одна форма без рождения и смерти.** Круговорот замкнут для одной особи; выдержит ли он популяцию —
  не проверено: конкуренция за `ready` может обратить его.
- Замыкание **маргинально**: при `c = 1` равенство выполняется впритык, и любая дополнительная трата
  (поддержание больше нуля) его ломает. В эксперименте `maintenance = 0`.
- Не проверено, устойчив ли круговорот к колебаниям `q` — при `q < q_min` форма уже мертва.

## Что дальше — предсказание до кода

**Популяция на замкнутом круговороте:** несколько форм, `c = 1`, приток 0, общий `ready`/`spent`.

**Предсказание:** популяция **не выживет целиком** — каждая форма берёт `c·u_min` и возвращает `q·d`, но
`ready` перерабатывается с задержкой, и при `n` формах суммарный спрос `n·c·u_min` превысит возврат
`n·q·d` только если `q < q_min`. То есть **круговорот замкнут на особь, но не на популяцию**: суммарное
равенство сохраняется, и вопрос в том, успевает ли `ready` дойти до всех. Проверка покажет, распадается ли
общий круговорот на «жадных и голодных».

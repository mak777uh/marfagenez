# Колеблющийся ресурс и сосуществование стратегий ремонта

Сгенерировано `python3 tools/core_variable.py`. Числа — результат прогона.

## Постановка

```
две стратегии: фиксированная (cR=2 всегда) и адаптивная (cR=1 при D<0.5, cR=3 иначе)
богато: uptake = 5.0, скудно: uptake = 2.2
60 поколений, логистическая ёмкость 2000, потолок энергии 3
```

|---|---|---|---|
| постоянно богато | 459.2 | 0.500 | 0.500 |
| постоянно скудно | 460.6 | 0.000 | 1.000 |
| чередование 1/1 | 433.5 | 0.000 | 1.000 |

## Что это значит

При постоянной скудости дорогая стратегия погибает (доля 0.000). При чередовании
от 2 поколений её доля 0.500, то есть она выживает. Гибнет она только при
чередовании каждый раз (1/1).

**Механизм не в буфере энергии.** Каждое поколение начинается с одинаковым запасом (E=1),
поэтому переносить запас между поколениями нечем. Спасает другое: в богатые поколения груз
падает, и следующее скупое поколение стоит дешевле — ремонт дешевле просто потому, что
ремонтировать нечего. При чередовании каждый раз груз не успевает упасть, и дорогая стратегия
платит полную цену каждое поколение.

| 8 | 0.500 | 0.500 |
| 9 | 0.500 | 0.500 |
| 10 | 0.500 | 0.500 |

**Гипотеза не подтвердилась:** порог не сдвигается при изменении буфера — в обоих случаях он
между 1 и 2 поколениями. Значит дело не в запасе энергии, а в грузе, накопленном за предыдущий
период. Это отрицательный результат для исходной гипотезы и положительный для механизма груза.

## Оговорки

- Стратегии — mean-field, по одной особи-представителю; вариации внутри стратегии нет.
- Нет мутаций и нет переключения стратегий: доли меняются только размножением и гибелью.
- Потолок энергии (3) и ёмкость (2000) выбраны произвольно; важен знак эффекта, а не
  конкретные доли.

# FINDING-340. κ-схема и абсолютная поддержка неразличимы, пока κ выводится из данных

**Слону:** снимает ещё одну мнимую проверку. План (фаза 1.3) предполагал различить две записи поддержания:
абсолютную (`income − maintenance ≥ dr·rc`) и κ-схему (`maintenance = κ·income`), — по тому, ляжет ли
граница на одну кривую в координатах `ρ_s` или `ρ_s^κ`. Анализ показывает: **пока κ вычисляется из тех же
данных** (`κ = maintenance/income`), величины `ρ_s` и `ρ_s^κ` **тождественны** — различие машинной точности
(5·10⁻¹⁷). Различить схемы можно только при **экзогенной** κ, и тогда разница огромна.

**Дата:** 2026-11-24. **Статус:** `passed` (постановка уточнена). **Цикл:** 526.

## Числа

Из `core/src/organism.rs` (по умолчанию): `income = 1.0`, `maintenance_cost = 0.6`,
`repair_cost = 1.5`, `damage_rate = 0.01`, значит `dr·rc = 0.015`.

| схема | граница по доходу |
|---|---|
| абсолютная: `income ≥ maintenance + dr·rc` | **0.615** |
| κ-схема с экзогенной κ = 0.5: `income ≥ dr·rc/(1−κ)` | **0.03** |

Эндогенная κ по умолчанию: `κ = 0.6/1.0 = 0.6`. Тогда

| `income` | `ρ_s` | `ρ_s^κ` | разница |
|---|---|---|---|
| 0.70 | 0.1500 | 0.1500 | 5.5·10⁻¹⁷ |
| 0.80 | 0.0750 | 0.0750 | 1.4·10⁻¹⁷ |
| 1.00 | 0.0375 | 0.0375 | 0 |
| 1.50 | 0.0167 | 0.0167 | 3.5·10⁻¹⁸ |
| 2.00 | 0.0107 | 0.0107 | 0 |

## Почему тождество неизбежно

`ρ_s = dr·rc/(income − maintenance)`, `ρ_s^κ = dr·rc/((1−κ)·income)`.
Если `κ = maintenance/income`, то `(1−κ)·income = income − maintenance` — **знаменатели совпадают
тождественно**. Никакой тест на данных не может различить эти две записи: они одна и та же функция.

## Что различие даёт на самом деле

Схемы различаются не «инвариантом», а **тем, что остаётся неизменным при смене дохода**:

- абсолютная: порог — **сдвиг** (`income* = maintenance + dr·rc = 0.615`), поддержка не зависит от дохода;
- κ-схема с фиксированной κ: порог — **пропорция** (`income* = dr·rc/(1−κ) = 0.03`), поддержка растёт
  вместе с доходом.

Числа показывают, что разница измерима: при `income = 0.03` κ-схема уже жизнеспособна, а абсолютная —
ещё нет; при `income = 0.1` абсолютная всё ещё не проходит, а κ-схема проходит с запасом.

## Вердикт

**Тест «в ρ_s расползётся, в ρ_s^κ ляжет» в прежней постановке не выполним:** он требует экзогенной κ,
которой в модели нет. Правильная проверка: задать κ **параметром** (поддержание как доля дохода) и сравнить
**положение границы по доходу** — сдвиг 0.615 против пропорции 0.03.

## Что это доказывает

- Две записи поддержания, которые считались разными гипотезами, при эндогенной κ — **одна и та же формула**.
- Различить их можно только структурным изменением модели (κ как параметр), и это изменение измеримо.

## Что это не доказывает

- Не говорит, какая схема верна для живого: обе — записи, а не измерения.
- Не проверяет κ-схему в прогоне: числа выше получены решением неравенства, а не симуляцией.

# Заметка для внешнего анализа

Здесь собираем всё интересное извне, чтобы потом разложить по карте и решить, что делать.

**Правило этой заметки:** пишем сырое, не фильтруя, но **каждый пункт помечаем**, проверен он или нет.
Непроверенное не идёт в карту — только сюда.

## Как помечать

- `[проверено]` — я открыл первоисточник и сверил дословно;
- `[не проверено]` — указатель, цитату не сверял;
- `[противоречит]` — расходится с тем, что уже в карте, с указанием ячейки;
- `[новое]` — этого у нас нет вообще.

**Что уже известно и не нужно присылать повторно:**

- квадрат в формуле не поддержан (лог-линейный закон у бактерий, экспонента лучше на радиации,
  показатели 0,15–0,76 у семи сталей);
- есть оптимум по темпу (ооциты 187 °C/мин, K562 180–5000 °C/мин);
- порог асимметричен (1,87× в криобиологии; 3 против 27–42 мОсм/мин в осмосе);
- взаимодействие скоростей включается только выше порога (T-клетки: 70-кратный диапазон без эффекта);
- смертность организмов — смесь распределений (ΔBIC 167,23);
- единой безразмерной оси в размерных единицах нет; ось строится через безразмерные числа
  (Дамкёлер, Пекле, Дина, Тиле, Био).

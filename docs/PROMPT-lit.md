## 0. Что за проект (три строки)

## 2. Задача раунда

В карте есть ячейки **без единой связи** (сейчас 283 из 1105). Они не находятся обходом и не влияют ни на
что. Прочитай группу и свяжи по роли.

```bash
python3 tools/map_orphans.py                 # сколько сирот и по каким группам
python3 tools/map_orphans.py --group DIP34   # список сирот одной группы
python3 tools/map.py zoom --atom DIP34-0001  # ПОЛНЫЙ текст ячейки: statement, формула, цитата, DOI, локатор
```

Возьми **одну группу** (например `DIP34`, 9 сирот). Прочитай **каждую** ячейку через `zoom`. Затем найди
для неё связную ячейку того же домена и определи **роль**:

| роль | тип | когда ставить |
|---|---|---|
| уточнение той же величины | `refines` | тот же предмет, больше деталей, другой диапазон |
| зависимость | `requires` | без этой величины утверждение не формулируется |
| расхождение | `contradicts` | две ячейки утверждают разное об одном |
| обобщение | `generalizes` | общая форма охватывает частный случай |
| следствие | `derives` | формула выводится из определения |
| другой механизм того же | `analogous` | **не больше одного за раунд** |

## 3. Три правила, из-за которых чаще всего отказывают

1. **Порядок величин.** Ставя `refines`, пересчитай обе величины в одну единицу. Ребро между 72 519 Дж/м² и
   0,12 Дж/м² уже было ошибочно поставлено как `refines` — различие 10⁶ раз. Если порядки разные — это
   `analogous` или связи нет.
2. **`analogous` — не больше одного за раунд.** В карте 29 % аналогий при потолке 1/3; карта не должна
   превратиться в метафоры.
3. **Ячейка без связи не принимается вообще** (правило цеттелькастена), но связь «лишь бы была» не считается:
   если роль не читается — так и напиши, это результат.

## 4. Куда класть результат (единственное место, куда ты пишешь)

Файл: **`literature/map/inbox/lit-<YYYYMMDD-HHMM>.jsonl`**

Строки — только связи, по одной JSON на строку:

```json
{"from": "DIP34-0001", "to": "DIP34-0002", "type": "refines", "note": "чем именно уточняет — одной фразой"}
{"from": "DIP34-0003", "to": "FAST-S2K-01", "type": "requires", "note": "без какой величины утверждение не формулируется"}
```

- `from` — **сирота** (та, что без связи), `to` — существующая связная ячейка (или наоборот: связь всё равно
  даст сироте степень 1);
- `note` — **причина по существу**, а не «связано по теме». Именно по ней `main` проверяет работу;
- не больше **8 строк** за раунд.

В каталог раунда (его путь печатает `take`) положи `RESULT.md`:

```markdown
# Раунд lit — <дата> — группа DIP34

## Что сделано
Группа DIP34, прочитано 9 ячеек, предложено 7 рёбер.

## Предложенные рёбра
| from | to | тип | основание (кратко) |
|---|---|---|---|

## Что связать не удалось и почему
- DIP34-0007: в домене нет связной ячейки о том же; ближайшие — про другой механизм, аналогию не ставил.

## Проверки
- `python3 checks/map_contract.py` — до приёма карта не меняется, проверка не применима;
- `python3 tools/map_orphans.py` — 283 сироты (до раунда).
```

Затем сдай раунд:

```bash
python3 tools/coord.py finish <каталог-раунда> --agent lit --artifacts literature/map/inbox/lit-<...>.jsonl
```

`main` проверит, примет в карту и закоммитит.

## 5. Чего делать нельзя (нарушение = отказ раунда)

| запрет | почему |
|---|---|
| `git add`, `git commit`, `git push` | история и публикация — только у `main` |
| править `literature/map/atoms.jsonl`, `edges.jsonl` | приём только через `map_ingest` с проверками |
| править `kg/nodes.jsonl`, `checks/`, `run.sh`, `AGENTS.md` | защищённые зоны |
| запускать `bash run.sh all` | `results/` — общий ресурс, гейт гоняет только `main` |
| создавать `docs/FINDING-*.md` | номера выдаёт `tools/new_finding.py`, диапазоны закреплены |
| `pip install`, `apt`, менять окружение | репозиторий должен воспроизводиться у всех |
| писать в чужие области (`literature/map/inbox/fast-*.jsonl`, `ver-*.jsonl`) | конфликт областей |

## 6. Если ты не можешь писать в репозиторий

Пришли в чат **два блока**: содержимое `lit-<...>.jsonl` и `RESULT.md`. `main` положит файл в `inbox`,
примет и закоммитит. Формат тот же — ничего не меняй.

# Находка: `spread = B/√3` — это предел без толчка

**Дата:** 2026-11-10
**Проект:** МАРФАГЕНЕЗ++
**Где:** `checks/consistency.py`, `checks/contradiction.py`

---

## Что искали

Четыре закона в Lean (гонка, реакция, время, мост). Складываются ли они — или противоречат?

Написал проверку: каждое численное предсказание против симуляции.

## Что нашли: противоречие

```
time to wall 25 vs fill 100 — CONTRADICTION
```

Закон времени: при толчке 0.05 стена давит через **25** шагов.
Закон гонки: комната заполняется за **100** шагов.

**Ребёнок сужается раньше, чем заполнит комнату.**

## Что это значит

Запустил обе популяции рядом, из одного старта:

| шаг | свободная | с толчком |
|---|---|---|
| 10 | 1.058 | 1.057 |
| 25 | 1.416 | **1.298** |
| 50 | 1.657 | **1.263** |
| 100 | **1.741** | **1.019** |
| 400 | 1.746 | **0.861** |

Свободная выходит на закон (1.73). С толчком — **падает до 0.86**.

> **`spread = B/√3` — это предел БЕЗ толчка. С толчком базовая линия не устанавливается вообще.**

## Почему это не противоречие законов

Законы описывают **разные режимы**:

| закон | режим |
|---|---|
| гонка | среда отвечает, дети заполняют — **без толчка** |
| время | есть толчок, дети сужаются **до** заполнения |

Противоречие было в **моей проверке**: я требовал, чтобы время до стены было **больше** времени заполнения. Но при толчке 0.05 это не так — и не должно быть.

## Формула

$$\text{spread} = \begin{cases} \dfrac{B}{\sqrt{3}} & \mu = 0 \\[6pt] < \dfrac{B}{\sqrt{3}} & \mu > 0 \end{cases}$$

Толчок **всегда** уводит ниже закона. Базовая линия — это не «нормальное состояние», а **состояние без толчка**.

## Ещё одна находка: `(B/σ)²` точна

Проверка «заполнение за `(B/σ)²`» сначала давала 50 вместо 100. Причина: я мерил **90%** закона, а формула предсказывает **полное** заполнение.

| шаг | разброс / закон |
|---|---|
| 50 | 0.961 |
| 75 | 0.984 |
| **100** | **0.998** ✅ |

При пороге 99% — **измерено 100, предсказано 100**. Точное совпадение.

## Итог проверки

```
PASS  spread = B/sqrt(3)                    1.716 vs 1.732
PASS  fill time ~ (B/sigma)^2 (99%)         measured 100, predicted 100
PASS  zero gain changes nothing             1.768997 vs 1.768997
PASS  time to narrow < B/mu                 measured 31, naive 60
PASS  with a push the wall bites first      25 < 100
PASS  a pushed population stays below law   0.893 vs 1.732
```

**6 из 6.**

## Для ребёнка

> **«Нормальный» диапазон — это диапазон ребёнка, которого никуда не толкают. Любое давление — даже общее, даже доброжелательное — уводит ниже.**

Это уточняет всё, что было раньше. Законы описывали **идеальный случай** — без толчка. Реальный ребёнок всегда под каким-то толчком, и значит **всегда ниже закона**.

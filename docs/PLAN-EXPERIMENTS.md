## Арифметика первого эксперимента (сделана)

**Вопрос из наблюдения:** почему `stay` и `remember` застывают?

### Ресурсный баланс

| величина | значение |
|---|---|
| богатая клетка | 2.0 |
| бедная клетка | 0.2 |
| `income` (макс с клетки) | 0.8 |
| `maintenance` | 0.6 |
| `damage_rate × repair_cost` | 0.02 × 1.5 = **0.03** |
| **тратит за шаг** | **0.63** |
| **берёт на богатой** | **0.80** |
| **берёт на бедной** | **0.20** |
| баланс на богатой | **+0.17** |
| баланс на бедной | **−0.43** |

### Потолок энергии

$$E_{\max} = \text{capacity} - \text{maintenance} - \text{damage\_rate} \cdot \text{repair\_cost}$$

$$E_{\max} = 10.0 - 0.6 - 0.03 = 9.37$$

**Проверено:** `10.0 - 0.6 - 0.03 = 9.370000000000001` ✅

**И в данных:** у `stay` и `remember` **все** организмы на 9.37. У `random` 16 из 21 на 9.37, 5 ниже.

### Вывод арифметики

**`9.370` — это потолок, не равновесие.** Организмы не «успокоились», они **упёрлись в крышу**.

**`stay` и `remember` не двигаются, потому что:**
- `stay` — политика запрещает движение
- `remember` — все уже на запомненной клетке (`best_cell == cell`)

**`random` двигается, попадает на бедные клетки (0.2 < 0.63), теряет энергию и умирает.**

## Что это не доказывает

**Этот план не гарантирует, что эксперимент даст результат.** `failed` или `void` — честные исходы.

**Арифметика может быть неверна.** E1 в прошлом предсказал распад, а все выжили.

**`capacity = 100` может дать неожиданное.** Например, организмы начнут двигаться иначе.

**Один сид.** Нужно проверить на 3+ сидах.

**`damage_rate = 0.10` даёт маленький запас (+0.05).** При 500 шагах хватает, но при 100 — нет (`0.05 × 100 = 5 < 0.12`). Нужно ≥ 3 шага для достижения потолка, но чтобы дойти от 5.0 до 9.25 нужно `(9.25-5.0)/0.05 = 85` шагов.

## Главная находка: переполнение в `ceil(b/μ)`

Формула `ceil(b/μ) = (b + μ − 1) / μ` **переполняется**, если писать буквально.

При `b = u64::MAX − 1`, `μ = 2`:
- `b + μ − 1 = u64::MAX` — влезает
- `b + μ = u64::MAX + 1` — **переполнение**

Verus нашёл это. Правильная форма:

```rust
// неверно при больших b
(b + mu - 1) / mu

// верно
(b + (mu - 1)) / mu
```

> **Verus нашёл баг, которого не нашли тесты.**

## Чего Verus не может

**`f64`.** Вся численная симуляция — на `f64`. Verus не поддерживает плавающую точку.

**Это значит:** целочисленные законы доказаны, численная часть — нет.

---

## Урок про предусловия

Предусловие должно быть в форме, которую **решатель понимает**.

```rust
// не работает: Verus не выводит из этого переполнение
requires b <= u64::MAX - mu + 1

// работает
requires (b as int) + (mu as int) - 1 <= u64::MAX
```

Обе формы эквивалентны математически, но только вторая даёт решателю нужный факт.

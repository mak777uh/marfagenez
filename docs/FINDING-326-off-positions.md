# FINDING-326 — «выключенное положение» проверено трассами, а не обещанием

**Дата:** 2026-11-21. **Основание:** внешний разбор (документация обещает больше, чем проверяет) и собственный тест
`core/tests/off_positions.rs`.

## Что было

В `core/src` больше десятка раз написано, что переключатель в выключенном положении «не меняет записанный прогон ни на
бит». Это утверждение — обещание, а не проверка: сравнения двух прогонов не было. После двух случаев, когда докбук врал
о собственном коде (`AUTONOMY.md:275`, `life.rs:40`), доверять такому тексту без теста нельзя.

## Что стало

`core/tests/off_positions.rs` строит трассу как FNV-1a по полному состоянию после каждого шага (слот, клетка, энергия,
урон, жив) и сравнивает:

| проверка | результат |
|---|---|
| `set_policy_mutation(0.0)` после постройки | трасса совпадает |
| `set_sight_radius(1)` (док: `k <= 1` — исходный путь) | трасса совпадает |
| `enable_claims(0.5, 0.1)` | трасса **отличается** — переключатель живой |
| контроль: `read_cost = 0.5` | трасса **отличается** — сравнение вообще видит различие |

Последняя строка важна не меньше первых: если бы все прогоны давали один хеш, равенства выше ничего не значили.

## Числа

`cd core && cargo test --test off_positions` → **2 passed, 0 failed**. Тестов во всём дереве: **365**.


**Слону:** не про новую часть слона, а про то, что старые части не должны меняться от выключенных
переключателей. Без этого любое «мы проверили на умолчаниях» — обещание, а не измерение.
## Что это значит

- **Обещание стало проверкой.** Теперь «off не меняет биты» — это тест, который может упасть, а не фраза в докбуке.
- **Сравнение с контролем.** Тест на равенство без теста на различие — это половина проверки, и вторая половина
  дешевле первой.
- **`Life` не `Clone`** — и это осознанно; baseline строится вторым прогоном с тем же сидом, а не копией.

## Чего это не доказывает

- Что покрыты **все** переключатели: покрыты те, у которых есть публичный сеттер или поле `World`, и чьё выключенное
  положение докбук называет контрактом.
- Что `read_period = 1`, `look_on_shortfall = false`, `max_population = 0` тоже проверены: они задаются только при
  постройке, и сравнение «явно выключено против умолчания» было бы тавтологией.
- Что трасса ловит всё: хеш видит состояние, но не порядок внутренних чтений; для порядка нужен другой инструмент.

## Команда

    cd core && cargo test --test off_positions

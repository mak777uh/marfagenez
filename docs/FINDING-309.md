# FINDING-309. Решающая проверка: корневой закон точен в пределах **1 %**, а `1/(1−h)` завышает в **6.8 раза**

**Слону:** закрывает вопрос, который делил два закона. При `h` = 0.995 / 0.998 / 0.999 измерено
**12.758 / 20.860 / 30.027**, корневой закон предсказывает **12.86 / 21.05 / 30.30** (совпадение **1 %**), а
`1/(1−h)` — 41 / 102.5 / 205, то есть **в 6.8 раза больше** на последней точке.

**Дата:** 2026-11-19. **Статус:** (a)(b)(c) `passed`. **Цикл:** 277.

## Предсказание, записанное до прогона

Корневой закон даёт 12.9 / 21.1 / 30.3; закон `1/(1−h)` — 41 / 102 / 205. Разница в пять раз — это выбор между
законами.

## Результат (`core/examples/organ_damage_drift.rs`, N = 300, 600 000 шагов)

| `h` | плато измерено | корневой закон | `1/(1−h)` | отношение к корневому |
|---|---|---|---|---|
| 0.995 | **12.758** | 12.86 | 41.00 | **0.99** |
| 0.998 | **20.860** | 21.05 | 102.50 | **0.99** |
| 0.999 | **30.027** | 30.30 | 205.00 | **0.99** |

## Вердикт

**(a) подтверждено:** плато растёт к `h = 1`.

**(b) подтверждено:** совпадение с корневым законом в пределах **1 %** (отношения 0.99).

**(c) подтверждено:** при `h = 0.999` плато — **30.0** против 205 по `1/(1−h)`, то есть **в 6.8 раза** меньше.

## Закон, подтверждённый на семи точках

```
λ·D² + μ₀·D = δ/(1−h)        ⇒        D* = ( −μ₀ + √(μ₀² + 4λδ/(1−h)) ) / (2λ)
```

| `h` | формула | измерено | расхождение |
|---|---|---|---|
| 0.90 | 2.09 | 2.022 | 3 % |
| 0.95 | 3.32 | 3.277 | 1 % |
| 0.98 | 5.85 | 5.798 | 1 % |
| 0.99 | 8.74 | 8.678 | 0.7 % |
| 0.995 | 12.86 | 12.758 | 0.8 % |
| 0.998 | 21.05 | 20.860 | 0.9 % |
| **0.999** | **30.30** | **30.027** | **0.9 %** |

**Три параметра (`μ₀ = 0.0027`, `λ = 0.001`, `δ = 0.001`) заданы заранее и не подгонялись.**

## Что это доказывает

- **Корневая расходимость подтверждена** на трёх порядках приближения к единице.
- **Самоограничение повреждения — не украшение, а механизм:** без него плато росло бы как `1/(1−h)`, то есть в шесть
  раз быстрее на последней точке.
- **Формула работает там, где предсказания расходятся в разы** — то есть это закон, а не подгонка интерполяцией.

## Что это не доказывает

- Не доказывает, что при `h → 1` поведение остаётся корневым **бесконечно**: проверено до 0.999.
- Не проверено, что `μ` линейна по повреждению: это допущение модели.
- Один штамм, без конкуренции; с конкуренцией форма та же, числа иные.

## Ядро выживания: три определения K

При длительной засухе `q` садится на неподвижную точку `q* = 0.02/0.05 = 0.40`: за шаг из запаса берётся не больше `0.02`, а распад — `5 %`. Это число не зависит от `alpha`.

| определение K | что ограничено | проекция на ось alpha | ширина |
|---|---|---|---|
| без засух | `q ≥ 0.5`, `stock ≥ 0` | [0, 1] | 100% |
| смертельная засуха, `q ≥ 0.5` | `q ≥ 0.5` при `k = 400` | **пусто** | 0 % |
| смертельная засуха, `q ≥ q*` | `q ≥ 0.40` при `k = 400` | [0.00, 1] | 100% |

## Сравнение с измеренной полосой

Измерено (`FINDING-314`, режим смертельной засухи): разброс средних времён жизни **10 %** при вершине на `alpha = 0.75`; без засух — **86 %**.

Ширины проекций ядра: 100%, 0%, 100%.

**Предсказание НЕ выполнено.** Ни одно из трёх определений K не даёт ширину 3–10 %: проекция либо **вся ось** (когда ограничение не связывает), либо **пуста** (когда засуха смертельна для `q`).

## Вердикт: **мост провален в текущей формулировке**

Полоса 10 % из `FINDING-314` — это **плато по времени жизни**: при смертельной засухе любая доля выше порога даёт ту же защиту, потому что защищает не доля, а запас, достаточный для пережидания (так это и объяснено в `FINDING-314`). Это **не** проекция ядра выживания на ось доли дохода.

Причина расхождения формулировок: `alpha` — это **управление**, а не координата состояния. Ядро выживания живёт в пространстве состояний `(q, stock)`, и его проекция на ось управления даёт либо всё множество допустимых управлений, либо пустое — третьего не бывает без ограничения на запас.

## Что это значит для картины

1. `CORR-01` в текущей формулировке («полоса = проекция ядра») **неверен**: полоса — плато выигрыша, а не проекция инвариантного множества.
2. `C-006` остаётся `hypothesis`: у него не появилось вычисленной опоры.
3. Проверяемая замена: полоса = **множество управлений с равным выигрышем** (плато по времени жизни), и это уже измерено в `FINDING-314`.

## Чего этот тест не проверяет

- Не проверяет стохастическое ядро (здесь взято детерминированное определение с фиксированной засухой).
- Не проверяет другие K (например, с ограничением на запас сверху).
- Не доказывает, что пик на `alpha = 0.75` — оптимум: проверены пять значений доли.

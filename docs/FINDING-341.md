# FINDING-341 — ремонт падает с повреждением только в фокусных методах

**Дата:** 24.11.2026. **Что проверялось:** есть ли измеренное падение способности ремонта при росте
повреждения — то есть величина `D_cap` из нашей формулы `D_crit = D_cap·ln(C0/P0)`
(`docs/FORMULA-DCRITICAL.md`).

## Ответ: зависит от метода измерения, и это главное

### Где падение есть

| измерение | число | ячейка |
|---|---|---|
| полувремя разрешения фокусов RIF | **1,4 ч** (0,1 Гр) → **2,1 ч** (1 Гр) → **5,7 ± 1,6 ч** (2 Гр) | `DIP59-0001` |
| разрешение фокусов при 2 Гр против 0,1 Гр | примерно **в 5 раз медленнее** | `DIP59-0001` |
| внутри одного ядра: трек HZE (~26 Гр) против delta-лучей (~0,17 Гр) | **~10 ч** против **3,3 ч** | `DIP59-0001` |
| при выключении ATM (2 Гр) | **15,4 ± 1,8 ч** против 5,7 ± 1,6 ч (**2,7×**) | `DIP59-0003` |
| ёмкость BER | насыщение выше **~110 SSB на ядро** | `DIP59-0007` |
| HR при сенесценции | падение **до 38 раз** | `DIP59-0008` |

### Где падения нет — и это прямые контрпримеры

| измерение | число | ячейка |
|---|---|---|
| полувремя репарации DSB (CHO), дозы **3–90 Гр** | **168 ± 10 мин** — одинаково | `DIP59-0005` |
| полувремя 53BP1-фокусов: 500 мГр против 5–10 мГр | **2,7 ± 0,8 ч** против **3,1 ± 0,5 ч** | `DIP59-0006` |
| клиренс polyQ-агрегатов | **≤72 ч** даже при конститутивной экспрессии | `DIP59-0010` |

## Что это значит для нашей формулы

**`D_cap` не нулевая, но не универсальна.** Она существует в измерениях, которые смотрят на
**сборку/разборку фокусов** (видимая кинетика), и отсутствует в измерениях **физических разрывов**
(прямое измерение). То есть «ремонт падает с повреждением» — верно для **видимой работы ремонтной
машины**, но не для её **пропускной способности**.

Есть и второй механизм, который виден только при вмешательстве: выключение ATM замедляет разрешение в
**2,7 раза** при той же дозе. Значит лимит — не только «сколько повреждений», но и **ёмкость пути**.

## Как это меняет формулу

Формулу нельзя записывать с постоянной `D_cap`. Правильнее:

```
C(D) = C0 · exp(−D/D_cap)   — верно для ВИДИМОЙ кинетики (фокусы)
C(D) = C0                    — верно для пропускной способности (физические разрывы)
```

**Опровергающее условие для нашей записи:** если в одном и том же объекте измерить оба показателя и они
разойдутся в одну сторону (фокусы замедляются, физические разрывы восстанавливаются с той же скоростью),
то `D_cap` — артефакт метода, а не свойство системы. Пока такие измерения есть только порознь.

## Чего не хватает

- **Нет работы, где оба метода применены к одной системе.** Это и есть точная формулировка пробела.
- **`k(load)` для деградации белков и поток аутофагии как функция нагрузки** численно не найдены —
  единственный непокрытый пункт задачи дипа.
- Кинетика фокусов измерена у **разных** клеточных линий и доз — прямого сравнения «видимое против
  физического» в одной работе нет.

## Почему это важно

Это **третий случай за исследование**, когда две записи одной величины расходятся из-за метода:
`CORR-01` (набор против оси), κ против ρ_s, и теперь ремонт по фокусам против ремонта по разрывам.
Закономерность: **метод измерения задаёт, будет ли у величины порог.**

# СЛОН-10 — обзор после аудита покрытия и проверки формулы v3

**Дата:** 25.11.2026. **Числа:** литературная карта **1009 ячеек, 592 связи, 65 инсайтов, 34 домена**;
карта знаний **580 узлов**; **строгая опора: 20 из 152 (13 %)** — и это **верхняя оценка**, см. §2.

Обзор без новых ячеек. Опирается на `SYNTHESIS-09`, `FINDING-345`–`FINDING-353`,
`docs/STITCH-ADJUDICATION.md`, `docs/REDTEAM-v2.md`.

---

## 1. Формула: три версии, и каждая появилась после провала предыдущей

| версия | запись | что её опровергло |
|---|---|---|
| v1 | `D_crit = D_cap·ln(C0/P0)` | отрицательная скорость при `D = 0`; «равновесие» неустойчиво |
| v2 | `R(D) = min(C0·exp(−D/D_cap), k·D)` | `D_cap` не переносится между эндпоинтами: RIF-фокусы дают 1,18 Гр, PFGE-разрывы — нижнюю границу >1418 Гр, 53BP1-фокусы — **отрицательный** (`FINDING-345`) |
| **v3** | `R(D) = C0·exp(−D/a)·(1 + D/b)` | пока не опровергнута; **одна** проверка на двух наборах (`FINDING-353`) |

**Что даёт v3.** Максимум при `D* = a − b` (только при `a > b`); v2 — её предельный случай `b → ∞`.
При `a = 0,55`, `b = 0,25` она воспроизводит **оба** отношения, которые v2 не могла совместить:
`R(0,1)/R(2) = 4,92` (цель 5,00) и `R(0,0075)/R(0,5) = 0,841` (цель 0,871), `D* = 0,30 Гр`.

**Честный статус v3:** две степени свободы подогнаны под две цели. Это согласованность, а не
свидетельство. Проверка была бы возможна на третьей точке: `R(1)/R(0,1) = 1,45` — но источник
(Neumaier 2011, PMC3258602) закрыт, и предсказание остаётся **непроверенным**.

## 2. Покрытие: цифра стала меньше, и у неё появился интервал

Аудит вердиктов сшивки (`P44`–`P46`): прочитаны все 51 пара, **`S` понижено 15 из 48 (31 %)**,
`Ch` — 12 из 43 (28 %).

| метрика | значение | что значит |
|---|---|---|
| прежняя (до аудита) | 30 / 152 | есть хоть одна пара |
| после Red Team | 22 / 152 | пара с совпадающей величиной, но вердикт не проверен человеком |
| **после аудита** | **20 / 152** | прочитано человеком, и доля ошибок вердиктов измерена |

**Оценка с интервалом.** Если доля ошибок 31 % сохранится на остальных парах, реальное число лежит в
диапазоне **14–20 узлов** (9–13 %). Публиковать одно число без этой оговорки нельзя.

**Что ещё важно:** «не задан» в `STITCH-TABLE.md` — это незаполненный **признак**, а не отсутствие
вердикта. Классификация этих 57 строк (`P17`) **не увеличивает** строгое покрытие; рост даёт только
поиск пар по величине, как это сработало для `F-029`.

## 3. Что подтверждено, что опровергнуто, что понижено

**Подтверждено по первоисточникам:** Johnson 2020 (порог Hog1 — AND двух условий: 12,1 ± 1,6 мМ/мин и
117,5 ± 34,5 мМ); Mori 2018 (30 DSB/(Гр·клетка)); Grudzenski 2010 (~21 фокус/Гр); Reznik 2013 — три
теневые цены **проверены по сырому Dataset S1** (`−0,0368`, `−15,1745`, `−9,0416`) с локаторами
«лист, строка, колонка».

**Найдено по величине:** `F-029` получила пару по показателю `ε^(2/3)`: прямой переход `p = 0,63 ± 0,10`
согласуется, **обратный** `p = 1` — нет (`FINDING-347`). То есть показатель ограничен направлением
перехода.

**Опровергнуто или понижено:**

- «плато» `F-002` 2,02 / 3,28 / 5,80 / 8,68 — снимки на конечном горизонте, пределы 2 / 4 / 10 / 20;
  источника чисел в репозитории нет (`FINDING-343`, `FINDING-344`);
- «порог» `F-014` `0,37` — это **типичный максимум** `N` гауссовых шумов (превышение ≈ 63 %), а не
  редкое событие;
- `μ₀` в Макегаме по двум точкам **не различим** с `α` (`FINDING-348`-дополнение);
- `κ = 1/PAL` — **тождество**, а не совпадение (`FINDING-349`).

## 4. Новое содержательное: `κ` не константа

DLW-данные спортсменок (атом `MAIN-P49-01`, обзор Park 2019): `PAL` 1,71–3,40, значит доля поддержания
`κ = 1/PAL` лежит в диапазоне **0,29–0,58** (`FINDING-350`). Среднее `κ = 0,57` — только режим покоя;
при соревновательных нагрузках оно падает до 0,3.

**Оговорка:** крайние точки взяты из обзора, первичные работы (Jones 1993, Sjödin 1994) закрыты, и их
абстракты дают `TEE`, но не `PAL` (`P50`).

## 5. Методы: что изменилось

1. **Проверки стали механическими:** `support_sources.py` (у `established` есть источник из четырёх),
   `formula_units_ceiling.py` (долг по единицам не растёт — сейчас 16 из 31),
   `stitch_coverage_floor.py` (строгая опора не падает), `tree_contract.py` (нет проверок без вызова).
2. **Различимость параметров — правило:** если параметры входят произведением, данные различают
   комбинацию (пять подтверждённых случаев). Инструмент `tools/identifiability.py` имеет точность 40 % —
   автоматический поиск не заменяет чтение.
3. **Номера находок выдаёт скрипт** (`O_EXCL`), после случая, когда чужой номер перезаписал находку.

## 8. Чего этот обзор не доказывает

- Что v3 верна: у неё одна подгонка и ноль независимых предсказаний.
- Что 20/152 — точное число: это верхняя оценка с измеренной долей ошибок вердиктов 31 %.
- Что «по величине» найдётся для всех узлов: для `C-006`, `F-002`, `F-006`, `GAP-02` поиск дал ноль
  (`SUPPORT-SEARCH-2`), и он ограничен нашей картой, а не литературой вообще.

## Обновление 25.11.2026: что изменилось после публикации

Обзор датирован, но числа в нём устарели за несколько часов работы. Ниже — датированная поправка, а не
переписывание.

### Покрытие: два счёта вместо одного

Раньше стояло «20 / 152». Правильнее:

| счёт | значение |
|---|---|
| по всем узлам с утверждением (`S`-пара есть) | **22 / 152 (14 %)** |
| из них с собственным `lit_ref` | `20 / 152` |

Причина расхождения: у `F-007` и `L-009` связь с литературой идёт только через пару сшивки. Прежняя
формулировка занижала результат, потому что считала лишь узлы с `lit_ref`. Знаменатель —
`claims + formulas + gaps + correspondences` (116 + 31 + 3 + 2).

**Оценка остаётся верхней:** аудит `P44`–`P46` показал 31 % ошибок в исходных `S`-вердиктах, сплошного
пересчёта не было.

### Формула: v3 не обоснована, рабочая — монотонная

После публикации проверено основание немонотонности: различие `3,1 ± 0,5` против `2,7 ± 0,8` ч у
53BP1-фокусов даёт `z = 0,42`, **`p = 0,672`** — не значимо. На PFGE-эндпоинте recruitment требует роста
мощности ремонта, а данные показывают обратное: RD-модель воспроизводит их без recruitment (числа
проверены независимо: остаток `28,42` против `28,4` в первоисточнике-пересказе).

**Текущая рабочая форма — монотонная (v2).** v3 не опровергнута, но и не обоснована
(`docs/FORMULA-DCRITICAL.md`, раздел «Вердикт на 25.11.2026»).

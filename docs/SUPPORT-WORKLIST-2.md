# SUPPORT-WORKLIST-2 — состояние сшивки по тождеству источника

**Дата:** 2026-11-25, раунд P1-identity-122 (агент fast).

## Что проверено

Для каждого узла `kg/nodes.jsonl` без `data.lit_ref` проверен `data.locator`:
поле `doi` напрямую и DOI-подобные подстроки (`10.XXXX/...`) во всех строковых
полях локатора (`doi`, `url`, `pmid`, `arxiv`, `openalex`). Извлечённые DOI
нормализованы (lowercase, снят префикс `https://doi.org/`, `dx.doi.org/`,
хвостовая пунктуация) и сравнены с DOI из `works[].doi` всех ячеек
`literature/map/atoms.jsonl`.

Дополнительно проверена симметрия уже существующих пар в обе стороны.

## Числа (python3-скрипт подсчёта по двум jsonl, 2026-11-25)

| величина | значение |
|---|---|
| узлов kg всего | 580 |
| узлов с `lit_ref` | 30 (5.2 %) |
| узлов без `lit_ref` | 550 |
| из них с непустым локатором | 56 |
| из них с DOI-подобным идентификатором | 41 (41 уникальный DOI) |
| уникальных DOI в `atoms.jsonl` | 743 (из 999 ячеек) |
| **новых пар по тождеству DOI** | **0** |
| пар «atom→kg_ref без обратного lit_ref» | 0 |
| пар «lit_ref без обратного kg_ref» | 0 |
| ячеек с `kg_ref` | 96 / 999 (9.6 %) |

Все 14 DOI-пересечений между картами целиком относятся к узлам, у которых
`lit_ref` уже заполнен и совпадает с `kg_ref` атомов — то есть канал
«тождество источника» **исчерпан**: ни одна новая пара по нему не добавляется.

## Вывод для следующих раундов

- Повторять проверку «узел без lit_ref ↔ атом по DOI» бессмысленно — результат
  воспроизводимо нулевой.
- Оставшиеся 550 узлов без опоры имеют локаторы, которых нет в карте
  (DOI узлов не встречаются среди 743 DOI ячеек), либо не имеют локатора
  вовсе. Дальнейший рост покрытия требует **не тождества, а смыслового
  сопоставления** (формулировка ↔ формулировка) — это зона задач P1/P11
  и поиска новых ячеек под конкретные формулы (`docs/SUPPORT-WORKLIST.md`).

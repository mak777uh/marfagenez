# DESIGN-division.md — разделение: часть, которая делает для другой то, чего та не может сама

**Слону:** следующий шаг после организации. Там части были связаны **зависимостью** (одна держит другую), но ни одна
не делала для другой того, чего та не может сама. `GOAL.md` §1a называет это **разделением**. Здесь оно появляется
в самой малой форме.

**Дата:** 2026-11-19. **Статус:** расчёт и предсказания, кода ещё нет. **Цикл:** 255.

---

## 1. Минимальная форма разделения

Две части, у каждой своя целостность:

```
q_a   часть A: распад d_a, САМА СЕБЯ ЧИНИТЬ НЕ МОЖЕТ (u_a = 0)
q_b   часть B: распад d_b, чинит и себя, и A
```

и **обмен**: A отдаёт B то, без чего B не может работать — назовём это «допуском» `k_a = min(1, q_a^k)` — а B
тратит вещество, чтобы чинить **и себя, и A**.

Каждая часть по отдельности **нежизнеспособна**:

- A без B не чинится вовсе и погибает за `ln(q_min)/ln(1 − d_a)`;
- B без A не получает допуска и не может чинить даже себя.

## 2. Расчёт — до кода

**Цена пары** в шаг: B чинит себя на `u_b = d_b·q_min` и A на `u_a = d_a·q_min`, всё за `cost = c`:
`c·(d_b·q_min + d_a·q_min) = c·q_min·(d_a + d_b)`.

**Цена одиночной части**, которая чинит себя сама: `c·d·q_min`.

**Отношение:** пара стоит `(d_a + d_b)/d` одиночной. При `d_a = d_b = d` это **вдвое дороже** одной части — ровно
столько же, сколько две независимые части. То есть **разделение само по себе не дешевле**, если считать починку.

> **Предсказание P1:** пара стоит **вдвое** дороже одиночной части того же распада и **ровно столько же**, сколько
> две независимые. Разделение не даёт скидки — оно даёт **нежизнеспособность по отдельности**.

**Предсказание P2:** у пары есть **порог дохода**, ниже которого гибнут **обе** части сразу, а не по одной: A
падает первой (её некому чинить), а B без допуска теряет и себя.

**Предсказание P3:** при доходе выше порога пара **устойчива**: обе части держатся выше `q_min`, потому что B
чинит A на `d_a·q_min`, а это ровно её нужда.

## 2a. Что вышло (2026-11-19, `FINDING-289`)

**P1 и P2 не проверены, потому что пара не живёт ни при каком доходе.** При доходе 10 (цена 0.03) обе части
падают **вместе** на 46-м шаге, равные на каждом шаге. Механизм: `q_a` вниз → допуск B меньше → `q_b` вниз → починка
A меньше. Обратная связь по целостности **всегда вниз**, равновесия нет.

**Вывод:** разделение нельзя построить как «каждая лицензирует другую». Следующая форма — **поток вещества**:
A отдаёт B `s` единиц из запаса, а не допуск из целостности.

## 3. Что проверяется сравнением

| вариант | что в нём |
|---|---|
| **S** | одна часть, чинит себя сама (`d = 0.05`) |
| **I** | две независимые части, каждая чинит себя |
| **D** | две части с разделением: A не может себя чинить, B чинит обе |

Сравнение по порогу дохода: `S` < `I` = `D` (если P1 верно). И по числу выживших: в `D` порог валит обе сразу.

## 4. Чего это не даст

- **Не даст «выгоды от специализации»**: B не производит ничего, чего A не могла бы потребить напрямую; выгоды
  считать не из чего, кроме цены починки.
- Не даст обмена **веществом между частями** как отдельного потока: допуск — это множитель, а не товар.
- Не покажет, **почему** разделение возникает; только что оно **стоит**.

## 5. Предсказание на будущее (если P1 подтвердится)

Тогда в модели появится аккуратная мысль: **разделение не выгодно по цене починки** — оно выгодно только если
часть, которая «не может сама», делает что-то **полезное для другой**. Значит следующий механизм должен дать A
**производство**, а не только неспособность.

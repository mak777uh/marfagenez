# `F-028`: adder, sizer, timer — откуда взялось `CV²_s = ln 4 − 1`

**Дата:** 25.11.2026. **Агент:** `main`. **Воспроизведение:** `python3 tools/adder_noise.py`.

## Запись в узле

```
правило:        s_d = a·s_b + b        (a = 0 sizer, 1 adder, 2 timer)
adder в числах: CV²_s = ln 4 − 1 ≈ 0.386      (при beta = 1/2)
наблюдаемое:    CV_h ≈ 0.07…0.09
```

## 1. Единицы

`s_d`, `s_b`, `b` — мкм; `a`, `CV_s`, `CV_h` — безразмерные. Сходится: `s_d = a·s_b + b` однородно
(`[b] = мкм` при `a` безразмерном). **Замечание:** `checked: {"kind": "none"}` — формула формально не проверена
до этого раунда.

## 2. Предел: шум → 0

Симуляция правила `s_d = a·s_b + 1`, `s_b = β·s_d` при `β = 1/2`, **без шума**:

```
CV_s = 0,000000  →  CV² = 0
```

**Вывод:** при отсутствии шума размер при делении — одно и то же число. Значит `CV²_s = ln 4 − 1 ≈ 0,386`
**не является свойством правила** `s_d = a·s_b + b`. Это свойство **модели с шумом**, и в узле это не сказано.

## 3. Что даёт шум

| источник шума | `CV` шума | `CV²_s` |
|---|---|---|
| добавка (аддитивный шум) | 0,10 | 0,013 |
| добавка | 0,20 | 0,054 |
| добавка | 0,40 | 0,225 |
| деление (асимметрия) | 0,10 | 0,003 |
| деление | 0,20 | 0,014 |

**Число 0,386 соответствует шуму добавки ≈ 0,5** — этого значения в узле нет ни в каком виде.

## 4. Различимость

| величина | значение | `CV` |
|---|---|---|
| заявленный `CV²_s` | 0,386 | **0,62** |
| наблюдаемое `CV_h` | 0,07–0,09 | **0,26–0,30** |

**Это не «немного разные» числа, а разные режимы:** 0,386 в 4–5 раз больше наблюдаемого. Если аддитивное
правило должно объяснять наблюдаемую стохастику, шум добавки должен быть ≈ 0,5, а не тот, что даёт 0,07–0,09.

## 5. Опровергающее условие

Формула убьётся, если при нулевом шуме `CV_s` окажется не нулём (тогда правило само порождает разброс), или
если наблюдаемое `CV_h` окажется ≈ `sqrt(ln4 − 1)` (тогда число не противоречит данным). Сейчас ни то, ни другое:
`CV_s(0) = 0` и `CV_h ≈ 0,07–0,09`.

## Что исправлено в данных

В корпус добавлена пометка: **`ln 4 − 1` — свойство модели с шумом добавки ≈ 0,5, а не аддитивного правила;
наблюдаемое `CV_h ≈ 0,07–0,09` соответствует меньшему шуму.**

## Чего это не доказывает

- Что аддитивное правило неверно: неверна **интерпретация** числа, а не правило.
- Что наблюдаемые 0,07–0,09 несовместимы с adder: совместимы при меньшем шуме добавки.

## Дополнение 28.11.2026 (lit): `F-015` — устойчивость и стационарная дисперсия

Запись `F-015` (sizer/adder/timer) содержит два проверяемых утверждения, до этого
раунда не верифицированных (`checked: none`):

```
s_d = a·s_b + b        a = 0 (sizer), 1 (adder), 2 (timer)
s_b' = (a/2)·s_b + b/2
устойчивость распределения  ⟺  |a| < 2
стационарная дисперсия      =  σ²/(1 − (a/2)²)
```

### Аналитическая проверка

Карта `s_b' = (a/2)·s_b + b/2` — это авторегрессия AR(1) с `ρ = a/2`:

- неподвижная точка `s_b* = b/(2 − a)` при `a ≠ 2`;
- сходимость ⟺ `|ρ| < 1` ⟺ `|a| < 2` — **точное** условие, не приближение;
- при аддитивном шуме с дисперсией инновации `σ²` стационарная дисперсия AR(1)
  равна `σ²/(1 − ρ²) = σ²/(1 − (a/2)²)` — совпадает с записью.

### Численная проверка (200 тыс. шагов, burn-in 20 тыс., σ = 0,3, b = 1)

| a | ρ = a/2 | среднее (сим / теория b/(2−a)) | дисперсия (сим / теория σ²/(1−(a/2)²)) |
|---|---|---|---|
| 0,0 | 0,000 | 0,501 / 0,500 | 0,0898 / 0,0900 |
| 0,5 | 0,250 | 0,667 / 0,667 | 0,0957 / 0,0960 |
| 1,0 | 0,500 | 0,999 / 1,000 | 0,1198 / 0,1200 |
| 1,5 | 0,750 | 1,999 / 2,000 | 0,2062 / 0,2057 |
| 1,9 | 0,950 | 10,00 / 10,00 | 0,930 / 0,923 |
| −0,5 | −0,250 | 0,401 / 0,400 | 0,0956 / 0,0960 |
| −1,0 | −0,500 | 0,333 / 0,333 | 0,1204 / 0,1200 |
| −1,9 | −0,950 | 0,256 / 0,256 | 0,904 / 0,923 |
| 1,99 | 0,995 | 100,1 / 100,0 | 9,01 / 9,02 |

Расходящиеся (`|a| > 2`): `a = ±2,5`, `a = 3` — рост за 200 шагов до ~1e19–1e35.
Граница `a = 2` точно: `s_b' = s_b + b/2 + ε` — аддитивное случайное блуждание с
дрейфом; дисперсия растёт линейно `∝ n·σ²`, стационарного распределения нет.
Условие `|a| < 2` — **строгое**, и `timer` (a = 2) сидит ровно на границе.

### Две оговорки, которых в записи нет

1. **Граница `|a| < 2` предполагает симметричное деление `β = 1/2`.** Общий случай:
   `s_b' = β·(a·s_b + b)`, `ρ = a·β`, устойчивость `|a·β| < 1`, то есть
   `|a| < 1/β`. При `β = 1/2` это и есть `|a| < 2`. При несимметричном делении
   порог сдвигается (например, `β = 0,6` → `|a| < 1,67`).
2. **`σ` в формуле дисперсии — стандартный разброс инновации шага `s_b'`.** Если
   шум входит в `s_d`, а не в обновление `s_b'`, дисперсия распространяется иначе
   (`Var(s_d) = a²·Var(s_b) + σ_d²`); запись не уточняет, куда добавлен шум.

### Что это НЕ доказывает

- Что реальные популяции описываются этой картой с постоянным `a`: `a` может
  зависеть от состояния/среды.
- Что `σ²/(1−(a/2)²)` наблюдаема: она верна для AR(1)-инноваций; при
  коррелированном или мультипликативном шуме формула меняется.

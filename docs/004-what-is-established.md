## Реестр — один файл

[`POSITIVE.md`](../POSITIVE.md): **каждый результат** с уровнем, формулой, **командой** и границей. Это источник
истины для чисел. Ничего «своего» здесь не пересказывается — только ссылка.

## Что держится (по линиям)

| линия | что измерено |
|---|---|
| **кожа** | закон жизни без починки; цена удержания `c·d·q_min`; замыкание при `c ≤ 1` |
| **обмен** | законы доли запаса; плательщики; «карман» как самодостаточность |
| **организация** | цена границы и цена глубины; связь частей без разделения |
| **разделение** | часть, которая покрывает себя и другую; условие через поток |
| **прошлое** | жизнь как скорость; две равные формы не равны; порог наследования; корневой закон плато |
| **выбор** | полоса допуска при катастрофе; две независимые опасности |

## Что опровергнуто — и это тоже результат

[`ELIMINATED.md`](ELIMINATED.md) и [`../NOT-CLAIMED.md`](../NOT-CLAIMED.md). Отрицательный результат имеет такую же
ценность, как положительный: он освобождает место.

## Правило чтения реестра

У каждой строки есть **граница применимости**. Если границы нет — строку нельзя использовать.

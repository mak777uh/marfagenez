## Одна команда

```bash
wsl -e bash /root/marfagenez/run.sh all      # ожидается «ВСЁ ЗЕЛЁНОЕ»
```

## Что именно проверяется

| проверка | что ловит |
|---|---|
| `checks/doc_numbers.py` | числа в документах против дерева |
| `checks/log_check.py` | те же числа + **непрерывность журнала циклов** |
| `checks/contract.py` | три контроля и хэши плеч |
| `checks/result.py` | вердикт, `limitations`, запись в `results/` |
| `checks/finding_elephant_line.py` | у находки есть строка `**Слону:**` |
| `checks/paper_format.py` | объём и формат бумаги |
| `checks/protocol_checks.py` | новая проверка названа в `PROTOCOL.md` |

## Чему гейт **не** может научить

Он проверяет **форму**. Он не знает, верна ли физика, не отличит подгонку от предсказания и не заметит, что вы
измеряете шум. Это работа круга B и круга A, а не гейта.

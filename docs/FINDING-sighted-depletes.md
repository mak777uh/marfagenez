# Находка: зрячий организм истощает поле

**Дата:** 2026-11-12
**Эксперимент:** `EXP-09` (предварительный)
**Вердикт:** предварительный — требует полного эксперимента

---

## Что сделано

Добавлен `Policy::Sighted` — первая политика с **обратной связью от мира**:

```rust
Policy::Sighted => {
    let left  = if r.cell > 0 { self.field.level(r.cell - 1) } else { f64::NEG_INFINITY };
    let right = if r.cell + 1 < cells { self.field.level(r.cell + 1) } else { f64::NEG_INFINITY };
    let best = here.max(left).max(right);
    if best > here {
        if left >= right { -1 } else { 1 }
    } else {
        0   // ничья -> стоит
    }
}
```

**Все остальные политики видят только свою клетку.**

## Но результат странный

**39 живых на 39 разных клетках** — почти каждый на своей.

**Проверка поля:**

| политика | клетки 0–9 на шаге 2000 |
|---|---|
| `stay` | `[1.8, 2.0, 2.0, 1.6, 2.0, 1.6, 1.6, 1.8, 1.6, 1.6]` |
| `remember` | `[2.0, 1.8, 1.8, 2.0, 1.8, 1.6, 1.6, 1.6, 1.8, 1.8]` |
| **`sighted`** | **`[0.8, 0.8, 0.8, 0.8, 0.8, 0.8, 0.8, 0.8, 0.8, 0.8]`** |

**Зрячий организм истощил поле до 0.8.** Остальные оставили 1.6–2.0.

---

## Почему

**`sighted` двигается больше** → **больше берёт** из клеток.

**`regrow_all`** отращивает к `max_resource = 2.0` со скоростью `regrow = 0.8`:

$$c \leftarrow c + (2.0 - c) \times 0.8$$

**Если брать больше, чем отрастает — поле истощается.**

**Баланс:**
- организм берёт `min(income, cell) = min(0.8, cell)`
- клетка отрастает `(2.0 - c) × 0.8`

**Равновесие клетки:** `c* = 2.0 - 0.8/0.8 = 1.0`. Но при многих организмах
на одной клетке — ниже.

---

## Что это значит

> **Зрение даёт движение. Движение истощает поле. Истощённое поле
> не даёт разницы между клетками.**

**Это петля:**

1. Зрячий видит разницу → двигается
2. Двигаясь, берёт больше
3. Поле истощается
4. Разница исчезает
5. Зрячий перестаёт двигаться (все клетки равны)

**Это самоограничение через истощение.**

---

## Почему это интересно

**Это первый раз, когда политика влияет на среду.**

Раньше: политика влияла только на себя (куда идти).
Теперь: политика влияет на **поле** (сколько брать).

**Это обратная связь в другую сторону** — организм меняет мир.

**`GOAL.md` §3.4:**
> **Среда допускает изменение условий собственного развития.** Организм может
> менять не только себя, но и мир, в котором будет жить дальше.

**Вот оно.** Зрячий организм **меняет мир**.

---

## Что это не доказывает

**Не проверено на 5 сидах.**

**Не проверено, что истощение — причина.** Может быть, что-то другое.

**`Policy::Sighted` не покрыта тестами Rust.**

**Поле истощается до 0.8 — но не до 0.** Значит есть равновесие.

**39 живых** — все выжили. Значит истощение не убивает.

## Что делать дальше

**Полный эксперимент `EXP-09`:**

| плечо | политика | поле | что проверяем |
|---|---|---|---|
| **A** | `remember` | alternating | контроль: не двигается, поле не истощается |
| **B** | `sighted` | alternating | двигается, поле истощается |
| **C** | `sighted` | uniform | не двигается (нечего искать) |

**Контроль:**
1. **Срабатывает:** B двигается, A нет
2. **Молчит:** C не двигается (в однородном поле нечего искать)
3. **Специфичен:** B истощает поле, A нет — **разница в поле, а не в политике**

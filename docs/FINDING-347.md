# FINDING-347: показатель `ε^(2/3)` подтверждён для прямого перехода и нарушен для обратного

**Дата:** 25.11.2026. **Агент:** `main`. **Тип:** литературная опора (найдена пара по величине).
**Связано:** `F-029` (нормальные формы и размытие перехода), `DIP33-0005`, `DIP33-0006`.

## Что установлено

В карте были две ячейки об одной системе (бистабильная реакция иодат–мышьяковистая кислота), не связанные
с формулой `F-029`, хотя измеряют **ту же величину** — показатель степени, с которым задержка переключения
масштабируется по расстоянию до порога `ε`:

| ячейка | что измерено | сравнение с `F-029` |
|---|---|---|
| `DIP33-0005` | прямой переход (нижняя → верхняя ветвь): `t_delay ∝ ε^p`, `p = 0,63 ± 0,10` | согласуется с `2/3 ≈ 0,67` |
| `DIP33-0006` | обратный переход (верхняя → нижняя): `t_delay ∝ ε`, то есть `p = 1` | **не согласуется** с `2/3` |

## Что это значит

1. **Показатель `2/3` подтверждён измерением** — впервые для `F-029`, которая до этого не имела строгой
   литературной опоры (считалась узлом без пары с совпадающей величиной).
2. **Универсальность показателя ограничена направлением перехода.** Обратный переход даёт `p = 1`:
   момент переключения линейно управляется скоростью изменения параметра. То есть `ε^(2/3)` — это не
   свойство «порога вообще», а свойство конкретного направления, где работает квадратичная нормальная форма.
3. **Практическое следствие для `F-029`:** запись `Delta_r ~ ε^(2/3)` верна для прямого перехода и
   требует оговорки для обратного. Сейчас запись оговорки не содержит.

## На каком основании

Ячейки `DIP33-0005` и `DIP33-0006` (одна система, два направления), добавлены `kg_ref → F-029`;
вердикты `S` записаны в `docs/STITCH-OVERRIDES.json` с причинами. Покрытие: пар `S` 45 → 47,
узлов `S` 22 → 23.

## Что это НЕ доказывает

- Что `p = 1` для обратного перехода универсален: это одна система.
- Что `0,63 ± 0,10` отличается от `2/3`: погрешность покрывает теоретическое значение.
- Что `F-029` теперь «подтверждена» целиком: подтверждён один её показатель в одном направлении.

## Следующая проверка

Искать другие системы, где измерены **оба** направления перехода, — если `p = 1` для обратного
повторяется, это закономерность, а не особенность иодат-реакции.

# Находка: `Std` кончается на делении рациональных

**Дата:** 2026-11-11
**Проект:** МАРФАГЕНЕЗ++
**Где:** `laws/Tilt.lean`

---

## Что пытались

Формализовать `α = 2μ/σ²` в Lean без Mathlib.

## Что получилось

**Две теоремы доказаны, три — нет.** Пробовал трижды, каждый раз упирался в одно и то же.

| утверждение | статус |
|---|---|
| `α = 0 ⇔ μ = 0` | **доказано** (`no_push_no_tilt`) |
| квадрат ненулевого ненулевой | **доказано** (`sq_ne_zero`) |
| `a ≠ b ⇒ a < b ∨ b < a` | **доказано** (построено из `le_total`) |
| знак `α` = знак `μ` | **не доказано** |
| `α` растёт с `μ` | **не доказано** |
| `α` падает с `σ` | **не доказано** |

## Что удалось построить

Две леммы, которых в `Std` нет, но которые выводятся из имеющегося:

**`lt_or_gt_of_ne_rat`** — из `Rat.le_total` и `Rat.lt_of_le_of_ne`.

**`sq_ne_zero`** — из `Rat.mul_eq_zero`.

Это показывает: `Std` **беден, но не пуст**. Часть недостающего строится.

## Где именно кончается

Три попытки упирались в **одно и то же**:

| нужная лемма | есть в `Std`? |
|---|---|
| `Rat.mul_pos_of_neg_of_neg` | нет |
| `Rat.neg_pos_iff` | нет |
| `Rat.div_lt_div_of_pos_right` | нет |
| `Rat.mul_pos_iff` | нет |
| `Rat.pos_of_mul_pos_left` | нет |
| `linarith` на `Rat` | нет |

Всё это — **арифметика с делением и знаком**. Ровно то, что нужно для `α = 2μ/σ²`.

> **Граница `Std` — рациональная арифметика со знаком и делением.**

## Что вместо доказательства

**Три пробы перебором** — все `true`:

```
signProbe 12 = true        — знак α = знак μ
monotoneProbe 12 = true    — α растёт с μ
antitoneProbe 12 = true    — α падает с σ
```

**Численная проверка** (`checks/tilt.py`, 3/3):

| μ | α | mean(сим) | mean(теор) | sd(сим) | sd(теор) |
|---|---|---|---|---|---|
| 0.01 | 0.22 | +0.6057 | +0.6477 | 1.6632 | **1.6586** |
| 0.05 | 1.11 | +2.0663 | +2.1076 | 0.8860 | **0.8741** |
| 0.10 | 2.22 | +2.4941 | +2.5500 | 0.4673 | **0.4499** |

Совпадение до 2%.

## Что нужно

Собрать Mathlib в `laws/`:
```bash
cd laws && lake build Mathlib
```

Час и 6 GB. После этого три теоремы доказываются стандартными тактиками.

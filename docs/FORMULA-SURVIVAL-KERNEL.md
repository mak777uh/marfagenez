# `F-024`: ядро выживания — аппроксимация сходится, если считать прообраз правильно

**Дата:** 25.11.2026. **Агент:** `main`. **Воспроизведение:** `python3 tools/survival_kernel.py`.

## Запись в узле

```
V(K) = { x₀ ∈ K : ∃ траектория x(·), x(0)=x₀, x(t) ∈ K ∀t ≥ 0 }        ядро выживания
K₀ = K,  K_{i+1} = K_i ∩ F⁻¹(K_i)          убывающая последовательность
граница выживания: ∂V_α = ∂{ параметры : система остаётся в K навсегда }
```

## Проверка на примере с известным ответом

`F(x) = 2x − 0,5`, `K = [0; 1]`. Выживают только точки, у которых **все** итераты остаются в `K`.
Первое ограничение даёт `[0,25; 0,75]`, дальше интервалы сжимаются к единственной точке `x* = 0,5`.

| шаг | размер `K_i` |
|---|---|
| `K_0` | 2001 |
| `K_1` | 1001 |
| `K_2` | 501 |
| `K_3` | 251 |
| … | … |
| `K_11` | **1** |

**Предел: `[0,5000; 0,5000]`, ширина 0,0000** — совпадает с аналитическим `x* = 0,5`.
Монотонность `K_{i+1} ⊆ K_i` выполняется на каждом шаге. Остановка — по **неизменности множества**
(`K_11 = K_10`), а не по «достаточному числу итераций». Точка `0,5` выживает 1000 шагов.

## Что это подтверждает

Аппроксимация из узла **работает**: последовательность убывает, стабилизируется за конечное число шагов и
даёт `V(K)`. Критерий остановки — совпадение двух соседних множеств — тоже верный: он не требует знать ответ
заранее.

## Честно о собственной ошибке

Первая версия проверки дала **«предел шириной 0,5»** и вывод «аппроксимация не подтверждена».

Причина: я считал прообраз как «`F(x)` попадает в отрезок `[0; 1]`» — **постоянный**, а не как «`F(x)` попадает
в текущее множество `K_i`». Из-за этого последовательность останавливалась на `K_1 = [0,25; 0,75]` и
выдавала его за предел.

Правильная запись `K_{i+1} = K_i ∩ F⁻¹(K_i)` означает именно **прообраз относительно `K_i`**, и в ней всё
дело: с постоянным отрезком это другая (и неверная) итерация.

**Это седьмой случай за день, когда дефект был в проверке, а не в формуле.** И самый поучительный: ошибка
была в одном слове — в том, относительно чего берётся прообраз.

## Опровергающее условие

Если последовательность не убывает или предел не равен `V(K)` на примере с известным ответом,
аппроксимация из узла неверна. `tools/survival_kernel.py` возвращает 1 в этом случае.

## Что это НЕ доказывает

- Что на реальных системах `V(K)` вычислимо за малое число шагов: здесь один пример и одна сетка.
- Что «полоса» на оси `α` из узла равна проекции `V(K)`: это отдельное утверждение, оно не проверялось.

# `F-010`: RAF (reflexively autocatalytic and food-generated) — проверка определения на игрушечных сетях

**Дата:** 28.11.2026. **Агент:** `lit` (раунд S3-formulas-lean). **Источник:** определение из L-027 (RAF-теория, Hordijk–Steel).

## Запись в узле

```
R' ⊆ R  есть RAF, если
  ∀ r ∈ R': катализатор r ∈ (молекулы, порождённые R' из food set F)
  все реагенты r строятся из F
```

**Откуда.** L-027. **Наше.** Ни один из наших механизмов пока не проверен на это условие.

## Что проверено

Численной формулы у записи нет — это теоретико-множественное определение.
Проверка свелась к тому, что определение корректно применимо: реализован
наивный перебор подмножеств реакций с проверкой двух условий и прогнан на
трёх контрольных сетях (проверка «инъекцией»: заведомо RAF и заведомо не-RAF).

Соглашения, зафиксированные в реализации (в записи они не проговорены):

- «молекулы, порождённые R' из F» — это замыкание: стартуем с F, итеративно
  добавляем продукты реакций, чьи реагенты уже в замыкании. Замыкание
  включает сам F (пища считается доступной).
- катализатор — одна молекула (не множество), и она должна входить в замыкание
  подмножества `R'`, а не обязательно быть продуктом `R'` — то есть
  **самокатализ разрешён** и **катализ пищей тоже** (если катализатор ∈ F,
  условие выполнено тривиально).
- «все реагенты строятся из F» = реагенты ⊆ замыкание(R', F).

## Результаты контрольных сетей

Сеть `F = {A, B}`; реакции записаны `(реагенты, продукты, катализатор)`:

| Сеть | Реакции | RAF-подмножеств | Комментарий |
|---|---|---|---|
| R1 | `{A}→{B}` ; `{B}→{A}` кат. `A` | **3** | каждый синглтон RAF + всё множество: цикл A↔B самоподдерживается, катализатор `A` ∈ F |
| R2 | R1 + `{A,B}→{D}` кат. `D` | **7** | самокатализ: `D` порождается самой реакцией и потому входит в замыкание — реакция RAF даже в одиночку |
| R3 | R1 + `{A}→{E}` кат. `Z` | **3** | катализатор `Z` нигде не порождается → реакция не входит ни в одно RAF-подмножество; максимум — полный R1 |

Все три исхода соответствуют определению — отрицательный контроль (R3)
отсекает реакцию с недостижимым катализатором, положительный (R2)
подтверждает самокатализ.

## Оговорки

- В канонической RAF-теории (Hordijk–Steel) «food-generated» требует, чтобы
  каждый реагент был либо в F, либо произведён подмножеством — это совпадает
  с нашей реализацией; дополнительно требуется, чтобы катализатор входил в
  замыкание — у нас это условие `cat ∈ prod`.
- В записи не сказано, считается ли еда F частью замыкания (мы считаем —
  иначе ни одна реакция с чисто пищевым катализатором не была бы RAF, что
  противоречит литературе).
- Для наших механизмов проверка не проводилась — запись остаётся
  концептуальной; этот документ фиксирует только то, что определение
  непротиворечиво и применимо.

## Опровергающее условие

Если в L-027 определение RAF отличается (например, катализатор обязан быть
продуктом именно `R'`, а не допускать пищу), таблицу результатов надо
пересчитать — R1 уменьшится до 2 RAF-подмножеств (исчезнут синглтоны,
где катализатор берётся из F).

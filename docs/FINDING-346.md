# FINDING-346: v3 — параметр насыщения относится к эндпоинту, а не к системе

**Дата:** 25.11.2026. **Тип:** собственный вывод (алгебра) поверх данных `FINDING-345`.
**Связано:** `docs/FORMULA-DCRITICAL.md` (раздел v3), `DIP59-0001`, `DIP59-0005`, `DIP59-0006`.

## Зачем

`FINDING-345` показал, что `D_cap` из формулы v2 не переносится: из RIF-фокусов получается ≈1,18 Гр, из
PFGE-разрывов — нижняя граница >1418 Гр, а из 53BP1-фокусов — **отрицательный** (при большей дозе
разрешение быстрее). Чистая экспонента `C0·exp(−D/D_cap)` такие данные описать не может.

## Что предложено

Минимальная поправка — recruitment-член: с ростом дозы включается больше центров ремонта, видимая
скорость сначала растёт, потом падает из-за насыщения:

```
R(D) = C0 · exp(−D/a) · (1 + D/b)
```

## Что из этого следует точно (алгебра)

`dR/dD = R · (−1/a + 1/(b + D))`, откуда

```
D* = a − b      (максимум существует только при a > b)
```

- при `a ≤ b` функция монотонно падает, то есть **v2 — предельный случай** `b → ∞`;
- наклон в нуле положителен ровно при `a > b` — это и есть признак, различающий формы;
- при `a ≫ 90 Гр` насыщения нет до 90 Гр — случай PFGE-разрывов.

Численная проверка формы (`a = 2`, `b = 0,5`, `C0 = 1`): `D* = 1,5`; `R` растёт от 1,01 при `D = 0,01`
до 1,89 при `D = 1,5` и падает до 0,90 при `D = 5`; наклон в нуле `+1,5`.

## Различающее предсказание

Нужны `R(D)` при **≥3 дозах** в одном типе клеток и одним методом:

| форма | что предсказывает |
|---|---|
| v2 | монотонное падение с ростом дозы |
| v3 (`a > b`) | рост до `D* = a − b`, затем спад |

Для 53BP1-фокусов рост **уже виден** (`t½` 3,1 ч при 7,5 мГр против 2,7 ч при 500 мГр): v2 в этом
эндпоинте опровергнута, v3 согласуется по направлению.

## Что это НЕ доказывает

- Что v3 верна: она согласуется по направлению с одним набором и не проверена на других.
- Что `a` и `b` измеримы по двум точкам: две точки дают одно уравнение, нужна третья доза между ними.
- Что `D*` существует в живых системах: он предсказан формой, а не наблюдён.

## Следующая проверка

Найти ряд `R(D)` при трёх и более дозах в одном методе (лучше — PFGE-разрывы, где нет артефакта
консолидации). Если `R` монотонно падает — v3 лишняя; если растёт и падает — измерить `D*` и `a − b`.

---

**Дополнение 25.11.2026 (важное, меняет статус).** Эта находка предлагала v3 как «согласующуюся по
направлению» с инверсией у 53BP1-фокусов. Дальнейшие проверки:

- инверсия **статистически не значима**: `3,1 ± 0,5` против `2,7 ± 0,8` ч даёт `p = 0,672`
  (`FINDING-356`);
- на PFGE-эндпоинте recruitment-член `(1 + D/b)` требует **роста** мощности ремонта с повреждением, а
  данные показывают обратное; RD-модель воспроизводит их без recruitment (`docs/RD-VS-V3.md`,
  независимая проверка чисел — `P68`).

**Текущий статус:** v3 не опровергнута, но и **не обоснована**; рабочей формой считается монотонная
(`docs/FORMULA-DCRITICAL.md`, раздел «Вердикт на 25.11.2026»). Читать эту находку следует как историю
вывода, а не как подтверждение recruitment.

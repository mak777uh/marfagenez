# FINDING-323 — граф стал проходимым: свидетельство перестало быть строкой

**Дата:** 2026-11-21. **Основание:** внешний разбор (§4.1 «свидетельства не становятся полноценными путями графа») и
правка `kg/migrate.py` + `kg/kg.py`.

## Что было

`check` умел находить свидетельство: `FINDING-317` разрешался в файл на диске, `EXP-SHADOW-PRICE` — в тексты прогонов.
Но `expand` эти ссылки не проходил: у него был свой цикл, который смотрел только на точные ID узлов. Получалось, что
валидация и навигация имеют **разные представления связности**: проверка говорит «свидетельство найдено», а исследователь
не может дойти от утверждения до этого свидетельства.

## Что стало

1. **Свидетельство — объект.** 11 новых узлов `EV-*` (`kind: evidence`) для ссылок, которые не были узлами:
   `EV-FINDING-247/297/309/316/317/318/319/320` и `EV-EXP-CLOSURE-MEASURE/PRICE-KINKS/SHADOW-PRICE`.
   У каждого — `ref`, `form`, `used_by`, `locator`.
2. **Один резолвер.** `ref_targets()` отвечает и проверке, и навигации: находка → её объект, алиас → прогоны, путь →
   узел, который владеет этим путём в собственном свидетельстве.
3. **`expand` ходит по резолверу**, а не по точным ID.
4. **`check` проверяет объекты свидетельств:** `EV` без `ref` — ошибка; `EV-FINDING-NNN` без файла на диске — ошибка.

Граф: **560 узлов**, из них 11 свидетельств; ссылки свидетельств разрешаются все (539).

## Числа

`expand C-001 1` теперь печатает:

```
EV-EXP-SHADOW-PRICE [evidence] серия прогонов EXP-SHADOW-PRICE
EV-FINDING-317      [evidence] находка FINDING-317
F-023               [formula]  Двойственная задача и смысл цены
X-EXP-SHADOW-PRICE-2026-11-20T10-06-53 [experiment/refuted]  verdict failed
X-EXP-SHADOW-PRICE-2026-11-20T10-09-49 [experiment/established] verdict passed
```

Путь «утверждение → свидетельство → прогон» проходится за один шаг; раньше он обрывался на имени файла.

**Слону:** карта перестала быть каталогом имён. Теперь от утверждения можно дойти до конкретного прогона и
конкретной находки по связи, а не по памяти — это то, без чего «карта слона» остаётся оглавлением.

## Что это значит

- **Проверка и навигация больше не расходятся** — это был не косметический дефект, а два разных графа в одном файле.
- **Одиннадцать объектов вместо пятисот.** Ссылки на документы (420 различных путей) остаются ссылками: узел-дубликат
  реестра на каждую строку утопил бы граф и не добавил проходимости.
- **Пустой разрыв виден:** если у `EV` нет `ref`, `check` краснеет, а не молчит.

## Чего это не доказывает

- Что свидетельство **истинно**: объект адресуем, но не проверен; за это отвечает чтение источника и `access`.
- Что пройдены все пути: документы-реестры по-прежнему не объекты, и путь к ним короче.
- Что `FINDING-317` — полная запись: это указатель на файл, а не его содержание.

## Команда

```bash
python3 kg/kg.py expand C-001 1
python3 kg/kg.py show EV-FINDING-317
python3 kg/kg.py check
```

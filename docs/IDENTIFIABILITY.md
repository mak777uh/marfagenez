# Различимость параметров: что наблюдается, а что нет

Сгенерировано `tools/identifiability.py`. Эвристика по латексу: список кандидатов на
чтение глазами, а не приговор. Смысл правила: если параметры входят только
произведением, данные различают **комбинацию**, а не множители.

## Подтверждено вручную

| формула | комбинация | что это значит |
|---|---|---|
| `F-001` | `alpha = lambda·delta` | наблюдаемо только alpha; множители не разделяются |
| `F-002` | `delta·T` | различимо только повреждение за поколение |
| `F-017` | `q^nu` | различима только точность в степени длины генома |
| `F-006` | `Pi·lambda` | порог задан произведением; отдельные Pi и lambda не наблюдаются |
| `F-019` | `Pi·lambda` | то же, симметричный случай |

## Кандидаты из латекса

- `F-001`: `λ·δ`, `F·I`, `N·D`, `I·N`
- `F-002`: `h·D`, `δ·T`
- `F-003`: `λ·D`, `λ·δ`
- `F-004`: `c_y·σ`
- `F-005`: `κ·E`
- `F-006`: `Π·λ`
- `F-010`: `R·A`, `f·o`
- `F-011`: `Δ·R`
- `F-012`: `Δ·z`, `C·o`, `w·Δ`
- `F-016`: `g·λ_s`, `g·λ`
- `F-019`: `Π·λ`
- `F-021`: `κ·J_A`
- `F-022`: `o·u`
- `F-025`: `I_col·I_env`
- `F-027`: `γ·A`
- `F-028`: `C·V`, `C·V_h`, `f·o`
- `F-029`: `h·f`
- `F-030`: `M·O`, `D·E`

## Как пользоваться

1. Кандидат — не приговор: проверьте, входит ли пара как произведение или как два
   независимых слагаемых.
2. Если произведение — данные различают только его. Записывайте комбинацию как
   наблюдаемую величину, а множители — как параметры модели.
3. Проверка не заменяет оценку: она говорит, что **нельзя** оценить, а не что можно.

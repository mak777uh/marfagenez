# 002 · Как работать одному

## Четыре круга

| круг | что делает | куда пишет |
|---|---|---|
| **A. Литература** | что человечество уже нашло | `ELEPHANT-LITERATURE.md`, `ELEPHANT-MAP.md` |
| **B. Эксперимент** | наше число и вердикт | `results/`, `FINDING-NNN.md`, `POSITIVE.md` |
| **C. Репозиторий** | чтобы следующий агент видел материалы с порога | `INDEX.md`, `AGENT_STATE.md` |
| **D. Тупик** | вывод из застревания по протоколу | `LESSONS.md`, `ELIMINATED.md`, `QUESTIONS.md` |

**Порядок:** A → B → C. Литература **до** эксперимента: она дешевле и часто отменяет работу.

## Признаки тупика (любой — стоп)

три одинаковых провала подряд; **невозможное число** (доля ровно 0.500, отрицательное повреждение, гейт, равный
единице); три раунда без нового числа; оптимум переезжает при смене выборки; красивое совпадение с грубой формулой.

**Диагностика по порядку:** дефект постановки → масштаб → метрика → литература → вопрос владельцу.

## Откуда брать импакт

1. **пустое пересечение** двух формализованных областей;
2. **слова → число** там, где литература говорит качественно;
3. **противоречие** двух линий, которое прогон различает;
4. **убить своё** — снять заявку, у которой нашёлся аналог.

Полный текст, включая «что читать в тупике» — [`WORK-LOOPS.md`](WORK-LOOPS.md).

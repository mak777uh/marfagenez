# PREDICTIONS.md — предсказания, записанные **до** прогона

**Зачем.** Мера понимания по `Q-022`: **доля предсказаний, сбывшихся вне заложенного**. Без файла эта мера
невычислима, потому что предсказание всегда можно «вспомнить» после результата.

**Правила.**

1. Запись делается **до** запуска, с датой и номером цикла.
2. Формулировка — **с величиной и направлением**: «при `h = 0.99` плато будет ≈8.7, не ≈100».
3. После прогона — поле `Итог`: `сбылось`, `не сбылось`, `частично` + ссылка на `FINDING`.
4. Записи **не удаляются** и не переписываются: несбывшееся — часть счёта.

### P-NNN · цикл NNN · 2026-MM-DD
**Предсказание.** ...
**Проверка.** команда, которая это покажет
**Итог.** (заполняется после прогона)

### P-010 · круг 008 · 2026-11-20

**Предсказание.** Если катастрофа **общая** для всех форм (крупное зерно), оптимум по **средней** жизни сдвинется к
стратегии с меньшим средним и меньшей дисперсией (bet-hedging); если катастрофы **идиосинкратические** (мелкое зерно)
при том же среднем — сдвига не будет. Плюс: измеренный `log λ_s` ляжет на приближение Тулджапурака с точностью 15 %.
**Вероятность.** 0.65
**Проверка.** `organ_saving.rs`: два режима общности катастрофы при одинаковом среднем; замер обоих оптимумов и
`log λ_s` по эпизодам.
**Итог.** не проверено

### P-012 · круг 010 · 2026-11-20

**Предсказание.** Если наш регулятор размера — adder-подобный, то дисперсия стационарного распределения даст
`CV² ≈ 0.386`; если он «сила ∝ ошибке» (пропорциональное регулирование), `CV²` будет **меньше** и **зависеть** от
коэффициента возврата. Плюс: среднее, измеренное по траектории (forward), окажется **независимым** от шума деления, а по
случайной выборке (backward) — **растущим** с ним.
**Вероятность.** 0.6
**Проверка.** Прогон с `a = 0, 1, 2`: замер `CV²` по обоим способам выборки.
**Итог.** не проверено

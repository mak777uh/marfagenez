# Проверка двухосевой формулы на наших числах

Обзорная проверка: можно ли **проверить** формулу (нагрузка/критическая + квадрат скорости/критическая
≤ 1) на данных, которые уже есть в карте. Новых ячеек нет, все числа — из принятого.

## Что нужно для проверки

Одна система, в которой измерены **оба** порога:

- `L*` — критическая нагрузка (из кривых насыщения клиренса);
- `v*` — критическая скорость изменения;
- хотя бы один наблюдённый переход.

## Что у нас есть по системам

| система | `L*` (уровень) | `v*` (темп) | оба в одной системе? |
|---|---|---|---|
| деградация субстрата протеасомой | Km 6·10⁻⁸ М | нет | нет |
| клиренс in vivo | половинное насыщение 8,15 нМ | нет | нет |
| цианобактерии (цветение) | нет | 0,1378 1/сут | нет |
| планктон | нет | около 0,003 1/сут | нет |
| AMOC | нет | 234 года при 0,5 Sv | нет |
| термоакустика | нет | переход за 107 единиц | нет |
| химический переход (автокатализ) | окна по 20 K | задержка с показателем 0,63 | **да, частично** |
| наклонённая нормальная форма | граница бассейна (формула) | критическая скорость (формула) | **да, только теория** |

## Вывод проверки

**Формулу нельзя проверить на текущем материале.** Причина не в формуле, а в том, что **литература
измеряет оси порознь**: в биологии — уровень, в экологии и климате — темп, в химии — оба, но в
безразмерных координатах, где нагрузка не выражена в физической величине.

Единственное место, где обе оси стоят рядом, — **теория** (наклонённая нормальная форма): там есть и
граница бассейна, и критическая скорость, но нет измерения.

## Что это значит

Два следствия, и оба важны.

**1. Формула остаётся гипотезой — и это надо сказать прямо.** Она не опровергается текущими данными не
потому, что верна, а потому что данных, которые могли бы её опровергнуть, нет. Такую ситуацию надо
называть своим именем, а не выдавать за подтверждение.

**2. Появилась конкретная измерительная задача.** Не «найти ещё литературу», а **измерить обе оси в одной
системе**. Минимальный протокол:

1. взять систему, где уже есть кривая насыщения клиренса (например, деградация субстрата с измеренным Km
   и Vmax);
2. добавить второй эксперимент: менять нагрузку **во времени с разной скоростью** при одной амплитуде;
3. зафиксировать, при какой скорости наступает срыв при нескольких уровнях нагрузки;
4. получить точки в плоскости (нагрузка, скорость) и посмотреть, лежат ли они на одной кривой
   `L/L* + (v/v*)² = 1`.

Если точки ложатся на прямую `L/L* + v/v* = 1` — квадрат неверен. Если на гиперболу — верен. Если
разбросаны — ни одна ось не описывает исход.

## Что это даёт помимо проверки

Протокол сам по себе — законная лабораторная работа (первая из трёх, которые задача называет: чтение,
формулы, лаборатория). И он опирается на уже измеренные величины, то есть не требует новых методов —
только нового дизайна.

## Честный итог цикла

Формула не подтверждена и не опровергнута. Вместо ложного «проверено» записано: **какие именно данные
нужны и почему их нет**. Это менее приятный результат, чем «формула работает», но он не развалится при
первой же попытке проверки.

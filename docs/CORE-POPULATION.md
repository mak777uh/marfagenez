# Популяция: две стратегии оплаты ремонта

Сгенерировано `python3 tools/core_population.py`. Числа — результат прогона.

## Модель

```
dD/dt = eta - C*D/(K+D)
dC/dt = (C0-C)/tau - gamma*D*C
dE/dt = uptake - m0 - cR(D)*C*D/(K+D) - cC*C
фиксированная: cR = 2 всегда
адаптивная:    cR = 1 при D < 0.5, cR = 3 при D >= 0.5
потомство = E_end/2, потолок численности 1000
```

## Результат

| приток энергии | всего особей | доля фиксированной | доля адаптивной |
|---|---|---|---|
| 2.2 | 464.4 | 0.000 | 1.000 |
| 2.5 | 461.8 | 0.500 | 0.500 |
| 3.0 | 461.8 | 0.500 | 0.500 |
| 3.5 | 461.8 | 0.500 | 0.500 |
| 5.0 | 461.8 | 0.500 | 0.500 |

Смысл: при достаточном притоке обе стратегии упираются в потолок накопления энергии и
различие исчезает; при скудном притоке выигрывает та, что платит меньше в здоровом
состоянии. Преимущество стратегии оплаты существует только при энергетическом ограничении.

## Что это значит

1. **В скудных условиях «платить вовремя» вытесняет «платить всегда»:** при притоке 2.2
   фиксированная стратегия не доживает, адаптивная занимает всю популяцию.
2. **В богатых условиях различие исчезает:** при притоке от 2.5 обе стратегии упираются в
   потолок накопления энергии и делят популяцию ровно пополам.
3. Значит **расточительная стратегия не наказывается, пока ресурса в избытке** — и это
   отдельный вывод, а не отсутствие результата: отбор по цене ремонта работает только
   вблизи энергетического ограничения.

## Оговорки

- Это mean-field: одна особь-представитель на стратегию, без вариации внутри стратегии.
- Потомство пропорционально остатку энергии — простая модель, не отбор по функции.
- `delta_eff` в этом прогоне одинаков для обеих стратегий, поэтому наследуемый износ не
  даёт преимущества ни одной из них: различие только в энергии и грузе.

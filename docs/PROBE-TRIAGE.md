## Лучшая находка — №4

Агент не ограничился «формула не сходится»: он **восстановил из двух точек другую зависимость**.

```
η·φ = 0,61 × 2,31 = 1,409
η·φ = 0,21 × 6,67 = 1,401   → постоянная
⇒ η ≈ 1,41/φ, а не (1/φ²)(1 − Ccrit/Cs)
```

Я проверил обе точки — зависимость действительно `1/φ`, а не `1/φ²`. Записал как **нашу реконструкцию**,
а не как цитату из источника: это важно, потому что восстановленная формула не проверена по тексту.

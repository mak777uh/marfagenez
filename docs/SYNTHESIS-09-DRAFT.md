# СЛОН-09 — черновик: обзор после смены формулы и роста покрытия

**Дата:** 25.11.2026. **Статус:** черновик к публикации (`main` публикует).
Обзор без новых ячеек. Числа на момент обзора: **999 ячеек, 584 связи, 65 инсайтов,
34 домена** в литературной карте; **580 узлов** в карте знаний; **сшивка: опора у
30 из 152 утверждений (20 %)**.

---

## 1. Что изменилось с прошлого обзора (СЛОН-08)

Тогда формула точки невозврата была v1 и содержала два дефекта; лестница режимов
склеивала три разные величины в одну ось; покрытие опорой было 10 %. За эти круги:

1. **Формула переписана (v1 → v2).** `D_crit = D_cap·ln(C0/P0)` заменена записью с
   ремонтным членом, ограниченным грузом: `R(D) = min(C0·exp(−D/D_cap), k·D)`.
   Появились **два равновесия** (нижнее устойчивое, верхнее неустойчивое), их
   слияние считается **точно** через W Ламберта: `D_x = D_cap·W(C0/(k·D_cap))`,
   `P_crit = k·D_x`. Это **не гладкая складка**: в точке слияния производная
   меняется скачком (излом `min`), равновесие полуустойчиво.
2. **Лестница режимов заменена двумя осями.** Вместо `P < Vmax < P_on < P_fast`
   — безразмерные координаты `Π_repair = J_D/V_max(D)` и `Π_adapt = τ_response/τ_ramp`;
   режим — клетка в плоскости, а не точка на оси. Основание — первоисточник:
   у Johnson 2020 порог включения Hog1 есть **AND двух условий** (темп
   **12,1 ± 1,6 мМ/мин** И концентрация **117,5 ± 34,5 мМ**), а не одно число.
3. **Покрытие опорой удвоилось: 10 % → 20 %.** Каналом стал **сшивка по
   тождеству источника** (`tools/stitch_identity.py`): узел `kg/` и ячейка карты,
   ссылающиеся на одну работу. Дало 34 ячейки с `kg_ref` и рост 16 → 30 из 152.
   Тем же каналом он и **исчерпан**: проверка всех 550 узлов без `lit_ref`
   (раунд P1, 25.11) дала **0 новых пар** — DOI узлов без опоры не встречаются
   среди 743 DOI ячеек.
4. **Найден дефект измерения `D_cap`** (`FINDING-341`): падение ремонта с
   повреждением видно только в **фокусных** методах (полувремя RIF 1,4 → 5,7 ч
   при 0,1 → 2 Гр) и **не видно** в прямых (полувремя DSB 168 ± 10 мин при
   3–90 Гр). `D_cap` не универсальна — она про видимую кинетику ремонтной
   машины, а не про её пропускную способность.

## 2. Формула сейчас

| элемент | запись | статус |
|---|---|---|
| точка невозврата | `dD/dt = P0 − min(C0·e^(−D/D_cap), k·D)` | **наша конструкция**, v2; v1 отозвана (отрицательная скорость при D=0, неустойчивое «равновесие») |
| равновесия | два: `D* = P0/k` (нижнее) и ветвь `C0·e^(−D/D_cap) = P0`; слияние при `P_crit = k·D_cap·W(C0/(k·D_cap))` | проверено численно (`tools/dcritical2.py`) |
| режимы | клетка `(Π_repair, Π_adapt)` в плоскости | гипотеза о структуре; числа порогов из **разных систем** |
| растворение | `c_skin = ∂V/∂b` против дохода на границу | конструкция, измерения `c_skin` в живом объекте нет |

**Ключевая честная оговорка v2:** это не «порог», а **сепаратриса с изломом**.
Между равновесиями `dD/dt < 0` — система спускается к нижнему; вверх уходит
только выше верхнего. Подстановка `k` вместо `C0` — категориальная ошибка
(`k` — константа первого порядка, не поток).

## 3. Что подтверждено и что опровергнуто в этом сезоне

**Подтверждено по полным текстам** (внешний аудит 25.11, перепроверено):
Johnson 2020 (порог AND, 12,1 мМ/мин + 117,5 мМ), Mori 2018 (30 DSB/(Гр·клетка)),
Grudzenski 2010 (~21 фокус/Гр; при ≤10 мГр удаления нет; H₂O₂ возвращает).

**Опровергнуто/ослаблено:**
- `CORR-01` («полоса = проекция ядра выживания») — **опровергнуто** (`FINDING-338`);
- `F-014` (порог ∝ `√(2 ln N)`) — **различитель провален** (`FINDING-339`);
- κ-схема против абсолютной поддержки — **тождество** при эндогенной κ (`FINDING-340`);
- `CORR-02` — у источника «аналог», не «производная»; ослаблено.

**Новое знание о методах:** `D_cap` существует в фокусных кинетиках и отсутствует
в прямых измерениях DSB — «ремонт падает с повреждением» верно для видимой
работы машины, но не для пропускной способности (`FINDING-341`).

## 4. Проблемы, которые остались

**4.1. Опора у 20 % утверждений.** 122 из 152 без внешней пары. Причём канал
«тождество источника» исчерпан (0 новых пар, P1): дальше — только смысловое
сопоставление (P11) или новые ячейки под конкретные формулы.

**4.2. `D_cap`, `c_skin`, `P` не измерены.** У формул нет чисел для ключевых
величин; `Vmax = 1,4·10⁵` — про тромбоcпондин, а не про «повреждение вообще».

**4.3. Три артефакта недоступны** (P8): Dataset S1 Reznik, Table 1 Zaharieva,
Supp. Table Ma & Zeng. Каналы блокируют (PLOS→TIFF, HAL→HTML, PMC OA→404).

**4.4. Единицы по-прежнему не мостятся.** `°C/мин ↔ Гр/мин` не сведены; ось
держится только на безразмерных отношениях (Дамкёлер, Пекле, Дина, Тиле, Био).

**4.5. Четыре режима — в разных системах.** Пороги 12,1 мМ/мин (дрожжи),
Vmax (млекопитающая клетка), 187 °C/мин (ооциты) — ни один эксперимент не мерил
все режимы в одной системе.

1. **Добыть три артефакта** (P8) — закрывают числами теневые цены и итерации ядра.
2. **Смысловая сшивка вместо тождества** (P11): 550 узлов без опоры, у 41 есть
   DOI, которого нет в карте — нужен поиск новых ячеек под них.
3. **`D_cap` до числа** (P2): фокусные методы дают диапазон (1,4–15,4 ч),
   прямые — константу; вопрос — есть ли работы с нагрузочной серией.
4. **Пары `(D, R(D))`** (P3): pulse-chase ряды, различающие v1 и v2.
5. **Синтез-09 → публикация** после verify `main`.

## 6. Одна фраза

Явление — **темп решает, успеет ли система ответить**; формула — теперь
**двухосная**: поток против мощности ремонта (`Π_repair`) и время ответа против
времени нарастания (`Π_adapt`); точка невозврата — **сепаратриса с изломом, а не
гладкий порог**; главный сдвиг сезона — **покрытие опорой удвоилось до 20 % и
канал-источник исчерпан**, а главный недостаток — **ключевые величины формул
(`D_cap`, `c_skin`, `P`) по-прежнему не измерены**.

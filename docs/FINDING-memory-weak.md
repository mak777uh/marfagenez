# Находка: память бесполезна, если организм видит только свою клетку

**Дата:** 2026-11-12
**Эксперименты:** `EXP-07`, `EXP-08`, попытка с меняющимся полем
**Вердикт:** отрицательный результат с ясной причиной

---

## Что я пытался

**Цепочка:**

1. `EXP-07`: `remember` — однократный выбор, память замерзает
2. Сделал `Policy::Memory` — обновляет память каждый шаг
3. **Не помогло:** оба стоят
4. Сделал **меняющееся поле** (`Field::moving`, богатая клетка ходит)
5. **Не помогло:** оба стоят

---

## Результаты

| политика | поле | живых | клеток | **двигаются** |
|---|---|---|---|---|
| `remember` | uniform | 32 | 32 | 0 |
| `memory` | uniform | 33 | 26 | 0 |
| `memory` | gradient | 33 | 26 | 0 |
| `remember` | **moving** | 39 | 27 | **0** |
| `memory` | **moving** | 39 | 28 | **0** |

**Ни в одном случае организм не двигается.**

---

## Почему

### Причина 1: `observe` требует строгого `>`

```rust
pub fn observe(&mut self, cell: usize, level: f64) -> bool {
    self.age += 1;
    if level > self.best_level {   // строго больше!
        ...
    }
}
```

**В однородном поле** `level == best_level` всегда → память не обновляется.

### Причина 2: организм видит только свою клетку

```rust
// life.rs
let here = self.field.level(r.cell);   // только своя клетка
```

**Он не видит соседей.** Значит не может узнать, что рядом есть клетка лучше.

**Он двигается только к тому, что уже запомнил.** А запомнил он только то,
на чём стоял.

### Причина 3: меняющееся поле не помогает

**`Field::moving`** ставит богатую клетку в позицию `t % n`. Но:

1. Организм смотрит только на **свою** клетку
2. Богатая клетка **уже ушла** с того места
3. Он видит `poor` и не обновляет память (`poor < best_level`)

**Он не может найти движущуюся цель, не видя соседей.**

---

## Что это значит

> **Память бесполезна, если организм видит только свою клетку.**

**Это глубже, чем «remember — однократный выбор».** Даже настоящая
обновляемая память не помогает, потому что **нечего запоминать** — организм
никогда не видит ничего, кроме своей клетки.

**Это дефект модели, а не находка о жизни.**

---

## Чего не хватает

**Организм должен видеть соседей.**

```rust
// сейчас
let here = self.field.level(r.cell);

// должно быть
let left = self.field.level(r.cell.saturating_sub(1));
let right = self.field.level((r.cell + 1).min(cells - 1));
let here = self.field.level(r.cell);
// и выбрать, куда идти, сравнив три
```

**Без этого:**
- `Policy::Random` блуждает слепо
- `Policy::Remember` находит первое и застывает
- `Policy::Memory` не отличается от `Remember`

**С восприятием соседей:**
- организм может **искать** градиент
- может **следовать** за движущейся целью
- память становится **полезной**

---

## Это возвращает к принципу проекта

**`GOAL.md` §3.3:**

> **Свобода не равна отсутствию причин.** Организм должен иметь внутренние
> процессы, обратную связь, память. Без них он просто случайно движется.

**Сейчас у организма нет обратной связи** — он не видит, что вокруг.

**Восприятие соседей — это и есть обратная связь.**

---

## Что это не доказывает

**Не доказано, что восприятие соседей решит проблему.** Может быть, нужна
более сложная память.

**Не проверено на 5 сидах.**

**`Field::moving` не покрыт тестами.**

**Меняющееся поле может быть неверно реализовано.** `apply_shift` сбрасывает
богатую клетку, но не проверено, что переход плавный.

---

## Что делать дальше

**Добавить восприятие соседей.** Это следующий шаг.

**Плечи для проверки:**

| плечо | что | предсказание |
|---|---|---|
| A | `remember`, слепой | стоит (как сейчас) |
| B | `remember`, видит соседей | находит лучшую из трёх, идёт |
| C | `memory`, видит соседей | следует за градиентом |

**Если B и C двигаются, а A нет — восприятие работает.**

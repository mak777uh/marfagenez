## 0.2. Что есть по существу

**Одна модель:** случайное блуждание популяции точек в ограниченном пространстве.

$$x_{t+1} = R_B(x_t + \mu + \sigma\xi_t)$$

**Пять законов** о ней:
1. Насыщение: `min(σ√t, B/√3)`
2. Гонка: `(B/σ)²`
3. Реакция: `g ≠ 0` меняет шаг
4. Время: `(B − spread)/μ < B/μ`
5. Наклон: `α = 2μ/σ²`

# Часть 1. Первые принципы

## 1.1. Что мы исследуем

**Не:** «как создать среду, в которой ребёнок хорошо развивается».

**А:**

> **Какие свойства среды и какие механизмы взаимодействия позволяют искусственной системе самостоятельно поддерживать свою организацию, изменять поведение на основании опыта и участвовать в формировании условий собственного дальнейшего существования?**

## 1.2. Что НЕ является критерием успеха

- рост сложности
- рост числа признаков
- рост популяции
- рост продолжительности жизни
- рост разнообразия
- появление интеллекта
- появление кооперации

**Это наблюдения, не цели.** Успешная организация может оказаться простой.

## 1.3. Четыре принципа

**1. Не программировать конечный образ.**
Не решаем заранее, каким организм обязан стать.

**2. Наблюдение отделено от управления.**
Не «среда не измеряет», а: **ни один измерительный канал не изменяет динамику, если воздействие явно не включено в эксперимент.**

**3. Свобода не равна отсутствию причин.**
Организм должен иметь внутренние процессы, обратную связь, память. Без них он просто случайно движется.

**4. Среда допускает изменение условий собственного развития.**
Организм может менять не только себя, но и мир, в котором будет жить дальше.

## 1.4. Правило трёх утверждений

Для каждого результата различать:

| уровень | что | инструмент |
|---|---|---|
| **A** | доказано | Lean / Verus |
| **B** | проверено на входах | тесты |
| **C** | измерено | эксперимент |
| **D** | гипотеза | не проверено |

**Никогда не смешивать.**

## 1.5. Правило двух формулировок

Каждый результат имеет:

| строгая | интерпретационная |
|---|---|
| что произошло в модели | какую гипотезу это позволяет предложить |

**Вторая не следует из первой.**

## 1.6. Правило честного счёта

| число | что значит |
|---|---|
| «198 теорем» | 198 утверждений, **не** 198 содержательных законов |
| «124 теста» | 124 проверки, **не** доказательство корректности |
| «18 verified» | 18 свойств доказано, **не** вся модель |

# Часть 2. Что чинить сначала

## 2.1. Почему сначала чинить, а не расширять

Расширение на ошибочном основании **умножает ошибки**.

Пример: закон `d/(d+2)·R²` построен на шаре, который не сохраняет меру. Добавление черт к организму, который не поддерживает себя, даст **более сложную ошибку**.

## 2.2. P0 — геометрия и динамика

### P0.1. Шар

**Проблема:** радиальный fold не сохраняет меру. `chi² = 31 429 297` при ожидании 9.

**Причина:** объём оболочки `∝ r^(d-1)`. Складывание радиуса без учёта этого переносит массу неправильно.

**Варианты:**

| вариант | что делать | цена |
|---|---|---|
| **A** | убрать `Shape::Ball` из выводов | теряем закон `d/(d+2)` |
| **B** | реализовать корректное отражение | сложно, нужна геометрия |
| **C** | оставить как эксперимент с пометкой | честно, но бесполезно |

**Мой выбор: A.** Шар не даёт ничего, чего не даёт куб. Закон `d/(d+2)` — про `E[‖X‖²]`, не про разброс.

### P0.2. `ball_trait_variance`

```rust
// сейчас: R²/d
// должно: R²/(d+2)
```

### P0.3. `fraction_of_law`

Всегда делит на `B/√3`. Для шара эталон другой.

**Что делать:** переименовать в `fraction_of_box_law`, либо учитывать форму.

### P0.4. Насыщение — приближение

`min(σ√t, B/√3)` — **эвристика**, не закон.

**Разделить три вещи:**

| что | формула |
|---|---|
| свободное движение | `σ√t` |
| стационарное распределение | `B/√3` |
| **переход** | **не известно** |

**Что делать:** исследовать переход отдельно. Не называть `min` законом.

### P0.5. `α = 2μ/σ²` — непрерывный предел

Дискретный переход не обязан давать ту же плотность.

**Эксперимент:** уменьшать шаг времени, масштабировать `μ` и `σ`, смотреть, сходится ли к экспоненте.

### P0.6. RNG-корреляция

`Cycle::born` создаёт `Rng::new(seed)` для рождения, `Medium::new(room, seed)` — **тот же** генератор.

**Что делать:** разделить seed. Проверить корреляцию между начальным состоянием и первым шумом.

# Часть 3. Что строить

## 3.1. Определение организма

**Индивидуальная система** — система с относительно устойчивой организацией, границей, внутренними процессами и историей состояний, причём её существование зависит от взаимодействия внутренних процессов и внешних условий.

**Не требует** размножения, интеллекта, морфологии.

### Семь минимальных свойств

| свойство | операциональное значение |
|---|---|
| Идентичность | непрерывность во времени |
| Внутреннее состояние | не сводится к мгновенному воздействию |
| Внутренняя организация | взаимосвязанные процессы |
| Обмен | получение ресурсов |
| Самоподдержание | компенсация нарушений |
| Агентность | действия меняют условия |
| История | прошлое влияет на настоящее |

**Вводить постепенно.**

### Идентичность ≠ неизменность

Различать:

- сохранение индивидуальности
- сохранение структуры
- сохранение функциональной организации
- изменение компонентов
- разрушение организации

## 3.2. Модель среды

$$E_{t+1} = G(E_t, A_t, X_t)$$
$$X_{t+1} = F(X_t, E_t, A_t, H_t)$$

- `E_t` — среда
- `X_t` — организм
- `A_t` — действия
- `H_t` — история

**Среда — самостоятельная система, не набор ограничений.**

### Пространство

Не только граница. Определяет:

- доступность ресурсов
- расстояния
- стоимость перемещения
- локальные условия
- следы активности

**Граница Box сама по себе не создаёт экологию.**

### Ресурсы

$$R(x,t) \geq 0$$

Могут: поступать, перемещаться, расходоваться, восстанавливаться, изменяться действиями.

**Разделять доступность и получение.**

### Энергетика

$$E_{t+1} = E_t + I_t - C_t - D_t$$

- `I_t` — поступление
- `C_t` — стоимость
- `D_t` — потери

**Нулевой баланс должен иметь семантику.** Нельзя бесконечно существовать без ресурсов.

## 3.3. Действия

$$A_t = \pi(X_t, H_t, E_t)$$

**Действие должно иметь последствия и стоимость.**

**Нельзя считать, что агентность есть, только потому что состояние меняется.**

### Проверка агентности

| | контроль | эксперимент |
|---|---|---|
| ресурсы | не зависят от действий | зависят |

**Если действия не меняют траекторию — агентность не подтверждена.**

## 3.4. Память

$$H_{t+1} = M(H_t, X_t, E_t, A_t)$$

**Различать:** пассивное накопление / память о воздействиях / изменение реакции / обучение.

**История в журнале ≠ использование истории.**

## 3.5. Самоподдержание

**Более фундаментально, чем сложность.**

Минимальные процессы:

1. поддержание запаса
2. обнаружение нарушений
3. восстановление
4. поддержание параметров
5. управление расходами

**Ремонт не бесплатен и не гарантирован.**

## 3.6. Изменение среды

$$E_{t+1} = G(E_t, A_t, X_t)$$

Следы: ресурсы, структуры, проходимость, защита, продукты.

**Изменения должны сохраняться достаточно долго.**

# Часть 4. Как проверять

## 4.1. Десять метрик

| категория | метрика |
|---|---|
| Жизнеспособность | время существования |
| Самоподдержание | восстановление после повреждения |
| Энергетика | динамика баланса |
| Агентность | причинный эффект действий |
| Пластичность | различие реакций при разной истории |

| Развитие | изменение доступных способов поведения |

| Наследование | влияние среды предков |
| Разнообразие | различия между траекториями |

**Каждая метрика:** определение, единицы, вычисление, ограничения, контроль.

**Не объединять в один индекс без обоснования.**

## 4.2. Шесть причинных экспериментов

### EXP-01. Ресурсная неоднородность

**Вопрос:** влияет ли распределение ресурсов на существование?

Контроль: однородное. Эксперимент: неоднородное, **тот же общий объём**.

### EXP-02. Агентность

Контроль: ресурсы не зависят от действий. Эксперимент: зависят.

### EXP-03. Память

Контроль: без состояния опыта. Эксперимент: с состоянием.

### EXP-04. Ремонт

Контроль: нет. Эксперимент: есть. Дополнительно: ограничен.

### EXP-05. Нишестроительство

Контроль: без следа. Эксперимент: со следом.

### EXP-06. Экологическое наследование

Контроль: нет изменений. Эксперимент: среда изменена. Доп. контроль: изменение воспроизведено искусственно.

## 4.3. Методология

Каждый эксперимент:

1. гипотеза **заранее**
2. независимая переменная
3. контрольная группа
4. одинаковые начальные условия
5. достаточные репликации
6. фиксированные seed
7. метрики **заранее**
8. полные конфигурации
9. результаты отдельных репликаций
10. анализ неопределённости

**Не путать:**

- отсутствие эффекта
- недостаточную мощность
- гибель всех
- устойчивость
- отсутствие признака

**Отрицательный результат — полноценный результат.**

```
  ├── Interactions
  ├── RandomState
  └── ExperimentState
```

**Логическое разделение, не требование первой реализации.**

## 6.3. Чистая функция перехода

$$(World_t, RNG_t) \longrightarrow (World_{t+1}, RNG_{t+1})$$

**Воспроизводимо** при одинаковых начальных состояниях, правилах, параметрах, RNG.

**Случайность — явная часть вычисления, не скрытый глобальный эффект.**

## 6.4. Что доказывать

**Verus (целые):**

- энергия ≥ 0
- ресурсы ≥ 0
- действия в пространстве
- балансы сохраняются
- переполнения нет

**Lean (математика):**

- свойства переходов
- инварианты
- условия жизнеспособности

**Но:** доказательство инвариантов ≠ биологическая состоятельность.

# Часть 7. Чего не делать

1. Не оптимизировать под максимальное число организмов
2. Не максимизировать сложность как цель
3. Не добавлять память/ремонт/действия ради наличия компонента
4. Не считать корреляцию причинностью
5. Не путать случайные изменения с обучением
6. Не путать изменение параметров с развитием
7. Не путать устойчивость популяции с самоподдержанием индивида
8. Не путать изменение среды с нишестроительством без последствий
9. Не называть наследованием любое сохранение состояния
10. Не делать вывод о жизни по нескольким похожим признакам
11. **Не расширять модель, пока не исправлено основание**
12. **Не называть `Child` организмом**, пока нет самоподдержания
13. **Не добавлять память, обучение, наследование одновременно**

# Часть 8. Критерии успеха

**Не** получение одного красивого результата.

**Да:** система, в которой можем:

- точно определить индивидуальность
- отделить организм от среды
- проследить причинные связи
- измерять самоподдержание
- исследовать влияние истории
- выявлять обратные связи
- проверять экологическое наследование
- воспроизводить результаты
- отличать свойства модели от интерпретаций

**Главный критерий:** не сходство с земной жизнью, а убедительность показа, какие механизмы создают организацию и поддерживают её.

# Часть 10. Главный принцип

> **Среда не должна заранее знать, каким станет организм.**
>
> Она предоставляет ресурсы, ограничения, возможности, взаимодействия и последствия.
>
> Организм действует, поддерживает себя, изменяется и оставляет следы.
>
> Задача исследователя — не направлять к выбранной форме, а устанавливать, какие механизмы и условия приводят к возникновению и сохранению организации.
>
> **Мы проектируем не результат развития. Мы проектируем мир, в котором развитие можно исследовать.**

# RESULT — P4-redteam-formula

Дата: 2026-11-25. Агент: fast.

## Что сделано

Проведена попытка опровержения формулы v2
(`R(D) = min(C0·e^(−D/Dcap), k·D)`, излом-сепаратриса; `docs/FORMULA-DISSOLUTION.md`)
и двухосевой записи `(L/L*) + (v/v*)² ≤ 1` (`docs/FORMULA-TWO-AXES.md`).

Результат — `docs/REDTEAM-v2.md`: таблица из 8 предсказаний с контрпримерами
(числа + локаторы) и вердиктами ЧАСТИЧНО / ПОДТВЕРЖДЁННЫЙ РИСК / НЕ ПОДТВЕРЖДЁН.

## Ключевые находки

- **Подтверждённый риск один**: постоянство цены поддержания (C-002) — DIP56-0003
  (m_S в 3 раза ниже при μ<0.001 ч⁻¹). Уже известен проекту.
- τ_dsb=168 мин константен 3–90 Гр (DIP59-0005) — частичный удар по экспоненте,
  но FINDING-345 показал несводимость эндпоинтов.
- Агрегаты huntingtin — не «закупорка», а конкуренция+латентность 22.8±4 ч
  (FAST-S2-01/02) → у v2 нет временного слагаемого.
- Излом сепаратрисы в источнике (B26-01-0009) не проверен авторами — эмпирического
  подтверждения нет.
- Двухосевая запись: прямого контрпримера к (v/v*)²-члену не найдено;
  экосистемные работы (W2161650500, W1971799755, W2325339739) показывают, что
  гистерезис — свойство системы, не закон.

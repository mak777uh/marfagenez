# `F-011`: ниша и её изменение — формула без опоры и без чисел

**Дата:** 25.11.2026. **Агент:** `main`. **Воспроизведение:** см. текст ниже (проверка — поиск по карте).

## Запись в узле

```
ΔR = R_original − R_modified          эко-подпись (ecosystem signature)
единицы: Delta_R = 1, R_original = 1, R_modified = 1
```

## Проверка 1: есть ли у формулы содержание

**`ΔR` — разность двух величин, которые в узле не определены.** Не сказано, что такое `R`: вектор откликов?
набор признаков? индекс? Из записи этого не восстановить, а «эко-подпись» — не определение, а метафора.

**Операционально:** чтобы посчитать `ΔR`, нужно знать, как считать `R`. Этого нет.

## Проверка 2: есть ли опора в карте

Поиск по 1125 ячейкам по словам «ниша», «niche», «эко-подпись», «ecosystem signature»:

**найдено 0 ячеек.**

То есть у формулы нет ни литературной опоры, ни собственного числа: это **набросок**, а не формула.

## Проверка 3: размерность

Единицы объявлены как `1` для всех трёх величин — это корректно только если `R` безразмерна. Если `R` —
вектор, то `ΔR` — вектор, и «единица 1» вводит в заблуждение: покомпонентная разность не имеет одной
размерности.

## Вывод

**`F-011` — не формула, а обозначение намерения.** Её нельзя ни проверить, ни опровергнуть, ни посчитать.

## Что с ней делать

Три варианта, по честности:

1. **Удалить** — но история не переписывается, и она уже стоит в графе.
2. **Понизить статус** до «набросок/черновик» с явной пометкой, что `R` не определена. Это правка данных.
3. **Доопределить**: выбрать конкретное `R` (например, вектор лимитирующих факторов с порогами из `DIP57-*`),
   и тогда формула станет проверяемой — но это уже новая работа, а не исправление.

**Рекомендация: вариант 2 сейчас, вариант 3 — если появится задача про нишу.** Оставлять как есть нельзя:
формула без определённых величин выглядит как результат, которым не является.

## Опровергающее условие

Если в карте или в корпусе найдётся определение `R` (что именно измеряется и как) — вывод «не формула»
неверен, и тогда её надо проверять как обычную формулу.

# REANALYSIS-EXP-2026-4103 — переанализ существующего raw (exploratory, post-hoc)

**Статус:** exploratory post-hoc реанализ. НЕ меняет исход EXP-2026-4103 (void терминальный),
НЕ заявляет подтверждений, preregistration не ретроактивна. Все выводы — вход в будущую
preregistration инструмента полюса death-reset.

**Дата:** 2026-11-27. **Источник:** raw прогона a2d (SUB-EXP-2026-4103-1, 50 артефактов),
0 новых прогонов. **Повод:** внешнее ревью (21 вопрос, два независимых ревью).

## Факты

1. Сетка raw: 25 h-конфигураций death-reset (12 базовых h + соседи ±derivative-step для центральных
   разностей + полюс h=1.0), 12 сидов; 336 строк = 12 x 28 (25 death-reset + 2 sham + 1 cap).
   Гипотеза ревьюера о 25 конфигурациях подтверждена.
2. Окна НЕ пересекаются: fit x in [5e-4, 5e-3] (h=0.995..0.9995), silent x in [1e-2, 1e-1]
   (h=0.9..0.99); h=0.99 в fit-сетку не входит (несходящаяся точка). Гипотеза о пересечении опровергнута.
3. Причина провала silent — ширина допуска: remote alpha_D=0.628 vs цель 0.5 (отклонение 0.128 < 0.15),
   alpha_Tlife=0.378 (0.122), alpha_deriv=1.589 (0.089). Запас до края коридора 0.022/0.028/0.061:
   инструмент видел дрейф наклона, но коридор его проглотил.
4. Локальные наклоны монотонны и сходятся к 0.5: D: 0.678 -> 0.514 (сверху),
   T_life: 0.332 -> 0.452 (снизу). Согласовано с corrections-to-scaling:
   D = A x^-0.5 (1 - 1.14 sqrt(x)), A=0.984, R2=0.9992 (экстраполяция на x=0.1: 1.99 vs 2.05);
   T = C x^0.5 (1 - 2.05 sqrt(x)), C=10.82, R2=0.972 (локально у полюса). Отклонения endpoints
   0.525/0.451 — две стороны одной поправочной структуры, не независимые подтверждения.
5. Zero-interval share (глобальные интервалы = 0, события в одном шаге): 0.20 (h=0.9) ->
   0.49 (0.995) -> 0.77 (0.9995) -> 0.963 (h=1.0), разброс по сидам ±0.002. Нули — доминирующий
   режим у полюса; фикс interval>=0 был спасением estimand, а не косметикой парсинга.
6. T_life = средний ТОЧНЫЙ глобальный интервал (pooled stream), не per-organism; per-organism
   интервалы >= 1 (dev-колонка organism_interval). Усечения гистограммы нет (точные counts,
   max interval 32); zero-event сидов нет (12/12 на каждом h).
7. Модельная экстраполяция по декадам вниз: alpha_D 0.525 -> 0.508 -> 0.502 -> 0.501;
   alpha_T 0.452 -> 0.486 -> 0.496 -> 0.499 — оба показателя к 0.5.

## Следствия для будущей preregistration

- silent-контроль «по окну параметров» нежизнеспособен: наклон степенного закона одинаков в любом
  окне, поправка дрейфует монотонно. Негатив = выключение механизма; валидация = exponent-tracking
  (механизмы с разными предсказанными показателями) + known-answer тесты.
- допуск назначать из bias-бюджета поправки (tol ~ |c| sqrt(x_min)), не «на глаз»:
  при ±0.05 silent прошёл бы (отклонение 0.128 > 0.05).
- связанные endpoint'ы (производная — конечная разность того же D) не считать независимыми;
  совместная статистика с ковариацией, а не конъюнкция коридоров.

**Слону:** переанализ объясняет, ПОЧЕМУ void: коридор был шире сигнала, а «удалённое» окно ничего
не выключало. Урок приборостроения: валидность дают инварианты и выключенные механизмы, а не узкие
CI. Смерть-through-reset по-прежнему не доказана численно; следующий шаг к слону — D-Q9 по
ревизии §13 (DESIGN) и мост FINDING-457 №2/№3.

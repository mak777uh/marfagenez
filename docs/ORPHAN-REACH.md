# Насколько связуем оставшийся долг сирот

**Дата:** 25.11.2026. **Агент:** `main`. **Воспроизведение:** `python3 tools/orphan_reach.py`.

## Зачем

Лечение долга идёт группами (`FAST`, `B8`, `W3`, `DIP54`, `W2`, `DIP30`, `DIP41` — 92 ячейки за семь
раундов). После `DIP41` доля аналогий выросла до 30,4 % при потолке 1/3, и возник вопрос: **хватит ли
запаса `analogous`, чтобы долечить остаток?**

## Числа

| категория | сирот | доля |
|---|---|---|
| в домене есть ≥2 связных опоры → `refines`/`requires` реальны | **301** | **99 %** |
| опора только по префиксу группы | 4 | 1 % |
| опоры нет ни в домене, ни в группе (только аналогия) | **0** | **0 %** |

## Что это значит

**Аналогии для остатка не требуются.** У 301 из 305 сирот в том же домене уже есть не меньше двух связных
ячеек — то есть содержимое для честной связи есть, нужна только работа чтения.

Пессимистичный прогноз прошлого раунда («`M9` скоро остановит лечение») **не подтвердился**.

## Оговорка о грубости метода

Совпадение домена — **необходимое, но не достаточное** условие осмысленной связи. Инструмент отвечает на
вопрос «есть ли рядом материал», а не «есть ли правильная роль». Поэтому:

- 99 % — это **потолок** связуемости, а не обещание;
- по опыту групп примерно половина связей находится сразу (`refines` к соседней ячейке), остальные требуют
  чтения и иногда заканчиваются выводом «связи нет»;
- три домена без опор (`evolution.selection` 2, `demography.stochastic_growth` 1, `aging.damage_load` 1) —
  там связь придётся искать вне домена, то есть риск аналогии.

## Что было бы красным флагом

Если бы третья категория («только аналогия») оказалась большой — это означало бы, что долг не лечится без
нарушения M9, и правильным выводом было бы оставить сирот. Сейчас она нулевая.

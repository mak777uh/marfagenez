# FINDING-339. Нейтральная точка мутации не зависит от длины прогона — F-014 к ней неприменима

**Слону:** разделяет две вещи, которые чуть не склеились. `F-014` даёт `δ_c ≈ σ_g·√(2 ln N)` и сам
называет различителем «зависимость `δ_c` от `N`». Если измеренная нейтральная точка `p_grow* ≈ 0.27`
(`FINDING-221`) — это и есть `δ_c`, то при смене числа мутаций `N` она обязана **сдвинуться вправо** на
`σ_g·√(2 ln N)`. Прогон показал: она **не только не растёт, но слегка падает**.

**Дата:** 2026-11-24. **Статус:** `passed` (предсказание не выполнено — это и есть результат). **Цикл:** 524.

## Предсказание, записанное до прогона

| гипотеза | предсказание |
|---|---|
| **F-014** (порог полосы без возвращающей силы) | `p*` растёт как `√(2 ln N)`: при `σ_g = 0.1` это **0.372** (N = 10³) → **0.445** (N = 2·10⁴), сдвиг **+0.07 … +0.12** |
| **баланс роста и удаления** | `p*` — свойство оператора мутации, от длины прогона не зависит: сдвиг ≈ 0 |

## Метод

`core/examples/form_neutral_scaling.rs`: без экономии, только `Form::mutate`; старт — квадрат 3×3;
хвост — последние `max(20, min(200, steps/10))` шагов; **8 сидов** на точку; сетка `0.24…0.30` с шагом
`0.005`; пересечение стартового размера (9 клеток) ищется линейной интерполяцией.

## Результат

| `steps` (N) | `p*` измеренная | предсказание F-014 |
|---|---|---|
| 200 | **0.269** | 0.326 |
| 1000 | **0.268** | 0.372 |
| 2000 | **0.267** | 0.390 |
| 5000 | **0.246** | 0.413 |
| 20 000 | **0.241** | 0.445 |

**Сдвиг `p*` от 200 к 20 000 шагам: −0.028. Предсказание F-014: +0.120.**

Знак **противоположный**, величина расходится в четыре раза.

Сетка при 2000 шагах подтверждает резкость перехода: 0.265 → средний размер 3.68, 0.270 → **16.22**.
Измеренная точка **0.267** согласуется с записанной в `FINDING-221` (**0.27**) — метод тот же, значит
расхождение не от метода.

## Вердикт

**Применение `F-014` к нейтральной точке мутации опровергнуто.** `p_grow*` — не «порог полосы без
возвращающей силы»: это точка **баланса** роста и удаления, свойство оператора мутации (§`FINDING-216`:
мест для роста больше, чем законных удалений). Она не сдвигается по `√(2 ln N)`.

**Сама формула `F-014` не опровергнута:** её область — порог полосы при отсутствии возвращающей силы, и в
нашей модели такого режима мы не измеряли. Опровергнута **склейка** двух разных величин.

## Что это доказывает

- Нейтральная точка мутации **не** масштабируется как `√(2 ln N)`; наблюдаемый слабый сдвиг вниз
  (**−0.028** на два порядка по N) не объясняется F-014 ни по знаку, ни по величине.
- Различитель, который сама формула предложила, **выполнен и провален** — это правильный способ
  проверять формулу, а не подбирать под неё число.

## Что это не доказывает

- Не проверяет `F-014` в её собственной области (полоса без возвращающей силы).
- Не доказывает, что сдвиг −0.028 значим: сидов 8, дисперсия не оценена.
- Не проверяет другие операторы мутации (только `Form::mutate` для квадратов).

# REDTEAM-STITCH: аудит 111 пар сшивки atom↔kg

Задача `P11-redteam-coverage`. Дата: 2026-11-25. Агент: fast.

Объект: все пары `kg_ref` в `literature/map/atoms.jsonl` ↔ `kg/nodes.jsonl` (111 пар; `docs/STITCH-TABLE.md` покрывает 96 строк — 15 пар добавлены позже, включая `FAST-S2-01→L-009`).

## Метод

Для каждой пары сравнивалась **измеряемая величина** ячейки (число, единицы, объект) с **переменной узла kg** (что стоит в `math.latex`/`context`/`text`: какая величина, для какого объекта). Совпадение по слову, голому числу или размерности без общего объекта не засчитывалось.

- **С** — величина совпадает: атом измеряет ту же или прямо параметризующую величину узла.
- **Ч** — частично: общий конструкт/тема, измеряемые величины разные.
- **Н** — несравнимо: совпали только слово, число или размерность.

## Что аудит меняет по сути

1. **Самые крепкие пары — не «сравнимо» таблицы, а несколько «не задан»:** DIP56-0005→F-005/F-021 (57 % — эмпирическое κ), B26-01-0004→C-003 (43.7 % — сама мера), B26-01-0008→F-024 (ядро выживания применено), FAST-S2-01→L-009 (Km/Ki протеасомы).

2. **Пары «сравнимо» на слове «порог» преувеличены:** DIP48-0008→F-002, DIP47-0004→F-003, DIP51-0001/0006→F-003 — управляющие переменные разные.

3. **Числовые совпадения проверены:** 1/6 (Biot) и 0.9 (аутофагосомы) — ложные; 57 % (PAL) и −1/2 (CSD) — настоящие.

4. **Ценные «частичные»:** DIP56-0003 (m_S не постоянна — контрпример к C-002), B26-01-0009 (скачки двойственной цены открыты — напряжение с C-002), DIP59-0005 (ремонт DSB не насыщается до 90 Гр), B20-02-0001 (немонотонный dose-rate).

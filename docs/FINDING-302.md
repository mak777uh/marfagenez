# FINDING-302. Предсказание не сработало: ряд **остался** немонотонным, а B при смертельном входе — «вертушка»

**Слону:** проверяет мой же совет из 301-й — и он **не помог**. Я предсказал, что если судить приспособленность по
**новорождённому**, ряд станет монотонным. Ряд **не стал**: 0.790 / 0.715 / **0.980** / 0.925 / 0.925. Зато видно
**чем** B держится при смертельном входе: у него повреждение **0.145–0.156**, то есть состоит он почти целиком из
только что вошедших. Штамм не живёт — он **обновляется**.

**Дата:** 2026-11-19. **Статус:** предсказание **опровергнуто**; найдено объяснение **удержания**, но не
немонотонности. **Цикл:** 270.

## Что изменено

Приспособленность штамма считается по тому, с чем входит **новорождённый**, а не по среднему члена:

```
entry_damage(A) = 0
entry_damage(B) = inherit_B · mean_damage(B)
```

Это разрывает прямую связь двух штаммов через среднее — то, что я считал причиной немонотонности.

## Результат (`core/examples/organ_inherit.rs`, 200 форм, 200 000 шагов)

| `inherit` B | доля A | повреждение A | повреждение B |
|---|---|---|---|
| 1.00 | 0.790 | 0.292 | 3.793 |
| 1.20 | 0.715 | 0.283 | 2.762 |
| **1.50** | **0.980** | 0.307 | 11.423 |
| 2.00 | 0.925 | 0.315 | **0.156** |
| 3.00 | 0.925 | 0.311 | **0.145** |

## Вердикт

**Предсказание опровергнуто:** монотонности нет. Между 1.2 и 1.5 доля A прыгает с 0.715 до 0.980.

**Но число повреждения объясняет удержание:** при `inherit ≥ 2` у B повреждение **0.145–0.156**, то есть штамм
состоит из мгновенно умирающих новорождённых. Он **не живёт, а обновляется**: место занимает новорождённый, сразу
гибнет, место снова разыгрывается, и B получает его с той же вероятностью.

> **Штамм, который не может прожить ни шага, всё равно удерживает долю мест — потому что вход всегда разрешён.**

## Что это доказывает

- **Немонотонность не связана со связью через среднее** — моё объяснение из 301-й неверно.
- **Удержание при смертельном входе — не парадокс**: это «вертушка», постоянный оборот без накопления.
- **Доля мест не равна выживанию:** штамм может владеть местами, не имея ни одного долгоживущего члена.

## Что это не доказывает

- Не объясняет **прыжок** между 1.2 и 1.5. Возможные причины: дискретная численность (200), связь через среднее,
  оставшаяся в `mean_damage(B)` для входа, или собственно динамика.
- Не доказывает, что «вертушка» — устойчивое явление, а не эффект малой популяции.

## Что дальше — предсказание до кода

**Проверить размер популяции:** 200 против 2000 при `inherit = 1.5`, где прыжок.

**Предсказание:** при 2000 форм доля A окажется **ближе к 0.93** (как при 1.0), и прыжок **исчезнет** — то есть
немонотонность была **эффектом малой популяции**, а не механизма. Если при 2000 картина та же — значит дело в
механизме, и это уже настоящий результат.

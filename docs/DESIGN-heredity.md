# DESIGN-heredity.md — единица наследственности с возвращающей силой

**Дата:** 2026-11-18. **Статус:** расчёт и предсказание, **кода ещё нет**. **Цикл:** 203.

---

## 1. Задача

`FINDING-247` измерила: морфология **наследуется** (ребёнок — `mutate` копии родителя), но **линия не
держит форму**. Двести линий, сто мутаций без отбора: медиана `x` ушла с **0.500** на **0.375**, IQR вырос
**0.150 → 0.194**, линии кончают между **1** и **22** клетками.

Причина — у мутации **нет возвращающей силы**: `p_grow = 0.27` добавляет клетку или убирает её с
одинаковой вероятностью и без памяти о том, какой размер был у предка.

> **Отбор не может накапливать то, что не удерживается.** Пока это так, вопрос «какая структура
> выбирается» не имеет смысла: структура не единица, а блуждание.

## 2. Предлагаемый механизм — минимальный

Добавить форме **наследуемый целевой размер** `x*`:

| где | что |
|---|---|
| `FormState` | поле `target: Option<f64>`; `None` — прежнее поведение (числа 215–247 не сдвигаются) |
| `ShapeRules` | поле `target_restore: f64` (0.0 по умолчанию) — сила возврата |
| рождение | ребёнок получает `target = parent.target`, затем **мутация**: `target *= (1 + N(0, σ_t))` |
| рост | если `x < target`, вероятность добавить клетку `p_grow · (1 + target_restore)`; если `x > target` — `p_grow · (1 − target_restore)` |

**Почему это законно.** Возвращающая сила — **эндогенная**: она задана наследуемым параметром, а не
оценкой наблюдателя. Внешней функции приспособленности не появляется (§3.2 `GOAL.md`).

**Почему `None` по умолчанию.** Договор проекта: каждое число, измеренное до появления поля, обязано
воспроизводиться. С `None` мутация идёт как раньше, и 215–247 не двигаются.

## 3. Расчёт — до кода

### 3.1. Что делает возврат

Пусть `g = p_grow = 0.27`, возврат `r = target_restore`. Вероятность роста при `x < x*` равна `g(1+r)`,
убывания — `g(1−r)`; при `x > x*` наоборот. Тогда **дрейф** `x` за поколение:

```
E[Δn] ≈ g(1 + r) − g(1 − r) = 2·g·r          (при x < x*, добавление клетки)
```

но добавление клетки **на границе** меняет `p` на 2, а `n` на 1, значит `x = n/p` растёт на
`Δx ≈ (1·p − n·2)/p²`. Для квадрата со стороной `s`: `x = s/4`, добавление клетки на границе увеличивает
`s` примерно на `1/(2s)`, то есть `Δx ≈ 1/(8s)`.

Возврат **сжимает** распределение `x` к `x*` со скоростью, пропорциональной `r` и кривизне
`∂Δx/∂x`; стационарная ширина (стандартное отклонение) при малом шуме:

```
σ_x  ≈  σ_шага · sqrt( 1 / (2r) )
```

где `σ_шага` — шум одной мутации в единицах `x` (`≈ Δx/2` для клетки на границе).

### 3.2. Числа для проверки

При `g = 0.27` (нейтраль, `FINDING-221`), `r = 0.5`, старт `x = 0.5`:

| величина | предсказание |
|---|---|
| медиана `x` через 100 поколений | **в пределах 0.02 от 0.5** |
| IQR через 100 поколений | **< 0.10** (у безвозвратной линии было 0.194) |
| доля линий, дошедших до 1 клетки | **< 5 %** (у безвозвратной — заметная часть) |
| доля линий с > 15 клетками | **< 5 %** |

При `r = 0` всё обязано совпасть с `FINDING-247` **точно** — это контроль «механизм выключен, числа
прежние».

## 4. Предсказания, записанные до кода (проверяемые)

- **P1.** При `r = 0` линия ведёт себя как в 247: медиана уходит ≥ 0.05 от старта, IQR > 0.10.
- **P2.** При `r = 0.5` медиана **остаётся** в пределах 0.02 от 0.5 через 100 поколений.
- **P3.** При `r = 0.5` IQR **меньше**, чем при `r = 0`, и меньше 0.10.
- **P4.** При `r = 0.5` **ни одна** линия не доходит до 1 клетки и ни одна не превышает 15 клеток.
- **P5.** При `r = 1.0` (полный возврат) `x` **не двигается вовсе**: IQR ≈ 0.

**Если P2–P4 провалятся** — значит возврат не удерживает `x`, потому что добавление клетки меняет `p`
непропорционально; тогда первым делом надо смотреть на **форму** (квадрат против полосы), а не на размер.

## 6. Что этот механизм **не** решит

- **Не сделает структуру «выбранной».** Возвращающая сила удерживает размер, но отбор по-прежнему идёт по
  избытку (`FINDING-222`), а интервал платёжеспособности его не ограничивает.
- **Не даст «организации»** в смысле границы, обмена и распада — это отдельный вопрос (`GOAL.md` §1a).
- **Не докажет наследуемость приспособленности**: для этого нужен отбор нескольких поколений с измеренным
  ответом на отбор (`R = h²·S`), а его в модели пока никто не мерил.

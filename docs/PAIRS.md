# Пары «величина и движущая сила»

Это моя собственная сводка (не цитата), собранная из принятых ячеек. Смысл: сравнивать между собой можно
только пары «поток × сила», потому что одна и та же мощность на площадь получается при разных потоках и
разных силах. Одиночные числа сравнивать нельзя.

## Правило

Любая цена поддержания имеет вид

    цена за время = поток * движущая сила

Если в ячейке есть только цена, но нет потока или силы — число нельзя сопоставить с другими, пока не
найден второй член. Такие ячейки отмечены как «пара неполная».

## Что из этого следует (мой вывод)

1. **Сравнивать цены можно только внутри одной пары.** Мощность на площадь у клетки и у установки
   различается потому, что потоки различаются на порядки, а не потому что «граница дороже».
2. **Для нашей задачи нужна пара «повреждение × скорость удаления».** Сейчас она есть только в
   качественном виде: и повреждение, и ремонт измерены, но не как поток и сила.
3. **Поэтому следующий поиск должен быть по недостающим вторым членам**, а не по новым ценам: цена без
   пары не добавляет знания, а только длину таблицы.

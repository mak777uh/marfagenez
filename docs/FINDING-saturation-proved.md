## Что доказано

$$\text{spread}(t, B) = \min\left(\sigma\sqrt{t},\ \frac{B}{\sqrt{3}}\right)$$

| теорема | утверждение |
|---|---|
| `bounded_by_wall` | разброс ≤ `B/√3` |
| `bounded_by_free_walk` | разброс ≤ `σ√t` |
| **`wider_never_worse`** | **шире никогда не хуже** |
| **`saturation`** | **достаточно широкая комната → разброс = `σ√t`** |
| `wall_binds` | узкая → разброс = `B/√3` |
| `saturation_width` | насыщение ⇔ `σ√t ≤ B/√3` |

Пробы: `saturationProbe 20 = true`, `monotoneProbe 20 = true`.

Проверка чисел: `spread 9 16 = 9` (насыщение), `spread 9 4 = 4` (стена), `spread 9 9 = 9`.

## Почему это доказуемо без Mathlib

Формула — это **`min` двух величин**. `min` есть в `Std` для `Nat`, и все свойства — арифметика.

> **Закон насыщения — редкий случай: он одновременно прост и доказуем бесплатно.**

Сравните с наклоном (`α = 2μ/σ²`), где нужны деление рациональных и знак — и `Std` кончается.

## Что не доказано

Что разброс **достигает** обоих пределов. Это свойство случайного процесса, не арифметики.

Проверено численно: при `B = 32, 64, 128` измерено 9.60–9.61 против `σ√t = 9.49`. Достигает.

## Формула для практики

Чтобы комната не ограничивала:

$$B \ge \sqrt{3}\,\sigma\sqrt{t}$$

Для `σ = 0.3`, `t = 1000`: `B ≥ 16.4`.

## Для ребёнка

> **Шире определённого предела комната не даёт ничего. Уже — отнимает.**

И это **доказано**, а не только измерено.

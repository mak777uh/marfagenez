## 4. Почему покрытие стоит на 48 парах

Из **114** узлов без `S`: **109 — `hypothesis`** (наши гипотезы и конструкции), 4 — `established`,
1 — `refuted`. Для гипотез `S`-пара **невозможна по устройству**.

**Реалистичный потолок: ~77 узлов (51 %)**, если все 36 `L-*` с недостающими DOI дадут пару.
Для гипотез правильная метрика — **судьба**: проверена → граница → опровергнута.

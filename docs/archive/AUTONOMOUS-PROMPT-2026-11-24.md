## Что это за проект

Два графа знаний, их нельзя смешивать:

- **литературная карта** `literature/map/` — 923 ячейки, 554 ребра, 64 инсайта, 33 домена. Формат в
  `docs/MAP-FORMAT.md`. Приём партий через `tools/map_ingest.py`, контракты в `checks/`.
- **карта знаний** `kg/` — 580 узлов, 12 рёбер, 3 дыры, 2 соответствия. Код `kg/kg.py`, данные
  `nodes.jsonl`, инварианты внутри.

Работа — научная, не инженерная. Ценность в проверенных фактах и честных отрицательных результатах.

## Обязательный порядок цикла

1. Сделать работу одного пункта плана.
2. Записать в `docs/RESEARCH-NOTE.md` короткий разбор: что сделали, что получилось, что не сходится.
3. Добавить запись в `docs/agent/AGENT_LOG.md` в формате
   `### Цикл NNN — YYYY-MM-DD — \`<хеш предыдущего коммита>\`: <кратко>`.
   Нумерация непрерывна, последний цикл на старте — **516**.
4. `git checkout -- results/` (если менялись), `git add -A`, коммит.
5. `bash run.sh all` → должно быть «ВСЁ ЗЕЛЁНОЕ». Если нет — чинить, не коммитить дальше.

## Жёсткие правила

- **Числа без команды — не результат.** Любое число в документе либо из источника (с DOI и цитатой),
  либо из скрипта, который лежит в `tools/`.
- **Проверка, которая не может провалиться, — не проверка.**
- **Цитаты проверять по первоисточнику.** DOI + дословная цитата 10–30 слов + локатор. Аннотация —
  допустимый локатор, но помечать `access: abstract`. Цитата из закрытого текста — не принимается,
  только указатель.
- **«Не найдено»** писать только как «в просмотренной выборке», с запросами, каналами и датой.
- **История** получает датированные дополнения, задним числом не переписывается.
- **`kg/nodes.jsonl` руками не править.** Менять только `kg/kg.py` и производные файлы.
- **Формат карты не менять** под удобство партии. Новые поля — только необязательные.
- **Доля `analogous` ≤ 1/3.** Проверяется контрактом M9.
- **Свои формулы можно**, но с пометкой «моя конструкция» и списком ячеек-опор. Свои симуляции и
  игрушечные модели — **нельзя**.
- **Не расширять инфраструктуру без реального сбоя.** Новый инструмент — только если без него задача
  не решается.

## Что сделать по порядку

Читай `docs/PLAN-2026-11-24.md` и выполняй фазы по порядку. Кратко:

**Фаза 0 — видимость `kg/`.** В `kg/kg.py` компилировать в рёбра `evidence[].ref`,
`data.left`/`data.right` у дыр и соответствий, `data.existing_evidence`; считать строго межлинейные
рёбра отдельно; снять запрет `lines` с формул; развести счётчики пара и вердиктов; исключить
`kind == "evidence"` из `frontier.without_evidence`; перегенерировать `lines-map.json`; записать находку
в `docs/FINDING-NNN.md` и строку в `POSITIVE.md`. Приёмка: рёбер ≥ 45, мосты и дыры видны обходам.

**Фаза 1 — три прогона.** 1.1 тест `CORR-01` = `GAP-03` (итерация ядра выживания + проекция против
полосы 3–10%); 1.2 `F-014` против измеренного 0.27 **по скейлингу**, не по уровню; 1.3 κ-вариант
`maintenance = κ·income` против абсолютной. Предсказание фиксировать **до** прогона.

**Фаза 2 — научные направления.** 2.1 формула `D_critical` (точка невозврата: система жива, но не
способна восстановиться) — опора `B21-01-0003`, `B21-01-0004`, `B22-01-0006`, `I-060`. 2.2 таблица
нормальных форм порогов, генерируется скриптом. 2.3 тест «история при равном состоянии». 2.4
«растворение» как второй тип порога. 2.5 два направления записать как `gap`.

**Фаза 3 — сшивка карт.** Необязательное поле `kg_ref` / `lit_ref`, первые 20 пар по измеряемой
величине, а не по формулировке.

**Фаза 4 — правило остановки литературного круга.** Два круга подряд без новой проверенной ячейки —
менять канал; если не помогло — остановить круг и заняться сшивкой.

## Что считать успехом

- Гейт зелёный после каждого цикла.
- В `kg/` видны мосты и дыры (было 12 рёбер — стало ≥ 45).
- Хотя бы один из прогонов 1.1–1.3 дал **определённый** ответ: подтверждено или опровергнуто.
- Формула `D_critical` записана с единицами и опорами, либо честно записано, какого измерения не хватает.
- Таблица нормальных форм порогов существует и генерируется скриптом.
- Ни одного принятого факта без проверенной цитаты.

## Что считать провалом

- Коммит без записи в журнале или без зелёного гейта.
- Число в документе, которое не воспроизводится командой.
- Принятая ячейка с непроверенной цитатой.
- Правка `kg/nodes.jsonl` руками.
- Расширение формата карты «для удобства».

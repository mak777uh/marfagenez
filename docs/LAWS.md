# Закон 1. Насыщение

$$\text{spread}(t, B) = \min\left(\sigma\sqrt{t},\ \frac{B}{\sqrt{3}}\right)$$

- **ниже насыщения** — стена давит, разброс `B/√3`
- **выше насыщения** — ребёнок не доходит до стены, разброс `σ√t`

$$B_{\text{sat}} = \sqrt{3}\,\sigma\sqrt{t}$$

**Доказано (6 теорем):** разброс ≤ `B/√3`; разброс ≤ `σ√t`; **шире никогда не хуже**; достаточно широкая комната → `σ√t`; узкая → `B/√3`; насыщение ⇔ `σ√t ≤ B/√3`.

**Измерено:** при `B = 32, 64, 128` разброс 9.60–9.61 против `σ√t = 9.49`.

**Что это значит:** нет оптимума ширины. Есть **порог**. Выше него — всё равно, ниже — отнимает.

---

# Закон 2. Гонка

$$\text{комната: } 1 \text{ шаг} \qquad \text{дети: } \left(\frac{B}{\sigma}\right)^2 \text{ шагов}$$

Комната, которая отвечает на популяцию, всегда выигрывает гонку.

**Доказано (4 теоремы):** при `b ≥ 2σ` время заполнения больше времени реакции; удвоение комнаты учетверяет время; потолок останавливает гонку.

**Что это значит:** среда не должна подстраиваться быстрее, чем ребёнок заполняет.

**Измерено:** при `B = 3`, `σ = 0.3` заполнение — **100 шагов** (точное совпадение с `(B/σ)²`).

---

# Закон 3. Реакция

$$\text{шаг} = \mu + g \cdot f(\text{состояние}) + \sigma\cdot\text{шум}$$

$$g = 0 \iff \text{закон держится}$$

**Доказано (5 теорем):** `g = 0` не меняет шаг; `g ≠ 0` и `f ≠ 0` меняют; тяга к позиции равна нулю только в цели; полное демпфирование обнуляет шаг.

**Три формы реакции, три разных порога:**

| форма | что делает | порог | разброс при максимуме |
|---|---|---|---|
| тяга к позиции | тянет к точке | нет | < 1.38 |
| демпфирование | гасит движение | `d → 1` | **0.349** |
| тормоз | режет шаг | `limit ≈ σ` | **0.634** |

**Что это значит:** любая реакция на себя уводит от закона. Не потому что плохая — потому что **реакция есть действие**.

---

# Закон 4. Время

$$t^* \approx \frac{B - \text{spread}}{\mu}$$

**Доказано (4 теоремы):** расстояние до стены меньше `B`; шире комната → больше времени; без толчка время нулевое.

**Измерено:**

| толчок `μ` | наивно `B/μ` | измерено |
|---|---|---|
| 0.10 | 30 | **11** |
| 0.05 | 60 | **32** |
| 0.02 | 150 | **83** |

**Что это значит:** стена настигает **раньше**, чем кончается расстояние до неё. Потому что ребёнок занимает место — он не точка.

---

# Закон 5. Наклон

$$\alpha = \frac{2\mu}{\sigma^2}, \qquad \rho(x) \propto e^{\alpha x}$$

**Доказано (3 теоремы):** `α = 0 ⇔ μ = 0`; квадрат ненулевого ненулевой; `a ≠ b ⇒ a < b ∨ b < a`.

**Не доказано:** знак `α`, монотонность по `μ` и `σ`. В `Std` нет нужной рациональной арифметики.

**Измерено (3/3, до 2%):**

| `μ` | `α` | mean(сим) | mean(теор) | sd(сим) | sd(теор) |
|---|---|---|---|---|---|
| 0.01 | 0.22 | +0.6057 | +0.6477 | 1.6632 | **1.6586** |
| 0.05 | 1.11 | +2.0663 | +2.1076 | 0.8860 | **0.8741** |
| 0.10 | 2.22 | +2.4941 | +2.5500 | 0.4673 | **0.4499** |

**Что это значит:** нет «нормального» диапазона. Есть `spread = f(μ/σ²)`, и она **всегда** ниже `B/√3`, кроме точки `μ = 0`.

# Что из этого следует для среды

## Среда должна быть

| свойство | почему |
|---|---|
| **молчащей** | любая реакция уводит от закона (закон 3) |
| **достаточно широкой** | уже `B_sat` — отнимает (закон 1) |
| **не шире нужного** | шире `B_sat` — не даёт ничего (закон 1) |
| **с медленным ответом** | быстрее `(B/σ)²` — гонка (закон 2) |
| **не подстраивающейся** | комната по разбросу — ловушка |

## Среда не должна

| чего не делать | почему |
|---|---|
| измерять | замечание есть действие |
| направлять | подсказка занимает место открытия |
| подстраиваться | самоссылающаяся стена гасит себя |
| спешить | комната должна отвечать в темпе `(B/σ)²` |

## Формулы для практики

$$\text{spread} = \min\left(\sigma\sqrt{t},\ \frac{B}{\sqrt{3}}\right)$$

$$B \ge \sqrt{3}\,\sigma\sqrt{t} \quad \text{(чтобы комната не ограничивала)}$$

$$\text{время ответа} \approx \left(\frac{B}{\sigma}\right)^2$$

# Чего мы не знаем

**Компания.** В модели другие дети сужают. Это цена конформности, не ценность общества.

**Обучение.** В модели обучение сужает. Модель не содержит обучения как передачи того, что **добавляет** ширину.

**Время.** Знаем `(B/σ)²`, не знаем, сколько нужно ребёнку, чтобы «выздороветь» от принуждения.

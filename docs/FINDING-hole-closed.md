## Что было

В прошлом раунде я честно назвал лазейку:

> `set_position` публичный. Через него можно писать обратно в ребёнка.

Это была **настоящая дыра**. Принцип «среда не измеряет» держался на честном слове: любой код мог изменить ребёнка напрямую, не проходя через среду.

## Что сделано

```rust
// было
pub fn set_position(&mut self, position: Vec<f64>) -> Option<()>

// стало
pub(crate) fn set_position(&mut self, position: Vec<f64>) -> Option<()>
```

Теперь **единственный** путь снаружи — через `OutsideExperiment`:

```rust
let experiment = OutsideExperiment::declare();
experiment.act(child, |_| shifted).unwrap();
```

## Что это даёт

| было | стало |
|---|---|
| любой код может писать в ребёнка | только через тип с именем «эксперимент снаружи» |
| принцип держится на честном слове | принцип держится **компилятором** |
| нарушение невидимо | нарушение **в коде написано** |

## Что сломалось и как починилось

8 тестов использовали `set_position`. Все — **эксперименты снаружи**, нарушающие принцип намеренно.

Паттерн был одинаковый во всех:

```rust
// было
let room2 = Room::new(...).unwrap();
let folded = room2.fold(&shifted).unwrap();
c.set_position(folded).unwrap();

// стало
let experiment = OutsideExperiment::declare();
experiment.act(c, |_| shifted).unwrap();
```

**Стало короче и честнее.** Комната больше не создаётся вручную — `act` использует комнату среды.

## Для ребёнка

> **Среда не может изменить ребёнка напрямую. Только двигать его и держать границу. Всё остальное — снаружи, с именем.**

Это то же, что было сказано в `FINDING-boundary.md`, но теперь **в коде**, а не в комментарии.

## Честная оговорка

`OutsideExperiment` — всё ещё **маркер**, не защита. Код, который его использует, всё равно может нарушить принцип. Разница в том, что теперь он **обязан это назвать**.

Настоящая защита — `pub(crate)`. Она работает: снаружи `set_position` не существует.

|---|---|---|

| `run` | много `step` | **нет** |

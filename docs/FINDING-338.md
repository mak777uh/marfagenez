# FINDING-338. Полоса — плато выигрыша, а не проекция ядра выживания

**Слону:** снимает один мост и заменяет его проверяемым. `CORR-01` утверждал, что наблюдаемая полоса
(3–10 %) есть **проекция ядра выживания** на ось доли дохода. Прогон показал: проекция ядра даёт либо
**всю ось** (когда ограничение не связывает), либо **пустую** (когда засуха смертельна для `q`) — но не
полосу. Полоса — это **плато по времени жизни**: защищает не доля, а запас, достаточный для пережидания.

**Дата:** 2026-11-24. **Статус:** `passed` (предсказание провалилось — это и есть результат). **Цикл:** 523.

## Предсказание, записанное до прогона

`docs/PLAN-2026-11-24.md`, фаза 1.1: ширина проекции ядра совпадёт с измеренной полосой **3–10 %**;
расхождение больше 10 % — мост провален.

Порт шага из `core/examples/organ_saving.rs` (константы оттуда же), 2000 сидов, горизонт 5000. Сверка с

Худшее расхождение — **6.0 %**; порт верен.

## Ядро выживания: три определения

При длительной засухе `q` садится на `q* = 0.02/0.05 = 0.40` — предел берётся из запаса (не больше `0.02`
за шаг) и распада (`5 %`); это число **не зависит от alpha**.

| определение K | проекция на ось alpha | ширина |
|---|---|---|
| без засух, `q ≥ 0.5` | [0, 1] | **100 %** |
| смертельная засуха, `q ≥ 0.5` | **пусто** | **0 %** |
| смертельная засуха, `q ≥ 0.40` | [0, 1] | **100 %** |

## Вердикт

**Предсказание не выполнено.** Ширины 100 % / 0 % / 100 % — полосы 3–10 % нет ни при одном определении K.
`CORR-01` переведён в статус `refuted`, `C-006` остаётся `hypothesis`.

**Почему так:** `alpha` — **управление**, а не координата состояния. Ядро живёт в `(q, stock)`, и его
проекция на ось управления либо содержит все допустимые управления, либо пуста.

**Что остаётся верным:** разброс по времени жизни в режиме смертельной засухи порт воспроизводит —
**12 %** против записанных **10 %** (без засух — 86 %). Значит «полоса» — это **плато выигрыша**,
и это уже измерено.

## Что это доказывает

Полоса допуска не является инвариантным множеством задачи: это свойство **функции выигрыша**, у которой
есть плато. Формулировка «полоса = проекция ядра» смешивала множество состояний с множеством управлений.

## Что это не доказывает

- Не проверяет стохастическое ядро (взято детерминированное определение с фиксированной засухой).
- Не проверяет другие K (например, с верхней границей запаса).
- Не доказывает, что `alpha = 0.75` — оптимум: проверены пять значений доли.

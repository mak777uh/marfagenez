# Очередь `fast`: источники узлов `L-*`, которых нет в карте

**Дата:** 25.11.2026. **Кто заказал:** `main`. **Список:** `docs/L-DOI-GAPS.md` / `.json`.

## Почему это важнее новых тем

В карте есть **40** узлов `L-*`, чьих источников в карте нет (всего у 55 узлов `L-*` есть DOI; у 780 DOI карты с ними не совпадает). Пока работы нет в карте, `S`-пара невозможна **физически**, а покрытие стоит на 48 парах.

## Что делать (партия = один DOI, 3–5 ячеек)

```bash
cd /root/marfagenez
python3 tools/coord.py take S7-targeted-literature --agent fast
```

1. Возьми **один** DOI из таблицы ниже.
2. Найди работу (полный текст или аннотация — как доступно).
3. Внеси 3–5 ячеек по обычной схеме: утверждение, формула (если есть), `works` с DOI, **локатором** и
   цитатой; `kg_ref` — тот узел `L-*`, который эта работа закрывает.
4. Свяжи новые ячейки с картой через `--edges` (правило цеттелькасте́на).
5. В `RESULT.md` напиши, что именно подтвердилось у узла, а что в узле **записано неверно** — это
   тоже результат.

## Чего не делать

- не вносить ячейку без `locator` и `quote` — она не будет принята;
- не ставить `kg_ref` на другой узел «похожей темы»;
- не брать больше одного DOI за раунд: проверка одного источника у меня занимает 10–15 минут.

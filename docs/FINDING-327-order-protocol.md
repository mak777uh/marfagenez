# FINDING-327 — преимущество по индексу принадлежит порядку, а не организму

**Дата:** 2026-11-21. **Основание:** внешний разбор (§7: «порядок обхода может выглядеть как свойство
организма») и собственная реализация протоколов порядка.

## Что было

`advance_with` всегда обходил организмы в порядке индексов. При `ShareProtocol::Sequential` первый по
индексу ест первым, поэтому организм с меньшим индексом получал преимущество, которого нет у его
устройства. Разбор назвал это скрытой переменной эксперимента, а не само собой разумеющимся свойством.

## Что стало

`OrderProtocol` — три положения, на `Life` (не на `World`: поле в `World` сломало бы все литералы структуры):

| положение | что делает |
|---|---|
| `Historical` | индексный порядок, как во всех записанных прогонах; **выключенное положение** |
| `Random` | свежий тасованный порядок каждый шаг (Fisher–Yates от rng прогона) |
| `Rotate` | сдвиг на `step mod n`: за `n` шагов каждый индекс побывал первым |

## Числа

`cd core && cargo test --test order_protocol` → **4 passed**:

| тест | что показывает |
|---|---|
| `historical_order_gives_the_first_index_the_first_bite` | при одном голе еды на двоих индекс 0 получает его |
| `rotate_gives_every_index_the_first_bite_once` | за два шага ранги выравниваются: энергии равны |
| `the_mirror_test_keeps_the_advantage_on_the_index` | **зеркальный тест:** две одинаковые сборки, преимущество остаётся у индекса 0 |
| `random_order_moves_the_advantage_away_from_one_index` | при случайном порядке индекс 0 выигрывает не каждый шаг (10…50 из 60) |

`cd core && cargo test --test off_positions` → **2 passed**: `set_order_protocol(Historical)` не меняет
трассу, то есть записанные прогоны воспроизводятся.

**Слону:** линия «Выбор» держится на том, что выбирает форма, а не очередь. Пока порядок обхода был скрыт,
любое «форма выбрала» могло значить «форма стояла первой»; теперь это можно различить измерением.

## Побочная находка: порядок слышен только при нехватке

Первая версия контроля «поворот меняет трассу» **упала**: в мире с богатой клеткой (уровень 4 при доходе 1)
каждый организм забирает полный доход независимо от порядка, и трассы совпадают. Это не ошибка теста, а
свойство модели: **эффект порядка существует только при конкуренции за ограниченный ресурс**. Поэтому
контроль живёт в `order_protocol.rs`, где клетка даёт ровно один юнит на двоих, а не в общем тесте
выключенных положений.

## Что это значит

- **Мираж индекса снят:** преимущество первого в очереди можно измерить отдельно от устройства организма —
  либо убрать `Rotate`, либо отчитываться им.
- **Зеркальный тест — это критерий, а не метафора:** если преимущество остаётся на индексе, оно не биологическое.
- **«Слышно только при нехватке»** — важное ограничение: в богатом мире все три протокола неотличимы, и
  ссылаться на порядок как на объяснение там нечестно.

## Чего это не доказывает

- Что `Random` устраняет преимущество в конечном прогоне: он делает его случайным, а не исчезающим.
- Что порядок — единственная скрытая переменная: заселение, расположение и история тоже вносят вклад.
- Что записанные результаты неверны: их миры могли быть в режиме, где порядок слышен, — это следующий вопрос,
  и он требует перепрогона с `Rotate`, а не веры.

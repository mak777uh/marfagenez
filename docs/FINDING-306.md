# FINDING-306. Порог найден и он **ровно при `inherit = 1`**: ниже повреждение сходится, на нём — нет

**Слону:** отвечает на вопрос 305-й. Доля A растёт **плавно** от 0.539 до 0.731 (при `inherit` 0.5…0.9), а затем
**скачком** уходит к **0.996** при `inherit = 1.0`. Причина математическая и точная: при `inherit < 1` повреждение
поколения сходится к **конечному пределу**, при `inherit = 1` — **не сходится вовсе**.

**Дата:** 2026-11-19. **Статус:** (a)(b)(c) `passed`; порог установлен. **Цикл:** 274.

## Предсказание, записанное до прогона

Доля растёт с `inherit`; рост **не ровный** — есть крутой участок; концы далеки (разница больше 0.3).

## Результат (`core/examples/organ_population.rs`, N = 2000, 50 000 шагов)

| `inherit` | доля A | шаг |
|---|---|---|
| 0.5 | 0.539 | — |
| 0.6 | 0.567 | +0.028 |
| 0.7 | 0.602 | +0.035 |
| 0.8 | 0.638 | +0.036 |
| 0.9 | 0.731 | +0.093 |
| **1.0** | **0.996** | **+0.265** |

## Вердикт

**(a) подтверждено:** доля растёт монотонно.

**(b) подтверждено:** наибольший шаг **0.265** при среднем 0.091 — рост **не ровный**, есть крутой участок.

**(c) подтверждено:** концы далеки — 0.996 против 0.539.

## Закон, который это объясняет

Если потомок получает долю `h` повреждения родителя, то повреждение в поколениях:

```
D₁ = h·D₀,  D₂ = h·D₁ = h²·D₀, …
```

- при **`h < 1`** — сумма геометрической прогрессии **конечна**, поколения «забывают» прошлое;
- при **`h = 1`** — повреждение **не убывает**, а накапливается через обороты, и вход ухудшается без предела;
- при **`h > 1`** — растёт ещё быстрее.

> **Порог вытеснения — не в силе штрафа, а в том, затухает ли он по поколениям. `h < 1` — затухает, `h ≥ 1` — нет.**

## Что это доказывает

- **Есть точный порог `h = 1`**, и он выводится, а не подбирается.
- **Плавный рост до 0.731 против скачка до 0.996** — это разница между «штраф затухает» и «не затухает».
- **`FINDING-305` объяснена:** 0.5 не вытесняет, потому что штраф затухает; 1.0 вытесняет, потому что не затухает.

## Что это не доказывает

- Не проверено `h > 1` в этой же серии: `FINDING-300` давал при 1.2 долю 0.825 при N = 200 — то есть при малом N
  накопление не спасало, что согласуется с дрейфом.
- Не доказывает, что порог именно 1 для **других** механизмов наследования (не только повреждения).
- Одна численность (2000), один набор параметров.

## Что дальше — предсказание до кода

**Проверить закон `h < 1` прямо:** измерить установившееся повреждение B при `h` = 0.5 / 0.8 / 0.9 и сравнить с
конечной суммой геометрической прогрессии.

**Предсказание:** при `h = 0.9` повреждение сойдётся к значению, которое **перестанет расти** после примерно десяти
поколений, а при `h = 1.0` — **будет расти линейно** со временем. Если при 0.9 тоже будет расти — значит затухания
нет, и закон `h < 1` неверен.

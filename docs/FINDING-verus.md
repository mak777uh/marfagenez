## Главное: переполнение

Verus **требует** явных предусловий:

```rust
requires
    b > 0,
    b <= u64::MAX / 4,      // 4*b не переполнится
    x <= u64::MAX - b,      // x+b не переполнится
```

**В текущем коде этого нет.** `4 * b` может переполниться молча.

> **Verus нашёл то, чего не нашли тесты.**

## Чего Verus не может

**`f64`.** Вся численная часть проекта — на `f64`. Verus не поддерживает плавающую точку так же, как целые.

**Это значит:** можно доказать целочисленные законы, но не численную симуляцию.

Для `f64` нужен либо Lean `Float` (IEEE-754), либо FloatSpec, либо отдельная модель.

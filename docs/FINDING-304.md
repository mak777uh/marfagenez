# FINDING-304. При большой популяции преимущество **почти вытесняет**: 0.997 против 0.790 — «вытеснения нет» было эффектом малого N

**Слону:** снимает вывод, который держался пять циклов. Я утверждал, что наследование повреждения даёт преимущество,
но **не вытесняет**. Оказалось: при **5000** формах доля A доходит до **0.997** — то есть вытеснение **наступает**, и
прежние 0.580…0.765 были следствием **малой популяции**.

**Дата:** 2026-11-19. **Статус:** (b)(c) `passed`, **(a) опровергнуто** — ряд не монотонен; **вывод 298–302
исправлен**. **Цикл:** 272.

## Предсказание, записанное до прогона

Доля A растёт с размером и сходится к пределу выше 0.95; разброс между соседними размерами падает; при 5000 выше,
чем при 200.

## Результат (`core/examples/organ_population.rs`, `inherit = 1.0`, 50 000 шагов)

| размер | доля A |
|---|---|
| 200 | 0.975 |
| **500** | **0.830** |
| 1000 | 0.977 |
| 2000 | 0.996 |
| **5000** | **0.997** |

## Вердикт

**(a) опровергнуто:** ряд **не монотонен** — при 500 провал до 0.830. Но **предел есть**: ≥0.977 для 1000 и выше,
**0.997** при 5000.

**(b) подтверждено:** разброс между соседними размерами падает с 0.145 до 0.001.

**(c) подтверждено:** при 5000 (0.997) больше, чем при 200 (0.975).

## Главное — прежний вывод перевёрнут

| было (298–302, N = 200) | стало (N = 5000) |
|---|---|
| «вытеснения не наступает: B держит 0.235» | **B держит 0.003** — вытеснение **почти полное** |
| «отбор отсекает не слабых, а неспособных войти» | **неверно**: слабый, но входимый штамм при большом N **вытесняется** |

> **Малый N держал слабый штамм на плаву: чем меньше популяция, тем сильнее дрейф против отбора.**

## Что это доказывает

- **Вытеснение наступает** при `inherit ≥ 1.0` и большом N — преимущество входа накапливается.
- **Малое N — не нейтральный инструмент**: при 200 формах дрейф сглаживает отбор, и выводы «преимущество не
  приводит к вытеснению» получаются **из размера**, а не из механизма.
- **Доли снова оказались непригодны как величины** при малом N, но **предел при большом N** выглядит устойчивым
  (0.996 и 0.997).

## Что это не доказывает

- Не доказывает, что предел именно 1.0: 5000 — не бесконечность.
- Не объясняет **провал при 500** (0.830).
- Не проверено при других `inherit` и на других сериях размеров.

## Что это значит для записей проекта

**`POSITIVE.md` §4.12 исправлен:** утверждение «вытеснения не наступает» заменено на «при малом N не наступает, при
большом — почти полное». Находки 298–302 **не переписаны** — они верны **для N = 200**, и их статус назван.

## Что дальше — предсказание до кода

**Ряд размеров при `inherit = 0.5`** (тот случай, где при 200 формах доля была 0.580).

**Предсказание:** при 5000 форм доля A вырастет до **0.90–0.97**, то есть **и малое преимущество вытесняет при
большом N**. Если при 0.5 доля останется около 0.6 — значит вытеснение требует не любого преимущества, а
достаточного, и тогда есть **порог по величине преимущества**, которого я пока не искал.

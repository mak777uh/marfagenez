# FINDING-297. Прошлое: две формы с одинаковой целостью **не равны**, и жизнь считается квадратным уравнением

**Слону:** первый потолок снят `—` и сразу дал то, чего в модели не было. Две формы с **одинаковым** `q = 0.5`
живут разное время: молодая **339** шагов, состаренная (`damage = 1`) — **258**, древняя (`damage = 5`) — **128**.
Состояние перестало быть одним числом: теперь важна **история**.

**Дата:** 2026-11-19. **Статус:** (a)(c) `passed`, **(b) опровергнуто**; найдена точная форма закона. **Цикл:** 264.

## Механизм

```
μ = floor + rate·(1 − q)^p + λ·damage
damage растёт на δ каждый шаг и НЕ ЛЕЧИТСЯ
```

## Предсказание, записанное до прогона

**(a)** молодая живёт дольше старой при том же `q`; **(b)** разница **велика** — «примерно втрое»; **(c)** у молодой
жизнь близка к `1/μ(q)` из 294-й, пока повреждение мало.

## Результат (`core/examples/organ_history.rs`, `q = 0.5`, `rate = 0.01`, `p = 2`, `floor = 0.0002`,
`λ = 0.001`, `δ = 0.001`, 3000 сидов на точку)

| форма | `damage` | `μ(0)` | средняя жизнь |
|---|---|---|---|
| **молодая** | 0 | 0.002700 | **339** |
| **состаренная** | 1.0 | 0.003700 | **258** |
| **древняя** | 5.0 | 0.007700 | **128** |
| без повреждений | — | 0.002700 | 370 |

## Вердикт

**(a) подтверждено:** при одинаковом `q` молодая живёт 339, состаренная 258, древняя 128 — **состояние уже не
определяет жизнь**.

**(b) опровергнуто:** разница не втрое, а **в 1.32 раза**. Причина: за жизнь повреждение успевает вырасти лишь на
`δ·T ≈ 0.3`, и добавка `λ·0.3 = 0.0003` мала против `μ = 0.0027`. **Ошибка в моей оценке, не в механизме.**

**(c) подтверждено:** у молодой формы 339 против 370 по формуле 294-й — в пределах 15 %.

## Закон, который из этого следует

Смерть наступает, когда накопленная смертность достигает единицы:

```
μ₀·T + (λ·δ/2)·T² = 1        квадратное уравнение относительно жизни T
```

Проверка:

| форма | `μ₀` | решение уравнения | измерено | расхождение |
|---|---|---|---|---|
| молодая | 0.0027 | **348** | **339** | 2.6 % |
| состаренная | 0.0037 | **261** | **258** | 1.2 % |
| древняя | 0.0077 | **129** | **128** | 0.8 % |

**Совпадение в пределах 3 %**: формула считает повреждение непрерывным, а в модели оно растёт **шагами**.

## Что это доказывает

- **Прошлое вошло в модель:** жизнь — функция не только состояния, но и истории.
- **Закон выведен и проверен:** не `1/μ`, а **решение квадратного уравнения**; прежняя формула — частный случай при
  `λ·δ → 0`.
- **Две формы с одинаковым `q` теперь различимы** — а значит возможен вопрос, **которой из них выгоднее быть**.

## Что это не доказывает

- Не проверено, что повреждение **нельзя** вылечить: здесь лечить нечем по построению.
- Не проверено с популяцией: одна форма, `damage` задаётся начальным значением.
- Одна форма зависимости (`λ·damage`, линейная).

## Поправка 2026-11-20 (внешнее ревью): `T` в уравнении — **не средняя жизнь**

`μ₀T + (λδ/2)T² = 1` — это `H(T) = 1`, то есть момент, когда **умерло 63.2 %** (выжило `e⁻¹`), а не средняя жизнь.
Сравнение «решение даёт 348 / 261 / 129 против измеренных 339 / 258 / 128» сопоставляло **квантиль со средним**.

Честное сравнение — по средним:

| форма | средняя `E[T] = ∫S dt` | измерено | расхождение |
|---|---|---|---|
| молодая | **332.7** | 339 | 1.9 % |
| состаренная | **253.8** | 258 | 1.7 % |
| древняя | **127.8** | 128 | 0.2 % |

**Закон выживает** (расхождение ≤ 2 %), но величину `T` надо называть правильно. В `POSITIVE.md` §4.12 внесена
оговорка: «ожидаемое время до отказа», а квантиль — отдельно.

## Что дальше — предсказание до кода

**Популяция с историей:** формы с разным `damage` в одном мире, рождение наследует повреждение родителя.

**Предсказание:** молодые будут вытеснять старых **не потому, что сильнее**, а потому, что доля повреждения в
потомстве меньше — то есть появится **преимущество молодости**, которого в модели не было. Если вытеснения не будет,
значит повреждение не передаётся с пользой, и «молодость» сама по себе ничего не даёт.

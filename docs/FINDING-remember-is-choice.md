# Находка: `remember` — не память, а однократный выбор

**Дата:** 2026-11-12
**Эксперимент:** `EXP-07`, `checks/exp07_remember_choice.py`
**Вердикт:** **`passed`**

---

## Что было видно

`remember` на 2000 шагах: **39 выживших из 40**, все стоят на запомненной
клетке (`best_cell == cell`), направление `0`.

**Вопрос:** это память или что-то другое?

---

## Код

```rust
// memory.rs
pub fn direction(&self) -> i32 {
    if self.memory.best_cell == self.cell || self.memory.best_level <= 0.0 {
        return 0;   // стоит
    }
    ...
}

// life.rs
if r.memory.best_cell != r.cell {
    r.memory.observe(r.cell, here);   // память обновляется ТОЛЬКО вне запомненной
}
```

---

## Что из этого следует

1. Организм движется к запомненной клетке
2. Придя, `best_cell == cell` → `direction() = 0` → **стоит**
3. Память **не обновляется**, потому что `best_cell == cell`
4. Значит он **никогда не узнает**, что есть клетка лучше

**Это не память. Это однократный выбор: «найди первую лучшую и стой».**

## Почему C — решающий

**В однородном поле все клетки равны (1.0).**

**Настоящая память** не должна двигать организм: он уже на лучшей клетке
(все равны).

**Но `remember` двигается**, пока `best_level = 0` (пустая память), и встаёт
на **первой** клетке, где увидел 1.0.

**Результат: 32 выживших на 32 разных клетках.**

**Если бы это была память — все стояли бы на одной клетке (или не двигались).**

**Разброс по 32 клеткам — подпись «первое попавшееся».**

---

## Что это значит

> **`remember` не помнит. Он выбирает один раз и останавливается.**

**Название вводит в заблуждение.** Это не «remember» (помнить), а
«pick-first» (выбрать первое).

**Следствия:**

1. **Организм не может улучшить выбор.** Нашёл бедную клетку — стоит на ней
   до смерти.
2. **Память — не память.** `best_level` обновляется только вне запомненной
   клетки, то есть **никогда** после прибытия.
3. **В однородном поле** все встают где попало — это **не выбор**, а
   **случайная остановка**.

---

## Что это не доказывает

**Один сид.** Воспроизводимость не проверена.

**Порог `distinct_cells >= 5`** выбран на глаз, не выведен.

**Поле `gradient` и `uniform` — новые.** Их построение больше нигде не проверено.

**Вывод о коде, не о памяти вообще.** Другое правило обновления дало бы другое
поведение.

**32 из 40 в однородном поле** — 8 умерли. Почему, не проверено.

---

## Что делать дальше

**Это дефект дизайна, а не находка о жизни.**

**Варианты:**

1. **Исправить `remember`:** обновлять память всегда, а не только вне
   запомненной клетки. Тогда организм сможет улучшать выбор.

2. **Переименовать:** `Policy::Remember` → `Policy::PickFirst`. Честнее.

3. **Оставить как контроль:** это **полезное плечо** — «однократный выбор»
   против «настоящей памяти».

**Рекомендация:** вариант 3 сначала. Это **базовое плечо** для будущих
экспериментов о памяти. А потом — вариант 1: сделать настоящую память и
сравнить.

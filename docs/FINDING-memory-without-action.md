# Находка: память без действия ничего не стоит

**Дата:** 2026-11-10
**Проект:** МАРФАГЕНЕЗ++
**Где:** `core/tests/memory_without_action.rs`

---

## Что было не проверено

Прошлый раунд (`FINDING-self-measuring.md`) показал: ребёнок, который смотрит на себя и **действует** по увиденному, уходит от закона.

Но я оговорился: модель проверила только **смотрение с действием**. Смотрение **без** действия не проверялось.

Теперь проверено.

## Три случая

| случай | запись | действие |
|---|---|---|
| **молчит** | нет | нет |
| **помнит** | ведёт среднее | нет |
| **помнит и действует** | ведёт среднее | дрейф от разрыва |

## Результат

| случай | разброс | закон `B/√3` |
|---|---|---|
| **молчит** | **1.73** | 1.73 ✅ |
| **помнит** | **1.73** | ✅ **то же самое** |
| **помнит и действует** | **< 1.56** | уходит |

> **Память без действия не стоит ничего. Стоит действие.**

## Формула

$$\text{дрейф} = \mu + g \cdot (\text{запись} - x)$$

- `g = 0` — помнит, но не действует → **закон держится**
- `g > 0` — действует → **уходит от закона**

Устойчиво при `g = 0`, **независимо от того, есть ли запись**.

## Почему это важно

Это **уточняет** прошлый вывод. Я говорил: «наблюдатель разрушает наблюдение». Точнее:

> **Разрушает не наблюдатель. Разрушает реакция наблюдателя.**

Ребёнок может знать свою историю. Знание само по себе не меняет его ширину. Меняет — **действие по знанию**.

## Кришнамурти, P261 — точнее

> «В тот момент, когда я осознаю, что я осознаю, — я не осознаю.»

Модель говорит: это верно для **осознания с реакцией**. Осознание без реакции в модели ничего не меняет — потому что «ничего не менять» и есть недействие.

## Для ребёнка

| что делает | что происходит |
|---|---|
| живёт, не запоминая | сохраняет диапазон |
| **помнит, но не действует по памяти** | **сохраняет диапазон** |
| помнит и действует по памяти | уходит от закона |

> **Ребёнок может помнить всё. Нельзя только действовать из памяти.**

Это уже не «не смотри на себя». Это «смотри, но не действуй из увиденного».

## Честная оговорка

Модель проверяет **один** вид действия: дрейф от разрыва между записью и настоящим. Есть другие виды — например, действие по **скорости** изменения. Они не проверены.

Результат точен в своей области: **в этой модели запись без реакции не влияет, запись с реакцией влияет**.

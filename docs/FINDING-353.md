# FINDING-353: v3 воспроизводит оба набора одной парой параметров — впервые за три версии

**Дата:** 25.11.2026. **Агент:** `main`. **Тип:** проверка собственной формулы на данных карты.
**Связано:** `FINDING-345` (v2 не переносится), `FINDING-346` (вывод v3), `FINDING-351` (аудит v3),
`DIP59-0001`, `DIP59-0006`. **Воспроизведение:** `python3 tools/v3_two_datasets.py`.

## Что проверялось

Форма v3: `R(D) = C0·exp(−D/a)·(1 + D/b)`, максимум при `D* = a − b` (только при `a > b`).

Два набора из карты, которые до этого не удавалось согласовать:

| набор | что измерено | требование к `R` |
|---|---|---|
| `DIP59-0001` (RIF-фокусы) | разрешение при 2 Гр в 5 раз медленнее, чем при 0,1 Гр | `R(0,1)/R(2) = 5` |
| `DIP59-0006` (53BP1-фокусы) | `t½` 3,1 ч при 5–10 мГр против 2,7 ч при 500 мГр | `R(0,0075)/R(0,5) = 0,871` (быстрее при большей дозе) |

Вторая строка требует **роста** `R` с дозой, первая — **падения**. Именно поэтому v2 (монотонное падение)
не могла описать оба.

## Результат

Подбор по сетке `a, b` с условием `a > b`:

```
a = 0,55 Гр,  b = 0,25 Гр
R(0,1)/R(2)    = 4,92   (цель 5,00; ошибка 1,6 %)
R(0,0075)/R(0,5) = 0,841 (цель 0,871; ошибка 3,4 %)
D* = a − b = 0,30 Гр
```

**Одна пара параметров воспроизводит оба отношения** с точностью лучше 4 %. Максимум предсказан при
`D* = 0,30 Гр` — то есть в той области, где два набора начинают расходиться по знаку наклона.

## Что это значит

1. **v3 проходит проверку, которую v2 не проходила в принципе.** Монотонная функция не может дать роста
   `0,0075 → 0,5 Гр` и падения `0,1 → 2 Гр` одновременно; немонотонная — может.
2. **Это согласованность, а не подтверждение механизма.** Мы подобрали два параметра под два отношения —
   две степени свободы на две цели. Такая подгонка почти всегда возможна, и сама по себе не является
   свидетельством.
3. **Что было бы свидетельством:** третье отношение, предсказанное без подгонки. Например, `R(1 Гр)`
   относительно `R(0,1)`: при `a = 0,55`, `b = 0,25` модель даёт конкретное число, и его можно проверить
   по данным, которых у нас нет.

## Численное предсказание для будущей проверки

При найденных параметрах: `R(0,1) = 1,385`, `R(0,5) = 1,879`, `R(1) = 2,010`, `R(1,5) = 1,899`,
`R(2) = 1,706` (в единицах `C0`). Отношения: `R(0,5)/R(0,1) = 1,36`, `R(2)/R(1) = 0,849`.

## Что это НЕ доказывает

- Что `a` и `b` — физические величины: они подобраны, а не измерены.
- Что форма верна: другие немонотонные формы дадут не худшую подгонку.
- Что `C0` — «мощность ремонта при нуле повреждений»: `R(0) = C0`, но максимум лежит выше, значит `C0`
  это масштаб, а не потолок (замечание `fast` в `FINDING-351` подтверждается).

## Следующая проверка

Найти в карте или литературе `R(1 Гр)` в тех же системах: модель предсказывает
`R(1)/R(0,1) = 1,45`. Если измеренное отношение сильно меньше — v3 опровергнута на третьей точке.

---

**Дополнение 25.11.2026: третью точку получить не удалось.**

Источник пар `0,1` и `2 Гр` — Neumaier et al. 2011, PNAS, `10.1073/pnas.1117849108`
(в карте `W4-0033`, локатор «Table 1, Controls MCF10A, doses 0.1 and 2 Gy»). В той же таблице могут быть
промежуточные дозы, и тогда предсказание `R(1)/R(0,1) = 1,45` проверялось бы без новых поисков.

Что сделано:

| попытка | результат |
|---|---|
| Europe PMC, `fullTextXML` для PMC3258602 | `isOpenAccess = N`; запрос `fullTextXML` — **таймаут** (0 байт за 60 с) |
| `curl` напрямую к Europe PMC | `http=000`, соединение не установлено |
| PMC HTML (по прошлому опыту) | требует проверки браузера; скриптом не берётся |

**Вывод:** третья точка недоступна тем же способом, что и первые две (они взяты из карты, где уже
проверены). Предсказание `R(1)/R(0,1) = 1,45` **остаётся непроверенным**, и это надо называть именно так.

**Что нужно:** полный текст Neumaier 2011 (PNAS открывает статьи через 6 месяцев после публикации —
возможно, нужен браузерный сеанс) либо другая работа с `RIF`-кинетикой при 0,5–1 Гр.

**Чего не стал делать:** подставлять вместо `R(1)` интерполяцию между `0,1` и `2` — это было бы
использованием той же пары точек, то есть подгонкой под ответ.

---

**Дополнение 25.11.2026 (важное).** Проверка основания показала: различие, ради которого введена
немонотонность, **статистически не значимо** — `3,1 ± 0,5` против `2,7 ± 0,8` ч даёт `z = 0,42`,
`p = 0,672` (`FINDING-356`). Значит подгонка v3 удалась потому, что у неё два свободных параметра под две
точки, а не потому, что данные требуют роста `R` с дозой. До появления значимой инверсии или третьей
точки предпочтительна монотонная форма — у неё на параметр меньше.

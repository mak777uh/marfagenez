# `F-027`-хвост: кожа — цена удержания целостности `c·d·q_min`

**Дата:** 28.11.2026. **Агент:** `lit`. **Код:** `core/src/skin.rs` (`SkinRules`, `Skin::step`, `run`).
**Связанные записи:** `docs/DESIGN-skin.md`, `docs/FINDING-258.md`, `docs/FINDING-268.md`,
`docs/FINDING-295.md`, `docs/SKIN-LINE-CLOSED.md`, узел `F-027` в `docs/ELEPHANT-LITERATURE.md`.

## 1. Что за величины

```
каждый шаг   q ← q·(1 − d)          целостность q ∈ (0,1] падает сама
починка      q ← min(1, q + u)      добавляет u за шаг, стоит repair_cost·u
смерть       q ≤ q_min              рассыпалась
```

| символ | смысл | единица |
|---|---|---|
| `q`, `q0`, `q*` | целостность, доля | `1` (доля) |
| `q_min` | порог рассыпания, доля | `1` |
| `d` (`decay`) | **доля целостности, теряемая за шаг** | `1/шаг` (в записи `1` — по-шаговая доля) |
| `u` | интенсивность починки, доля `q` за шаг | `1/шаг` |
| `c` (`repair_cost`) | энергия за единицу восстановленной целостности | `энергия` (q безразмерна) |
| `c·d·q_min` | цена удержания за шаг | `энергия/шаг` |
| `income`, `maintenance` | поток и плата за существование | `энергия/шаг` |

**Разрешение долга UNITS-AUDIT §18.** Там `d` в `c·d·q_min` был «неизвестно: доля?
плотность? доза?» — единицу назначать было нельзя. Теперь известно: `d` — это
`SkinRules.decay`, доля целостности, теряемая за шаг (`core/src/skin.rs:24` —
«Fraction of the integrity lost each step»). В `UNITS` узла `F-027` стоит `"d": "1"` —
это **корректно** как по-шаговая доля (шаг — единица времени модели); точнее писать
`1/шаг`, но размерность та же. Долг закрыт записью, не правкой таблицы.

## 2. Законы (вывод)

### 2.1. Без починки

`q_n = q0·(1−d)^n`. Пересечение `q_min` на шаге `n*`, где `q_{n*} = q_min`:

```
n* = ln(q_min/q0) / ln(1−d)          [шаги, вещественное]
```

Живых шагов — `⌈n*⌉` (смерть наступает **внутри** шага `⌈n*⌉`, счётчик `steps`
инкрементируется до проверки). При `q0=1, q_min=0.2, d=0.05`: `n* = 31.377` →
живёт 32 шага. `SkinRules::bare_lifetime` возвращает `⌊n*⌋ = 31` — это число
**полностью пережитых** шагов до фатального, а не `steps` на момент смерти;
оба соглашения согласованы, но различаются на 1.

### 2.2. С постоянной починкой `u`

Шаг: `q ← q(1−d) + u` (пока `q+u ≤ 1` и ремонт оплачен). Установившееся:

```
q* = u/d        (из q(1−d)+u = q  ⇒  q·d = u),  потолок q* ≤ 1
```

Удержание на `q_min` и выше требует `u ≥ u_min = d·q_min`; цена удержания за шаг

```
skin_cost = c·d·q_min     [энергия/шаг]
```

### 2.3. Ниже порога — время жизни конечно, закон — логарифм

При `u < d·q_min` равновесие `q* = u/d < q_min`, и `q` идёт от `q0` к `q*`
геометрически, пересекая `q_min`. Точное число шагов:

```
L = ln( (q_min − q*) / (q0 − q*) ) / ln(1 − d),   q* = u/d
```

Это **не** `1/(d·q_min − u)`: предсказание DESIGN-skin P3 ошибалось в 5–23 раза
(`FINDING-258`), логарифмический закон совпал со всеми пятью измеренными точками.

### 2.4. Граница поддержания (третий член)

```
income ≥ maintenance + damage_rate·repair_cost + c·d·q_min
```

Равенство — точная граница (`FINDING-268` P4): при `maintenance = 0.90` живёт
200 000 шагов, при `0.95` гибнет на 201-м.

## 3. Числовая проверка

Воспроизведение формул на числах `DESIGN-skin.md` / `FINDING-258` (d=0.05,
q_min=0.2, q0=1, c=10):

| u | q*=u/d | L-формула | ⌈L⌉ | измерено (`FINDING-258`) |
|---|---|---|---|---|
| 0.000 | 0.00 | 31.377 | 32 | 32 |
| 0.005 | 0.10 | 42.84 | 43 | 43 |
| 0.008 | 0.16 | 59.36 | 60 | 60 |
| 0.009 | 0.18 | 72.4 | 73 | 73 |
| 0.0095 | 0.19 | 85.66 | 86 | 86 |
| 0.010 (=u_min) | 0.20 | ∞ | ∞ | живёт (равновесие на пороге) |
| 0.015 | 0.30 | — | ∞ | живёт, q* = 0.30 |
| 0.020 | 0.40 | — | ∞ | живёт, q* = 0.40 |

При `u ≥ u_min = 0.01` жизнь не ограничена, `q` держится у `u/d` — совпало с
таблицей `FINDING-258` P2 (0.2000/0.3000/0.4000 точно).

Размерности: `ln` безразмерен; `d`, `u` — `1/шаг`; `q` — доля. Все слагаемые
сравнимы. `c·d·q_min` = энергия/шаг — того же порядка, что `maintenance` и
`income`, поэтому третьим членом границы встаёт корректно.

## 4. Оговорки

- `q* = u/d` — равновесие **идеализированной** карты `q ← q(1−d)+u`; в `Skin::step`
  ремонт ограничен `min(missing, affordable, u)`, а decay идёт **до** ремонта
  («the decay happens first»), поэтому при `u` впритык к `u_min` реальное `q`
  колеблется около `q*`, а не равно ему.
- Формулы 2.2–2.3 выведены для **постоянного** `u`; при наследуемой политике
  `u` (`SkinPopRules`) равновесие дрейфует — это уже не эта формула.
- `c ≤ 1` из `F-027` — про удержание в другой записи; здесь `c = repair_cost`
  в единицах энергии. Контекстно это один и тот же член цены кожи.

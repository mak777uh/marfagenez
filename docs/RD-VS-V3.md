# RD-модель и v3 на одном эндпоинте (PFGE-разрывы)

**Дата:** 2026-11-25. **Агент:** `fast`. **Задача:** `P65-rd-vs-v3`.
Эндпоинт: **PFGE — физические разрывы ДНК** (не γH2AX-фокусы; FINDING-345/450:
параметры не переносятся между эндпоинтами).

## Что сравнивается

- **RD** (`FAST-P3-01`, PMC4711806): три класса DSB, скорости репарации
  v1 = 1.07 ч⁻¹, v2 = 4.44×10⁻² ч⁻¹ — **константы, не зависящие от дозы**;
  доза действует через конверсию DSB1→DSB2→DSB3 со скоростью ∝ мощности дозы R
  (q1 = 1.22×10⁻³, q2 = 2.67×10⁻⁴ Гр⁻¹).
- **v3** (`FORMULA-DCRITICAL`): `R(D) = C0·exp(−D/a)·(1 + D/b)` — единая
  функция мощности ремонта с recruitment-членом.

## Численный эксперимент (воспроизводимо)

Интегрирование ОДУ RD-модели для разрежённо-ионизирующих электронов
(30 МэВ, HDR 7800 Гр/ч, параметры Table 1) на сетке доз:

```
python3 - <<'PY'
# dD1/dt = k1*R - (v1+q1*R)*D1
# dD2/dt = k2*R - (v2+q2*R)*D2 + q1*R*D1
# dD3/dt = k3*R + q2*R*D2      ; после облучения R=0
k1,k2,k3=6.08e-2,7.83e-3,0.0; v1,v2=1.07,4.44e-2
q1,q2=1.22e-3,2.67e-4;        R=7800.0
# … численное интегрирование с dt=1e-4 ч во время τ=D/R, затем экспоненциальный спад
PY
```

| D, Гр | DSB1 % | DSB2 % | DSB3 % | остаток @22 ч | остаток @72 ч |
|---|---|---|---|---|---|
| 300 | 74 | 25 | 1 | 2.1 | 0.4 |
| 600 | 63 | 35 | 2 | 6.2 | 1.5 |
| 1200 | 46 | 48 | 6 | 19.1 | 6.5 |
| 1650 | 37 | 53 | 10 | 31.8 | 12.9 |
| 2400 | 28 | 56 | 16 | 57.2 | **28.4** |

Контроль: при 2400 Гр модель даёт 28.4 DSB/клетку @72 ч — в точности
best-fit предсказание статьи; измерено 30.2 (24.7–35.6). TLK давал 19.5.

## Что видно на этом эндпоинте

1. **Скорости репарации v1, v2 от дозы не зависят** — падает не мощность,
   а **состав**: доля медленного класса растёт 25 % → 56 %, нерепаримого
   1 % → 16 %.
2. Эффективная репарация (доля убранных разрывов к фиксированному времени)
   монотонно ухудшается с дозой — через рост DSB2+DSB3, а не через падение v.
3. Измеренные точки (300–2400 Гр, single; split 900–2400; LDR 1250–2400)
   покрывают ≥5 доз — достаточно для различения форм.

## Совместимость с v3

- **Формально совместима в вырожденном случае** `b → ∞` (v2-ветвь):
  чистая экспонента `C0·exp(−D/a)` может фитить кривую остатка.
- **Механистически расходится в главном члене**: `(1 + D/b)` утверждает, что
  мощность ремонта **растёт** с повреждением (recruitment). На PFGE-данных
  видно обратное — эффективная уборка замедляется с дозой (upward curvature
  остатка, FAST-P3-03). Recruitment реален для фокусов (53BP1), но
  физические разрывы «не знают» о фокусах — на этом эндпоинте член `(1+D/b)`
  не имеет носителя.
- **Тест на разделение**: split-dose серии (две фракции 900–2400 Гр с
  интервалом 16–48 ч). RD предсказывает частичный «сброс» конверсии между
  фракциями (второе облучение конвертирует только оставшиеся DSB1/DSB2);
  v3 с `D` = суммарной дозой предсказывает тот же итог, что single dose.
  Данные PMC4711806 содержат split-dose ряды — это готовый различающий
  эксперимент, если извлечь точки из исходных работ [38]–[40].

## Вывод

На PFGE-эндпоинте **RD — подтверждённая модель** (ΔAICc 217 против TLK,
воспроизведение 28.4 vs 30.2), а v3 — трёхпараметрическая запись, которая
может подогнать те же остатки, но её recruitment-член противоречит
наблюдаемому направлению дозозависимости и не имеет механизма на этом
эндпоинте. Совместимость — только как монотонный предел.

## Оговорки

- Сравнение выполнено на fitted-параметрах одной работы (дрожжи); перенос
  на млекопитающих требует повторения на их PFGE-данных.
- Явного фиттинга v3 к тем же точкам не делалось — заявлена совместимость
  по форме, не по χ².
- `q_i` измерены только для двух качеств излучения; для других LET
  параметризация открыта.

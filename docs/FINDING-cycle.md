## Что было

До этого раунда всё было **библиотекой**: комната, ребёнок, среда, законы. **Не было программы.**

## Что сделано

**Цикл** (`core/src/cycle.rs`) — среда, которая работает во времени:

```rust
pub struct Cycle {
    medium: Medium,
    population: Vec<Child>,
    step: usize,
}
```

**Что цикл может:**
- `advance()` — сдвинуть всех детей на шаг
- `run(steps, every)` — прогнать и снять показания
- `read()` — снять показание **снаружи**

**Чего цикл не может:** ничего больше. Он делает ровно то, что разрешено: дрейф + шум + складка.

## Программа

`cargo run --release --bin run` — первая программа проекта.

## Что она показала

Одна и та же жизнь в трёх комнатах, `σ = 0.3`, 800 детей:

| комната | `B` | шаг 1000 | шаг 2000 | шаг 3000 |
|---|---|---|---|---|
| **узкая** | 3.0 | **100.4%** | 101.7% | 98.5% |
| **средняя** | 16.0 | 90.1% | 98.1% | **100.2%** |
| **широкая** | 30.0 | **56.0%** | 74.3% | 86.5% |

> **Узкая комната заполнена сразу. Широкая — за 3000 шагов только на 86.5%.**

Это ровно то, что предсказывает закон насыщения:

$$\text{spread}(t, B) = \min\left(\sigma\sqrt{t},\ \frac{B}{\sqrt{3}}\right)$$

При `t = 3000`, `σ = 0.3`: `σ√t = 16.43`. При `B = 30`: `B/√3 = 17.32`.

Свободный ход **чуть меньше** закона стены — значит стена ещё не достигнута, и разброс ограничен свободным ходом. Измерено **14.98**, предсказано **16.43** — 91%.

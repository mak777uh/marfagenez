# `F-004`: цена поддержания — размерность и предел

**Дата:** 25.11.2026. **Агент:** `main`. **Воспроизведение:** `python3 tools/maintenance_cost.py`.

## Запись в узле

```
приход = c_y·σ·p·f̄              доход формы
расход = f₀ + μ·n + κ·n²/p       поддержание + починка + издержки
жива ⟺ приход ≥ расход
```

## 1. Размерность: два слагаемых сходятся, третье — нет

Цель: все слагаемые расхода должны быть **мощностью** (Дж/с = масса¹·длина²·время⁻³).

| слагаемое | размерность | сходится |
|---|---|---|
| `f₀` | масса¹·длина²·время⁻³ | да |
| `μ·n` | масса¹·длина²·время⁻³ | да |
| `κ·n²/p` при `[κ] = Дж·с/г²` из таблицы | **масса¹·длина²·время⁻¹** | **нет** |
| что нужно для `κ` | масса¹·время⁻³, то есть **Дж/(с·г²)** | — |

Расхождение: **лишнее время²**. Значит в таблице единиц `κ` записан как `Дж·с/г²`, а должен быть
`Дж/(с·г²)`.

**Это дефект записи единиц, а не формулы**: само слагаемое `κ·n²/p` требует `Дж/(с·г²)`, чтобы давать
мощность. Формула верна, таблица — нет.

## 2. Предел `p → 0`

| `p` | расход | состояние |
|---|---|---|
| 1,00 | 3,20 | жива |
| 0,50 | 4,40 | жива |
| 0,20 | 8,00 | жива |
| 0,10 | 14,00 | **мертва** |
| 0,05 | 26,00 | мертва |
| 0,01 | 122,00 | мертва |

Расход растёт как `1/p`, поэтому существует **критическая доля** `p* = κ·n² / (приход − f₀ − μ·n)`; в этом
примере `p* = 0,150`. Ниже неё система мертва при том же приходе.

Это содержательное предсказание: **слишком маленькая доля `p` убивает быстрее, чем недостаток прихода** —
из-за члена «издержки формы».

## 3. Различимость двух прочтений

| прочтение `n` | единица `κ` | смысл |
|---|---|---|
| масса в граммах | `Дж/(с·г²)` | издержки растут как квадрат массы: крупная форма платит за геометрию |
| число особей (шт) | `Дж/с` | член теряет связь с массой и превращается в постоянную добавку |

**Два прочтения дают разные формулы, а не разные обозначения.** В таблице единиц стоит `n = г`, значит
рабочим считается первое; второе — граница применимости, о которой стоит помнить.

## Опровергающее условие

Если размерности всех слагаемых расходятся — п.1 провален; если при `p → 0` расход остаётся конечным —
п.2 провален. `tools/maintenance_cost.py` возвращает 1 в первом случае (так и сейчас — из-за дефекта
единиц `κ`).

## Что это НЕ доказывает

- Что `κ` в источнике имеет именно такую единицу: проверено только соответствие внутри нашей записи.
- Что `p*` достигается в реальных системах: пример условный, числа взяты для наглядности.

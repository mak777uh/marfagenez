# Вопросы владельцу — как это делается в этом проекте

Владелец не занимается предметом и не любит частые вопросы. Но есть решения, которые код не принимает:
что считать результатом, что важнее при развороте, сколько тратить времени. Для них есть форма.

## Правила (введены 2026-11-22, [`docs/OWNER-PROFILE-2026-11-22.md`](../../docs/OWNER-PROFILE-2026-11-22.md) §8)

1. **Только HTML**, собранный генератором — руками не писать:
   ```bash
   python3 tools/ask_owner.py --spec tools/ask_specs/<дата>-<тема>.json --out <путь>/QUESTIONNAIRE.html
   ```
2. **У каждого вопроса обязательное поле «своими словами»** — генератор добавляет его сам, structural:
   вопрос без этого поля собрать нельзя.
3. **У каждого вопроса есть «не знаю — реши сам»**: это не заглушка, а передача решения агенту с записью
   в журнал и показом результата через круг.
4. **Ответы сохраняются дословно** в `docs/owner-answers/YYYY-MM-DD-*.md` — включая свободные поля.
5. **Один опросник за круг**, и только по решениям, которые нельзя принять кодом.
6. Простой язык: никакого жаргона без перевода; в вопросе объясняется, зачем спрашивают.

## Почему генератор, а не шаблон в голове

Правило, живущее в переписке, забывается следующим агентом. Генератор делает требование структурным:
у вопроса физически нет варианта «без поля своими словами». Плюс он же пишет выгрузку, автосохранение
и одинаковое поведение во всех опросниках.

## Спека

```json
{"title": "...", "intro": "...", "out_name": "мои-ответы-3",
 "sections": [{"title": "...", "hint": "...",
   "questions": [{"id": "q1", "text": "...", "why": "...", "type": "radio|checkbox|text",
                  "options": [{"value": "a", "label": "...", "note": "..."}]}]}]}
```

Спеки лежат в `tools/ask_specs/` — по одной на опросник, чтобы вопрос можно было воспроизвести и
сравнить с ответом через месяц.

## Что делать с ответами

1. Записать дословно в `docs/owner-answers/`.
2. Обновить [`docs/OWNER-PROFILE-2026-11-22.md`](../../docs/OWNER-PROFILE-2026-11-22.md) — датированным
   добавлением, не переписыванием.
3. Отчёт владельцу — **только выводы** (`conclusions`): числа по запросу, «непроверенное» отдельным блоком.
4. Если ответ «не знаю» — принять решение самому, записать обоснование в журнал, через круг показать итог.

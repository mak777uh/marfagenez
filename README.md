# МАРФАГЕНЕЗ++

**Среда, в которой ребёнок может стать собой.**

Не продукт. Не школа. Исследование: какое пространство полезно для жизни — и как построить его так, чтобы оно не могло ошибиться в замерах.

---

## Название

**Марфагенез** — от *марфа* (греч. μορφή — форма) и *генезис* — рождение формы. Не «формирование» (это делает кто-то снаружи), а **рождение формы изнутри**.

**++** — потому что это вторая попытка. Первая (проект `medium`) дала 179 теорем и три неверные. Здесь эти ошибки невозможны по построению.

---

## Первый принцип

> **Среда не измеряет и не направляет. Она даёт условия и не вмешивается.**

Это не мягкость. Это вывод из 34 заметок и 179 теорем.

| что делали | что вышло |
|---|---|
| среда измеряла ребёнка | ребёнок боялся замера, а не жил |
| среда подсказывала | ребёнок перестал искать |
| среда направляла | ребёнок стал копией ориентира |
| среда помогала | ребёнок сузился |

Из Саммерхилла (N1, N4, N19, N24):
- **N1.** Школа должна подходить детям, а не дети школе
- **N4.** Отсутствие страха — самое прекрасное в жизни ребёнка
- **N19.** Показывая, как работает игрушка, мы крадём радость открытия
- **N24.** Я научился ждать

Из Кришнамурти (P19, P22, P29, P132):
- **P19.** Отношение — не зависимость; зависимость разрушает отношение
- **P22.** Сравнение — двигатель конфликта
- **P29.** Знание создаёт дистанцию, которую потом пытается преодолеть
- **P132.** Незрелый ум сравнивает; зрелый не имеет меры

## Что доказано, а что только измерено

Три уровня, которые нельзя смешивать (по образцу herness):

| уровень | что | доказуемо | где |
|---|---|---|---|
| **A. Закон** | утверждение о среде | **да**, Lean | `laws/` |
| **B. Ядро** | код, исполняющий закон | **да**, типами | `core/` |
| **C. Замысел** | что мы правильно поставили вопрос | **нет**, только пробами | `checks/` |

> **A и B — доказательство. C — измерение.**

Утверждать больше, чем доказано, здесь нельзя.

## Что мы уже знаем (и на чём это стоит)

### Законы среды

| закон | формула | уровень | чем подтверждено |
|---|---|---|---|
| разброс в комнате | `spread = B/√3` | **A** | Lean + симуляция |
| отбор не сжимает | `Var(exp(k·x)) = 1` для N(0,1) | **A** | Lean + симуляция |
| плотность роста | `ρ(x) ∝ exp(αx)`, `α = 2μ/σ²` | **A** | Lean + симуляция |
| отражение сохраняет меру | изометрия на окружности | **A** | Lean (Mathlib) |
| куб держит, шар душит | `Var = d/(d+2)·R²` | **A** | Lean + симуляция |
| подражание сужает | рост ↑, диапазон ↓ | **C** | симуляция |
| любая помощь сужает | копирование, обучение, подъём | **C** | симуляция |

### Три неверные теоремы, которые мы поймали

| теорема | ошибка |
|---|---|
| `negative_feedback_collapses` | неверна без `0 ≤ k` |
| `equal_division_maximises` | неверное направление |
| `double_room_sqrt_two_spread` | разброс растёт линейно, не `√2` |

Все три прошли бы, если бы мы не удалили `module`. Это и есть причина, по которой нужен уровень C.

## Структура

```
core/          Rust — ядро с типами, делающими ошибки невыразимыми

```

## Быстрый старт

```bash
# ядро
cd core && cargo test --release

# законы
cd laws && lake build

# пробы
python checks/verify_all.py
python checks/gates.py
```

---

## Три правила

1. **Число без команды — не результат.** У каждой цифры рядом команда и артефакт.
2. **Отрицательный результат остаётся.** Отброшенное не выбрасывается.
3. **Каждый отчёт содержит «что это не доказывает».**

---

## Чего это не доказывает

- **Не работает.** Это исследование, не продукт.
- **Не проверено на детях.** Модель математическая.
- **Не «лучше Саммерхилла».** Мы не сравнивали.
- **Уровень C не доказан.** Замысел проверяется пробами, а не доказывается.
- **Модель ограничена.** Одномерная черта и один источник ширины. Компания в ней не может расширять — это свойство модели, не жизни.

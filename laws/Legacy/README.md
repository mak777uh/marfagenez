# Legacy — отдельная библиотека

Эти девять файлов лежат в `laws/Legacy/` и собираются отдельной библиотекой
`Legacy` (`lake build Legacy`). Они **не** входят в `Medium` и не импортируются
из `Medium.lean`.

## Почему отдельно

До 2026-11-12 они лежали в корне `laws/` и в `Medium/`, но их никто не
импортировал — значит `lake build` их не компилировал. Это ровно та же ошибка,
из-за которой раньше 35 из 48 файлов `Medium/` ни разу не собирались.

Теперь они собираются, но отдельно, потому что это **другой проект**:

| файл | что это | теорем |
|---|---|---|
| `Saturation.lean` | `spread := min freeWalk wallLaw` — насыщение | 6 |
| `Race.lean` | гонка «время заполнения» против «время реакции» | 4 |
| `Reaction.lean` | реакция на дрейф, полное демпфирование | 5 |
| `Time.lean` | время до сужения зазора | 4 |
| `Tilt.lean` | наклон распределения при сдвиге | 3 |
| `FFI.lean` | те же законы на `UInt64` для вызова из Rust | 0 |
| `Equiv.lean` | `FFI.saturation` = `Saturation.spread` | 2 |
| `Convergence2.lean` | chi²-тест сходимости к равномерному | 3 (1 — `sorry`) |
| `Probe.lean` | пустышка: 0 теорем, 2 `example` | 0 |

Это язык «стена / свободный ход / гонка / наклон» — метафора, а не модель
клетки. Модель клетки (`cellStep`, `equilibrium`, `capacity`) живёт в `Medium/`
и считается в `core/`. Смешивать их нельзя: у них разные переменные и разные
единицы.

## Что не доказано

`Convergence2.fold_identifies` помечен `sorry`. Утверждение **ложно в том
виде, как записано**: `%` на `ℝ` в Lean не периодичен по `4B` в нужном смысле.
Теорема оставлена как маркер, а не как результат. Это третий случай за проект,
когда «доказанная» теорема оказалась ложной (`fold_identifies`,
`mean_le_of_all_le`, `varianceF_bound`).

## Сборка

```bash
cd laws
lake build Legacy     # только Legacy
lake build            # только Medium (defaultTargets)
```

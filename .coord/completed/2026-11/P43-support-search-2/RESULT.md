# Раунд P43 — 2026-11-25 — поиск опоры по величине: документированный ноль

## Вопрос

Даёт ли канал «поиск по измеряемой величине» пары для остальных узлов без опоры — `C-006`, `F-002`,
`F-006`, `GAP-02`?

## Ответ: нет, и это оформлено протоколом

Пять запросов по величине (не по названию) по 1008 ячейкам карты. Найдено:

| запрос | что нашлось | почему не пара |
|---|---|---|
| удержание/наследование повреждения | `D-0004` (наследуемые ошибки копирования), пустоты `D-0007`, `W2-0035`, `W2-0042`, `W2-0043`, `W3-0022` | измеряют наследование **мутаций**, а не повреждения сомы; `h` не наблюдается |
| складка/излом/порог деления | `DIP34-0006` (граница рампы), `DIP57-0007`, `DIP57-0012`, `DIP57-0009` | изломы по дозе/концентрации — другие величины; `Πλ` не измеряется |
| ядро выживания / полоса допуска | `V-0001` (определение), `DIP2-0009` (условия), `DIP14-0002` (инвариантность), `DIP14-0005` (вычислимость) | дают **объект и свойства**, но не проекцию на ось дохода и не ширину |
| граница/порог выживания | `B18-01-0005` (замораживание эмбрионов) | другая величина |
| цена удержания / доля дохода | `D-0007`, `W2-0037`, `W3-0047`, `DIP3-0012`, `B6-01-0001` | пустоты и модели без бюджета |

**Строгое покрытие не изменилось: 47 пар / 23 узла.** Это правильный результат: проход не дал повода
записать слабую пару.

## Чего я сознательно не сделал

Не записал `V-0001 → C-006` как пару. Соблазн был: общий объект — ядро выживания. Но `C-006` утверждает
**проекцию и ширину**, а `V-0001` — только определение множества. Связать их значило бы выдать
определение за измерение — ровно та ошибка, из-за которой пришлось понижать четыре вердикта в `P33`.

## Ограничение, записанное в документе

Поиск шёл **только по нашей карте** (1008 ячеек), не по внешним базам. «Не найдено» относится к
просмотренной выборке, а не к литературе вообще.

## Следующий вопрос

Расширить поиск за пределы карты: `Viability kernel projection`, `Chao asymmetric division threshold` —
и либо добыть ячейку с этой величиной, либо оформить такой же протокол по внешним каналам.

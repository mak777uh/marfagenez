# Раунд P30 — 2026-11-25 — v3: параметр относится к эндпоинту

## Вопрос

Можно ли поправить формулу v2 так, чтобы она допускала **немонотонность** (наблюдённую у 53BP1-фокусов)
и при этом оставалась проверяемой?

## Результат

Предложена форма с recruitment-членом:

```
R(D) = C0 · exp(−D/a) · (1 + D/b)
```

Из неё точно следует:

- `D* = a − b` — точка максимума, существует только при `a > b`;
- при `a ≤ b` функция монотонно падает, то есть **v2 — предельный случай** `b → ∞`;
- наклон в нуле положителен ровно при `a > b` — это и есть различающий признак.

Численная проверка (`a = 2`, `b = 0,5`, `C0 = 1`): `D* = 1,5`; `R` растёт 1,01 → 1,89 → 0,90;
наклон в нуле `+1,5`.

## Различающее предсказание

`R(D)` при ≥3 дозах в одном методе: v2 требует монотонного падения, v3 — роста до `D*` и спада после.
Для 53BP1-фокусов рост уже виден, то есть v2 в этом эндпоинте опровергнута.

## Что это НЕ доказывает

- Что v3 верна: согласуется по направлению с одним набором, другие не проверялись.
- Что `a` и `b` измеримы по двум точкам: нужна третья доза.
- Что `D*` наблюдается в живых системах: он предсказан формой.

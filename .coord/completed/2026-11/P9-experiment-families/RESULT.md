# Раунд P9 — 2026-11-25 — семьи экспериментов

## Вопрос

Можно ли сжать записи прогонов в семейства, **не удаляя** ни одного прогона, и сколько семейств
получится вместо прежнего счёта «по прогонам»?

## Предсказание (до подсчёта)

Ожидалось: семейств будет заметно меньше, чем прогонов, но больше сотни; часть семейств окажется
вырожденной (один прогон), а у части — расходящиеся вердикты при одинаковых параметрах.

## Метод

`tools/exp_families.py`: семейство = имя эксперимента + канонические параметры (JSON с сортированными
ключами). Прогоны остаются на месте; семейство — вычисляемое поле, а не новая сущность.

```
python3 tools/exp_families.py --write
```

## Результат (числа)

| величина | значение |
|---|---|
| прогонов | **407** |
| разных имён экспериментов | **110** |
| семейств (имя + параметры) | **117** |
| семейств из одного прогона | **75** |
| семейств с разными вердиктами при одинаковых параметрах | **10** |

Размеры семейств: 75 семейств по 1 прогону, 32 по 2, 6 по 3, 1 по 4, дальше три выброса —
15, 110 и 121 повтор.

**Три выброса — это не разные опыты, а повторы одного и того же:**

- `frozen-ceiling`: 121 прогон с одинаковыми параметрами
  `{"cells": 40, "every": 500, "maintenance": 0.6, "n": 40, "policy": "stay", "repair_cost": 1.5, "steps": 1200}`;
- `protocol-capacity`: 110 прогонов с одинаковыми параметрами;
- `look-order`: 15 прогонов.

То есть «407 экспериментов» — это счёт **прогонов**; уникальных опытов около **117**.

## Что нашлось сверх задачи

**10 семейств, где одинаковые параметры дают разные вердикты.** Это либо недетерминизм прогона, либо
разные версии кода (`commit unknown` в условиях). Пока это не разрешено, такие семейства нельзя
считать семейством с одним выводом — в черновике они перечислены с числом прогонов и примером id.

## Предложение для `kg/` (записано в черновике)

1. добавить каждому прогону `data.family = "<эксперимент>-<8 hex>"` (детерминированно);
2. не вводить новый вид узла — семейство читается группировкой;
3. при расхождении вердиктов — `data.family_conflict: true`, чтобы это видел фронт;
4. семейство с одним прогоном не считается воспроизведённым.

## Проверки

- `python3 tools/exp_families.py` — сводка воспроизводима;
- `python3 checks/doc_links.py` — зелёный;
- `python3 checks/doc_numbers.py` — числа совпадают с деревом.

## Что это НЕ доказывает

- Что группировка по параметрам отражает научную «семью»: это механическая группировка.
- Что параметры описывают опыт полностью: часть записей помечена `commit unknown`.
- Что расходящиеся вердикты — именно недетерминизм: возможны разные версии кода.

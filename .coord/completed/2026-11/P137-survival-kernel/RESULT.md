# Раунд P137 — 2026-11-25 — `F-024`: ядро выживания, аппроксимация проверена

## Что проверял

`K_{i+1} = K_i ∩ F⁻¹(K_i)` — убывающая последовательность, предел которой должен быть `V(K)`.

Пример с известным ответом: `F(x) = 2x − 0,5`, `K = [0; 1]`. Выживает только `x* = 0,5`.

## Числа

| шаг | размер `K_i` |
|---|---|
| `K_0` | 2001 |
| `K_1` | 1001 |
| `K_2` | 501 |
| … | … |
| `K_11` | **1** |

Предел `[0,5000; 0,5000]`, ширина **0,0000** — совпадает с аналитическим `x* = 0,5`.
Монотонность выполняется, остановка — по неизменности множества (`K_11 = K_10`), а не по числу итераций.
Точка `0,5` выживает 1000 шагов.

## Честно о собственной ошибке

Первая версия дала «предел шириной 0,5» и вывод «не подтверждено». Причина: прообраз считался
относительно **постоянного отрезка `[0; 1]`**, а не относительно **текущего множества `K_i`**.

Вся суть записи — в том, относительно чего берётся прообраз. С постоянным отрезком это другая итерация,
и она останавливается на `K_1`.

**Седьмой случай за день, когда дефект был в проверке, а не в формуле.** И самый поучительный: ошибка
в одном слове.

## Что это НЕ доказывает

- Что `V(K)` вычислимо за малое число шагов на реальных системах: один пример, одна сетка.
- Что «полоса» по `α` равна проекции `V(K)`: отдельное утверждение, не проверялось.

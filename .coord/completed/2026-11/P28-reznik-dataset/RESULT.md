# Раунд P28 — 2026-11-25 — Dataset S1 Reznik: три числа подтверждены

## Вопрос

Действительно ли Dataset S1 статьи Reznik недоступен («PLOS отдаёт TIFF под именем `.xlsx`»), или три
числа, стоявшие в карте как неверифицированные, можно проверить по сырому файлу?

## Ответ: доступен, и числа подтверждены

`s001` для DOI `10.1371/journal.pcbi.1003195` — **настоящий XLSX** (35 198 байт, PK-архив), три листа:
`Figure 2`, `Figure 3`, `Figure 5C`. Прежнее утверждение о TIFF **неверно для этого DOI**.

Три числа найдены точным совпадением в колонке `Shadow Price` листа `Figure 2`:

| число | строка | подпись |
|---|---|---|
| `−0,0368` (пируват) | 3 | ограничение `Glucose`, метаболит `Pyruvate` |
| `−15,1745` (ATP) | 22 | ограничение `Phosphate`, метаболит `ATP` |
| `−9,0416` (UTP) | 43 | ограничение `Uracil`, метаболит `UTP` |

## Что сделано

1. **`docs/artifacts/reznik2013-dataset-s1.xlsx`** — сырой файл в репозитории.
2. **`tools/reznik_dataset.py`** — разбор XLSX без внешних библиотек (zip + XML), поиск записанных
   чисел, выгрузка CSV.
3. **`docs/artifacts/reznik2013-Figure-2.csv`**, `-Figure-3.csv`, `-Figure-5C.csv` — таблицы.
4. **`docs/FINDING-344.md`** — находка с локаторами.
5. **`docs/ANALYSIS-EXTERNAL-2026-11-25.md`** — датированное уточнение: утверждение про TIFF неверно
   для этого DOI.
6. `NOT-CLAIMED.md` — счётчик находок приведён к дереву (342).

## Проверки

- `python3 tools/reznik_dataset.py --write` — воспроизводит поиск и выгрузку;
- `python3 checks/doc_numbers.py`, `python3 checks/doc_links.py` — зелёные.

## Что это НЕ доказывает

- Что числа означают то, что мы им приписывали: подпись говорит «ATP», но связь с моделью — отдельный вывод.
- Что листы разобраны полностью: извлечены строки, но не сверены с подписями рисунков.
- Что остальные «неверифицированные» числа карты тоже найдутся.

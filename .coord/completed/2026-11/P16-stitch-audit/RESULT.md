# Раунд P16 — 2026-11-25 — покрытие по величине, а не по паре

## Вопрос

Сколько утверждений действительно имеют литературную опору, если считать опору по совпадению
**измеряемой величины**, а не по факту наличия пары?

## Предсказание (до подсчёта)

Ожидалось: строгая метрика ниже прежних 30 из 152, потому что Red Team нашёл 20 несравнимых пар.

## Результат

| метрика | значение |
|---|---|
| пар проверено | 111 |
| `S` — величина совпадает | 48 |
| `Ch` — частично | 43 |
| `N` — несравнимо | 20 |
| узлов с `lit_ref` | 30 |
| **опора `S`** | **22** |
| только частичная | 6 |
| только несравнимые пары | 2 (`C-006`, `L-064`) |

Строгое покрытие: **22 / 152** вместо 30 / 152. Промежуточное (с частичными): 28 / 152.

То есть примерно **восемь утверждений из тридцати** считались опёртыми без опоры: у шести совпадение
частичное, у двух — только несравнимая пара.

## Что исправлено

1. `docs/STITCH-AUDIT.md` — разбор и таблица трёх метрик (генерируется `tools/stitch_audit.py`).
2. `docs/STITCH-COVERAGE.md` — датированная поправка: «30 из 152» = «есть пара», а не «есть опора».
3. `tools/stitch_audit.py` — воспроизводимый пересчёт по вердиктам Red Team.

## Проверки

- `python3 tools/stitch_audit.py --write` — сводка воспроизводится;
- `python3 checks/doc_links.py`, `python3 checks/doc_numbers.py` — зелёные.

## Что это НЕ доказывает

- Что вердикты Red Team верны: это суждение по тексту, а не измерение.
- Что остальные 122 утверждения не имеют опоры: они просто не покрыты парами вовсе.
- Что частичные пары бесполезны: они могут стать строгими, если выписать соответствие переменных.

## Следующий вопрос

Взять шесть частичных и две несравнимые пары и по каждой либо выписать соответствие переменных
(тогда `Ch → S`), либо снять пару. Два узла с несравнимыми парами (`C-006`, `L-064`) надо либо
опереть, либо честно пометить как гипотезы без опоры.

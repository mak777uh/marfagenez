# Раунд P138 — 2026-11-25 — `F-023`: инвариант относится к состоянию, а не к потокам

## Числа

Цикл `A→B→C→A`, левое ядро `S` одномерно, `w ∝ (1,1,1)`.

**(1) `wᵀv` на допустимых потоках (`Sv = 0`) — НЕ постоянно:**

| `v = t·(1,1,1)` | `wᵀv` |
|---|---|
| `t = 0,5` | 0,866025 |
| `t = 1,7` | 2,944486 |
| `t = 4,2` | 7,274613 |

Разброс в **8,4 раза**.

**(2) `wᵀx` вдоль траектории `ẋ = S·v` — постоянно:** 1,154700538 на всём `t = 0…5`.

**(3) Сильная двойственность:** прямая 16,000000000 = двойственная 16,000000000, разница 0,00e+00.

**(4) `Sᵀ(y + 2,5·w) = Sᵀy`** — теневые цены не определены вдоль `w`.

## Дефект записи

`wᵀS = 0 ⇒ wᵀv` тождественно, то есть **никакого ограничения на `wᵀv` не даёт**. Ограничение возникает для
состояния: `wᵀx` сохраняется. Для потоков верное утверждение другое — сдвиг цен вдоль `w`.

## Честно о двух собственных ошибках в проверке

1. Первая матрица `S` была 4×4 обратимой: левое ядро пусто, «допустимых потоков» нет вовсе.
2. Срез ядра брал по числу строк (`vt[3:]`) вместо ранга — при ранге 2 ядро одномерно, а срез давал пусто.

Обе — в проверке, не в формуле. **Восьмой и девятый случай за день.**

# Раунд P131 — 2026-11-25 — `F-018`: правило верно для мономов, асимптотично для смесей

## Что проверял

`F-018`: показатель `= 1/(порядок ведущего члена)`; два линейных канала дают 1, а не 1/2.

## Числа

| функция | измерено | теория |
|---|---|---|
| `ε = x` | 1,0000 | 1,0000 |
| `ε = x²` | 0,5000 | 0,5000 |
| `ε = x³` | 0,3333 | 0,3333 |
| `ε = x + x²` | 1,0000 | 1,0000 |
| `ε = x² + 0,001·x` | **0,9544** | 1,0000 |
| `ε = 1e-9 + x²` (выше смещения) | 0,5000 | 0,5000 |

## Что установлено

1. **Чистые мономы — точно** (расхождение 0,0000).
2. **Два канала одного порядка показатель не меняют:** `x + x²` даёт 1, а не 1/2 — ровно как записано в узле.
3. **Смесь разных порядков даёт ПРОМЕЖУТОЧНЫЙ показатель** (0,954 вместо 1): асимптота достигается при `ε → 0`,
   куда численно не добраться.
4. **Аддитивное смещение задаёт порог:** ниже него обратная задача неразрешима, «показателя» нет.

## Граница, которой нет в узле

Показатель определён **только вместе с диапазоном `ε`**. Без него `x ~ ε^(1/k)` читается как закон, а
является **асимптотой**. Тот же класс, что `F-029` (показатель без переменной) и `F-016` (приближение без
границы).

## Честно о первой попытке

Первый прогон включал `ε = 1e-9 + x²` на сетке **ниже смещения**, где решения нет: бисекция возвращала
`x → 0`, и «показатель» вышел **17,2**. Дефект постановки, а не правила; исправлено.

## Проверки

- `python3 tools/exponent_order.py` — rc=0 (на чистых мономах расхождение 0,0000);
- `checks/doc_numbers.py`, `checks/doc_links.py` — зелёные.

## Что это не доказывает

- Что в реальных системах ведущий порядок определён однозначно.
- Что 0,954 «неправильно»: оно правильно для этого диапазона.

literature/map» для узлов без `lit_ref`?

## Метод (воспроизводимо)

Скрипт на python3 по двум файлам:

1. `kg/nodes.jsonl` → узлы без `data.lit_ref` (550 шт.); из `data.locator`
   извлечены DOI: поле `doi` напрямую + regex `10\.\d{4,9}/[-._;()/:A-Za-z0-9]+`
   по всем строковым полям локатора (`doi`, `url`, `pmid`, `arxiv`,
   `openalex`). Нормализация: lowercase, снятие `https?://(dx.)?doi.org/`,
   хвостовой пунктуации.
2. `literature/map/atoms.jsonl` → множество DOI из `works[].doi` всех 999 ячеек
   (743 уникальных).
3. Пересечение множеств + проверка симметрии существующих пар в обе стороны.

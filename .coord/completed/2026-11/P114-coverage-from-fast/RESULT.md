# Раунд P114 — 2026-11-25 — покрытие выросло на один узел (19/152)

## Вопрос

Можно ли растить покрытие **из уже имеющейся карты**, не добавляя литературы?

## Метод

Искал атомы, у которых `kg_ref` указывает на узел **без** `S`-пары. Нашлось **22 кандидата** на 152 узла.

## Результат по шести разобранным

| пара | решение |
|---|---|
| `FAST-S2M-01 \| L-013` | **`S`** — прямое измерение `m_S = 0,039 ± 0,003` |
| `FAST-S2M-04 \| L-013` | **`S`** — `m_S` зависит от генотипа (0,082 против 0,066) |
| `FAST-S2M-05 \| L-013` | **`S`** — 0,039 прямым измерением против 0,066 из хемостатов |
| `FAST-S2M-02 \| L-012` | `Ch` — `m_ATP` коэффициент, `κ` доля |
| `DIP59-0007 \| F-003` | `N` — эффективность HR ≠ закон накопления |
| `DIP58-0001 \| C-008` | `Ch` — необратимость переключения ≠ наследование размера |

**Метрика:** `S`-пар **25 → 28**, узлов **18 → 19**.

## Честно о прибавке

Три пары прибавились к **одному** узлу. Устойчивость `L-013` выросла (три независимых измерения), а покрытие —
на **один узел**. Записывать «+3 к покрытию» было бы подменой: покрытие считается узлами, а не парами.

## Что дал метод

Правило «атом с `kg_ref` на узел без `S`-пары» — конечный список из 22 кандидатов. По нему видно, где опора
возможна **в принципе**, без поиска новой литературы.

## Проверки

- `python3 checks/stitch_coverage_floor.py --update` → 28/19;
- `checks/doc_numbers.py`, `checks/log_check.py` — зелёные.

## Что это НЕ доказывает

- Что остальные 16 кандидатов дадут `S`: часть окажется `Ch` или `N`, как `DIP58-0001`.
- Что `L-013` теперь «доказан»: три измерения одной величины у одного штамма не делают утверждение всеобщим.

## Следующий вопрос

Разобрать остаток списка (16 кандидатов) — это прямой путь к покрытию без новой литературы.

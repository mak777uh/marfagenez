# S7-targeted-literature — литература под конкретные узлы `kg/`

**Постоянная задача.** Раунд = одна цель из списка.

## Зачем это отдельно от S2

Сшивка (П2) **исчерпала материал**: все пары «ячейка ↔ узел» оценены, покрытие 48 `S`-пар из 152 узлов
(24 %). Дальше покрытие растёт **только** если в карту приходит литература **именно про те величины, которые
записаны в узлах без `S`**.

Партия «по интересной теме» ложится рядом и покрытия не двигает. Партия **под узел** может дать `S`-пару.

## Как выбрать цель

```bash
python3 tools/stitch_audit.py --write            # таблица S-пар → docs/STITCH-AUDIT.md
python3 tools/map_orphans.py                     # состояние карты
```

Список узлов без `S` (по состоянию на 25.11.2026):

| узел | о чём | что искать |
|---|---|---|
| `C-002` | цена удержания кусочно-постоянна | теневая цена / двойственная переменная: **скачки** при смене активного ограничения (измеренные) |
| `C-006` | полоса допуска = проекция ядра выживания | viability kernel и его **проекция** на одномерную ось параметра |
| `C-007` | показатель расходимости = 1/(m+1) | модели с несколькими **каналами удаления** повреждения и измеренный показатель |
| `F-001` | кумулятивная опасность `H(T)=∫μ dt`, смерть при `H=1` | эксперименты, где смерть наступает при накопленной опасности 1 |
| `F-002` | `Dₙ₊₁ = h·Dₙ + δT`, плато `δT/(1−h)` | измеренная **доля удержания** повреждения за поколение и плато |
| `F-004` | приход ≥ расход (поддержание + починка) | бюджеты поддержания и починки в одной системе |

| `F-031` | внутреннее ограничение выживания из графа процессов | порог выживания, вычисленный из структуры графа зависимостей |

Плюс ≈100 `L-*` узлов без вердикта: `python3 tools/map_atoms_all.py` нет — смотри `docs/STITCH-AUDIT.md`.

## Что присылать

Файл `literature/map/inbox/fast-<раунд>-atoms.jsonl` + `-edges.jsonl`, схема — как в `S2`.

**Обязательно в каждом атоме:** `kg_ref: ["<узел>"]` — тот узел, под который искали. Если честной пары нет,
это тоже результат: напиши в `RESULT.md` строкой «под узел `<X>` не нашлось: <что искали, где смотрели>».

**Не присылать:** ячейки, которые «рядом по теме». Сегодня из 12 таких пар одна дала `S`.

## Критерий приёмки

`python3 tools/stitch_audit.py` — число `S`-пар не уменьшилось; `checks/map_contract.py` зелёный;
правило цеттелькастена соблюдено (каждая новая ячейка со связью).

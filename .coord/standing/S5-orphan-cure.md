# S5-orphan-cure — лечение долга сирот

**Постоянная задача.** Каждое взятие — один раунд, отдельный каталог `active/S5-orphan-cure-<время>/`.

## Что делать

В карте есть ячейки **без единой связи** (на 25.11.2026 — 293 из 1105). Они не находятся обходом и не влияют
ни на сшивку, ни на вывод. Твоя работа — прочитать группу и связать по роли.

1. Получи список сирот: `python3 tools/map_orphans.py` (и `python3 tools/map_orphans.py --group DIP34` для одной группы).
2. Возьми **одну группу**, например `DIP1` (10 сирот), и прочитай КАЖДУЮ ячейку целиком:
   `python3 tools/map.py zoom --atom DIP34-0001`.
3. Найди для каждой связную ячейку того же домена и определи **роль**:

| роль | тип | когда |
|---|---|---|
| уточнение той же величины | `refines` | тот же предмет, больше деталей или другой диапазон |
| зависимость | `requires` | без этой величины утверждение не формулируется |
| расхождение | `contradicts` | две ячейки утверждают разное об одном |
| обобщение | `generalizes` | общая форма охватывает частный случай |
| следствие | `derives` | формула выводится из определения |
| другой механизм того же | `analogous` | **не больше одного за раунд** |

4. Положи файл предложения: `literature/map/inbox/lit-<раунд>.jsonl`, строки вида
   `{"from": "...", "to": "...", "type": "refines", "note": "чем именно уточняет"}`.
5. В `RESULT.md` напиши, **что связать не удалось и почему** — это тоже результат.

## Жёсткие правила

- Проверяй **порядок величин** при постановке `refines`: пересчитай обе в одну единицу. Ребро между
  72 519 Дж/м² и 0,12 Дж/м² уже было ошибочно поставлено как `refines` (различие 10⁶).
- Не более **8 рёбер** за раунд и не больше **одного** `analogous`: доля аналогий в карте 30,3 % при
  потолке 1/3.
- Git не твой. Правишь только свой файл в `inbox`.
- Правило цеттелькастена: ячейка без связи не принимается вообще — но и связь «лишь бы была» не считается.

## Критерий приёмки

`python3 checks/map_contract.py` зелёный после приёма; `python3 tools/map_orphans.py --strict` не вырос.

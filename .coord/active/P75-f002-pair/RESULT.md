# Раунд P75 — 2026-11-25 — F-002: пара по величине есть, предсказание не проверено

## Вопрос

Есть ли в карте пара по величине для `F-002` («порог доли удержания»: `D_(n+1) = h·D_n + δT`, плато
`D* = δT/(1 − h)` при `h < 1`, плато нет при `h ≥ 1`)?

## Ответ: да, но частичная

**Кандидат:** `B9-03-0002` — модель линии дрожжевых клеток с накоплением повреждённых белков при делениях
**с репарацией и удержанием повреждения**, объясняющая омоложение дочерних клеток и «вторую степень»
омоложения.

**Вердикт `Ch`, а не `S`:** величина совпадает (доля удержания повреждения за поколение), но атом

- не даёт **численного** `h`;
- не формулирует `h ≥ 1`;
- не говорит о **плато** — то есть о самом предсказании узла.

Это описание модели без чисел. Плюс оговорка: атом опирается на **абстракт**.

## Побочно: нашёл расхождение в двух числах и объяснил его

Документ `STITCH-AUDIT.md` писал «опора `S`: 20», а проверка пола — «узлов `S` = 21». Причина: **`L-009`
имеет `S`-пару, но у него нет `lit_ref`**, а документ считает только узлы с `lit_ref`.

Теперь это видно в самом документе: «20 (всего узлов с `S`-парой: 21; разница — узлы без `lit_ref`:
`L-009`)». Раньше два инструмента показывали разные числа без объяснения — то есть расхождение было
скрытым.

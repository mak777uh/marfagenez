# RESULT — S2 round: damage retention / F-002 (дыра из SUPPORT-SEARCH-2)

## Вопрос
Измерена ли доля удержания повреждения h между поколениями — и какова её величина при симметричном делении?

## Каналы
EPMC → fullTextXML (Stewart 2005, PLoS Biol, PMC546039, OA). Кандидаты-обзоры (PMC13310912) отклонены — без чисел.

## Ячейки (5 атомов + 4 ребра)
- FAST-S2N-01: old pole растёт на 2.2%±0.1% медленнее (7,953 пары, p<0.00001) — функциональная асимметрия при симметричном делении.
- FAST-S2N-02: −3.1%±0.3% биомассы потомства старого полюса.
- FAST-S2N-03: выгода распределения персистентна ≥3 делений, затем плато.
- FAST-S2N-04: рост монотонно убывает с возрастом полюса — градуально, не порог.
- FAST-S2N-05: асимметрия слаба (единицы %) — h близко к 0.5; контраст с yeast.

## Главный результат
F-002 получает первую числовую опору: удержание повреждений при симметричном делении измерено и мало (эффекты 2–3%), персистентно ≥3 поколений. Связь с моделью Borgqvist (s-параметр) установлена.

## Не найдено
Прямое измерение h как доли (нужен трекер повреждений, не только рост); данные по белковым агрегатам конкретно.

## Проверки
map_contract: 0 ошибок (merge-симуляция). DOI чистый.

# Раунд S3 — 2026-11-25 — единицы и режимы F-001 / F-003 / F-029

## Вопрос

Согласованы ли единицы в трёх «наших» формулах карты знаний, и является ли записанное условие режима
рабочим (то есть выражается ли оно через известные величины, а не через неизвестное равновесие)?

## Предсказание (до проверки)

Ожидалось: найдутся ровно те дефекты, что назвал внешний аудит (λ и δ без размерности в F-001,
λ без размерности в F-003, `Delta` в единицах состояния в F-029), а граница режимов F-003 окажется
нефункциональной, потому что содержит `D`.

## Команда проверки

```
python3 tools/units_check.py
```

Скрипт: `check_units.py` перенесён в `tools/units_check.py` (воспроизводимость).

## Результат (числа)

**F-003, граница режимов.** Точка равенства членов `λD² = μ₀D` на равновесии `D = μ₀/λ` даёт

```
h* = 1 − λ·δ/(2μ₀²)
```

Проверка равенства левой и правой частей в этой точке:

```
μ₀=1,   λ=1,   δ=1: h*=0.5000; λD²+μ₀D=2.000000; δ/(1−h*)=2.000000; разница 0.00e+00
μ₀=0.5, λ=1,   δ=1: h*=−1.0000; 0.500000 = 0.500000; разница 0.00e+00
μ₀=1,   λ=2,   δ=1: h*=0.0000;  1.000000 = 1.000000; разница 0.00e+00
```

Безразмерный критерий режима: `η = λδ/(μ₀²(1−h))`, линейный при `η ≪ 1`, корневой при `η ≫ 1`.

**Следствие, которого не было в записи.** При μ₀ = λ = δ = 1 наши точки `h = 0,90 / 0,95 / 0,98 / 0,99`
дают `η = 10 / 20 / 50 / 100` — все четыре **уже в корневом режиме**. Запись «корневой режим только при
h ≥ 0,97» верна лишь для конкретных параметров; линейная аппроксимация завышает равновесие в 4–10 раз
(отношение `D*/D_lin` = 0,270 / 0,200 / 0,132 / 0,095).

**F-029, где живёт показатель 2/3.** Для `ẋ = r·x − x³ + ε`:

```
eps=0.1     r_fold=0.407163  r_fold/eps^(2/3)=1.8899
eps=0.01    r_fold=0.087721  1.8899
eps=0.001   r_fold=0.018899  1.8899
eps=1e-06   r_fold=0.000189  1.8899
ожидание 3/2^(2/3) = 1.88988157484231
```

То есть `Δ_r = 3·2^(−2/3)·ε^(2/3)` — ширина **по параметру** `r` (единицы `1/с`), а сдвиг по состоянию
масштабируется как `ε^(1/3)`. Для статического `r + x² + ε = 0` сдвиг по `r` линеен по `ε`, по `x` — `√ε`.
Значит запись «Δ ~ ε^(2/3) в единицах x» неверна по оси и по общности.

**F-001.** `λ` и `δ` входят только произведением: `α = λδ` с единицей `1/с²`. Разделить их по данным
о смертности нельзя — это записано как свойство, а не как дефект.

## Что это НЕ доказывает

- Что формулы верны физически: проверены размерность и границы режимов, не механизм.
- Что литература знает форму F-003: поиск не закрыт (`L-005`, `L-009` — кандидаты).
- Что `η` измерим: для этого нужны `λ`, `δ`, `μ₀` из одной системы, а не выбранные значения.

### Четыре «чистых» порога со сменой механизма (главное по запросу)

- **Коррозия.** 2017A-T4: связь SR → SCC-индекс нелинейна, ниже ≈10⁻⁵ с⁻¹ — резкий рост
  (DIP51-0001). C465-H950: ниже ΔK_TH = 3.7–4.3 МПа√м включается межкристаллитный SCC, а частота
  2 → 0.2 → 20 Гц меняет da/dN в 10 раз при постоянной da/dt (DIP51-0002/0003) — то есть
  «порог по ΔK» и «порог по частоте» здесь суть два проявления одного переключения
  циклический ↔ time-dependent.
- **Усталость.** Немонотонность: ускорение от водорода растёт с понижением частоты и падает ниже
  0.1…0.01 Гц (DIP51-0004) — оптимум, а не монотонный закон. Для 20 кГц «частотный эффект»
  объясняется саморазогревом с порогом по амплитуде ≈550 МПа (DIP51-0005), то есть частота
  действует не напрямую, а через тепловой режим.
- **Катализ.** Классическая смена «кинетика → диффузия» с числовыми границами Th = 0.4 и Th = 4
  (DIP51-0008), подтверждённая значениями Th = 0.25–0.8 и модулем Вейса–Пратцера порядка единицы
  (DIP51-0009); отдельно — монотонное, но количественное влияние скорости подачи на конверсию и
  селективность (DIP51-0011).
- **Материаловедение.** Порог ε̇* ≈ 10⁴ с⁻¹ по пределу текучести (DIP51-0006) и трёхкратный рост
  хрупкой зоны при снижении скорости деформации на 3 порядка с переходом к межкристаллитному
  разрушению (DIP51-0007).
- **Химия.** Логарифмический закон MSZW(q) с насыщением при малых q (DIP51-0010): ниже ~1 мл/мин
  зависимость выполаживается, выше — растёт логарифмически.

### Незакрытые пробелы (для следующего прохода)

1. **Химия, смена продукта по скорости добавления.** Нужна OA-работа вида «dropwise vs inverse
   addition меняет соотношение продуктов» с числом (например, % моно-/ди-аддукта против мл/мин).
   Кандидат, который не удалось открыть: 10.1186/2193-8865-3-61 (ZnS, скорость капельного
   добавления Na₂S/меркаптоэтанола). Второй путь — Org. Process Res. Dev. / React. Chem. Eng. через
   ACS/PMC, но ACS отдаёт captcha с этого хоста.
2. **Материаловедение, оригинальный BDT-порог по скорости деформации.** Обзор (0006) даёт только
   сводное 10⁴ с⁻¹; оригинал по вольфраму (10.1080/14786430701253197) недоступен — нужен доступ к
   HAL/T&F или другая OA-работа с BDT-температурой как функцией ε̇.
3. **Катализ, порог именно по скорости подачи.** Числа есть для Thiele/Weisz–Prater (0008/0009),
   но «порог по GHSV/расходу, выше которого режим меняется» в OA-виде не зафиксирован; 0011 даёт
   монотонную зависимость.
4. **Коррозия: чистое число «скорость нагружения, 1/с» для перехода анодное растворение ↔
   водородное охрупчивание.** 0001 даёт порог по SR, 0002/0003 — по ΔK и частоте; прямого числа
   «переход при ε̇ = X с⁻¹» между двумя механизмами SCC не встретилось.

# dip-2026-11-23-32 — math.dynamics: резкость переходов (измеренные числа)

Задача: 8–12 ячеек про то, **насколько ступенчато** система переходит из одного состояния в другое:
коэффициент Хилла, критические показатели, ширина гистерезиса, критическое замедление, пороги с долей
диапазона. Не дублировать: rate-induced tipping (2 ячейки), viability kernels, бифуркации в math.dynamics
(16 ячеек), насыщение клиренса Km/Vmax и сигмоида (DIP31-*).

Итог: **12 ячеек**, все с измеренным или записанным числом; у 11 из 12 непустое поле `formula` содержит
только ту запись, которая есть в аннотации или следует из приведённых в ней чисел. Все ячейки —
`confidence: medium`, `locator_status: verified`, `access: abstract`.

## Проверено

Каналы: OpenAlex Works API (`search=`, `per_page=25`) — 22 запроса по пяти темам (Hill-коэффициент,
критические показатели, ширина гистерезиса, критическое замедление/время восстановления, пороги резкости);
затем индивидуальная проверка каждого отобранного DOI запросом
`https://api.openalex.org/works/https://doi.org/<DOI>?select=…` с разворотом `abstract_inverted_index`.
Crossref (`api.crossref.org/works/<DOI>`) использовался как второй канал для трёх работ, у которых
OpenAlex не отдал аннотацию, — ни одна из них в отчёт не вошла.

Проверено индивидуально (DOI открылся, аннотация получена): **32 уникальных DOI** (35 запросов, часть DOI
проверялась повторно в разных партиях); один DOI (`10.1002/chem.201300323`) дал 404 и отброшен. Для каждой из 12 ячеек цитата
программно сверена с текстом аннотации (`quote in abstract` = True; сборка отчёта падает с ошибкой,
если сверка не прошла). Ни один DOI, цитата или формула не выдуманы: всё взято из аннотаций OpenAlex.

Три самые интересные находки:

1. **0001 + 0002 + 0004 — шкала резкости от 1,86 до 11,6.** Это не «примерно сигмоида», а конкретные числа:
   один и тот же тип измерения (наклон Хилла) даёт 1,9 у короткого синтетического дуплекса, 1,86 у
   шаперонина, 3,01 при добавлении кошаперонина и 11,6 у RecA — то есть в биологии резкость перехода
   меняется в 6 раз, и она управляется составом комплекса, а не только сродством.
2. **0003 — резкость не константа системы.** У RecA при нагреве 25 → 37 °C n падает 9,8 → 6,6, тогда как
   kcat растёт. Это прямое предупреждение для любой модели «жёсткого» порога: наклон Хилла зависит от
   температуры так же сильно, как от структуры.
3. **0006 + 0007 + 0008 — показатели как измеренная мера резкости.** Депиннинг даёт β = 0,30 ± 0,03 и
   ν = 1,3 ± 0,3; мета-анализ двумерных экспериментов — узкое окно 0,1 ≤ β ≤ 0,25; динамический гистерезис
   даёт показатель ≈1/3 вместо среднего поля 2/3 и разброс 0,66 → 0,2 за 30 лет. Все три — числа о том,
   насколько быстро величина выходит из нуля у порога.

## Покрытие

Покрыто:

- **коэффициент Хилла как измеренное число** — 4 ячейки (0001–0004) с диапазоном 1,86 … 11,6 и двумя
  условиями, меняющими наклон: добавление кошаперонина (+62%) и температура (−33%);
- **несколько порогов в одной системе** — 0005 (два перехода 16 и 160 мкМ, разнесены на порядок);
- **критические показатели** — 0006 (эксперимент, β и ν с погрешностями), 0007 (окно β из мета-анализа
  экспериментов), 0008 (показатель площади гистерезиса и его разброс 0,66 → 0,2);
- **ширина гистерезиса** — 0009 (13 K, выведена из двух температур полуперехода), 0010 (расщепление
  ветвей по внутренней температуре до 7 K);
- **критическое замедление** — 0011 (закон τ ∼ \|μ−μc\|^β с β = −1/2 и неаддитивность при сближении
  бифуркаций; механизм «почему гистерезис зависит от скорости развёртки» — в 0008);
- **пороги с указанием доли диапазона** — 0012 (0,54 / 0,7 / 0,8 по шкале сухости 0–1, три ступени подряд).

Не покрыто (в просмотренной выборке не найдено):

- **измеренного времени восстановления в единицах времени** (секунды, часы, сутки) до перехода: все
  найденные работы по CSD либо качественны в аннотации («lengthening», «longest time»), либо не имеют
  аннотации в OpenAlex/Crossref. Это главный пробел партии; закрывать его нужно чтением полного текста,
  а не новым поиском по аннотациям;
- **ширины гистерезиса, выраженной долей диапазона управляющего параметра** (например, «петля занимает
  8% диапазона»): все найденные ширины даны в абсолютных единицах (K, мА, мВт);
- **коэффициента Хилла для климата/экологии** — Hill-числа нашлись только в биохимии, материаловедении
  и синтетической химии; для экосистем резкость выражается через показатели и пороги, не через n;
- **измеренного критического показателя для бифуркации Хопфа** в реальной системе (нашлись только
  седло-узловые и депиннинг).

# dip-2026-11-23-23 — bio.information_error: доступность повреждённого белка деградации

Задача: найти **измеренные** величины, описывающие доступность повреждённого белка деградации и скорость
его очистки (доли доступного пула, скорости клиренса, момент насыщения ёмкости, константы удержания,
случаи «потолка доступности»). Лимит задачи — 12 ячеек, минимум 8.

Сделано: 8 поисковых запросов по OpenAlex (`/works?search=…`, `per_page=15`), отобрано 12 работ,
для каждой — отдельная проверка локатора `GET /works/https://doi.org/<DOI>` и выписка дословной цитаты
из `abstract_inverted_index`. Итог: **12 ячеек**, **12 проверенных DOI**, 0 выдуманных локаторов.
Полные тексты не читались — все ячейки `access: "abstract"`, `confidence: "medium"`, `locator_status: "verified"`.

Сеть: в этой машине WSL имеет прямой выход, поэтому запросы шли из `python3 urllib` внутри WSL
(эквивалент `curl.exe` по содержанию запроса); ключ OpenAlex читался из

Три самые интересные находки:

1. **DIP23-0001** — самый прямой ответ на вопрос задачи: ёмкость протеасомы не падает, падает доступность;
   добавление Hsp104 (диз-aggregase) восстанавливает деградацию субстрата UPS **без** увеличения уровня
   протеасом. Это отделяет «ёмкость» от «доступности» экспериментально, а не риторически.
2. **DIP23-0002** — точка насыщения находится на шапероне, а не на протеасоме: убиквитинилированный
   субстрат при деплеции Ssa1/Ssa2 уходит в Hsp42-положительные тельца, и это отменяется запретом
   убиквитинилирования. То есть «метка деградации» и «доступность деградации» — разные переменные.
3. **DIP23-0005 + DIP23-0007** — два независимых случая потолка доступности, и они разной природы:
   в одном доступность задаётся **составом** включения (и восстановима сменой состава), в другом —
   **структурой** агрегата (машина активна, но не связывает субстрат).

## Покрытие

**Покрыто (чем закрыт каждый пункт задачи):**

- *доля доступного пула* — прямых процентов/фракций в аннотациях **не найдено**; вместо числа —
  качественные переключатели (DIP23-0002, 0004, 0005) и один относительный результат (DIP23-0003, 0006).
- *скорость клиренса в единицах белка за время* — найдена только как **относительная** (ускорен/замедлен
  оборот, DIP23-0006, 0011); абсолютных k_clear в аннотациях нет. Единственная работа с измеренными
  константами — DIP23-0008, но это in vitro система Aβ/катепсин B, а не клеточный клиренс агрегатов.
- *насыщение деградации* — покрыто тремя независимыми сценариями: лимит шаперона-переносчика
  (DIP23-0002), компенсаторный рост ёмкости без пользы (DIP23-0010), сохранная ёмкость при падении
  функции in vivo (DIP23-0001).
- *константы связывания/удержания* — одна работа, K(eq) CysC–Aβ (DIP23-0008); констант удержания
  повреждённого белка шаперонами (Kd Hsp70–субстрат, Hsp42–агрегат) в выборке нет.
- *случаи, где добавление ремонта не ускоряет очистку* — DIP23-0005 (состав включения),
  DIP23-0007 (структура агрегата); плюс обратный случай DIP23-0011, где агрегат очистке не мешает.

**Не покрыто (кандидаты на следующую задачу):**

1. Числовая доля протеасомо-доступного пула: нужен полный текст 10.1016/j.jbc.2022.102680
   (вклады путей, вероятно с процентами), 10.1091/mbc.e14-08-1262 (доля удалённых включений),
   10.1093/hmg/ddn157 (какие именно компоненты не рекрутируются).
2. Абсолютная скорость клиренса агрегатов in vivo (ед. белка/время): ни один из 8 запросов не вывел
   на работу с такой величиной в аннотации; нужен отдельный поиск по «SILAC/pulse-chase aggregate
   half-life» и по полному тексту 10.1074/jbc.m117.811448.
3. Порог насыщения как число (при какой нагрузке ёмкость перестаёт быть лимитирующей): в выборке только
   качественные переключатели. Вероятный источник — модели UPS (10.1186/1752-0509-1-17) при чтении
   полного текста, где параметры заданы явно.
4. Константы связывания шаперон–агрегат: работы по Hsp42/Hsp104 есть (10.1083/jcb.201106037,
   10.1038/s41467-020-19104-1), но Kd в аннотациях не приводятся — нужен поиск по «binding affinity
   Hsp42 aggregate», «Hsp104 substrate binding Kd».
